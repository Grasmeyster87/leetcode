2515. Shortest Distance to Target String in a Circular Array
Easy
<p>You are given a <strong>0-indexed</strong> <strong>circular</strong> string array <code>words</code> and a string <code>target</code>. A <strong>circular array</strong> means that the array's end connects to the array's beginning.</p>

<ul>
	<li>Formally, the next element of <code>words[i]</code> is <code>words[(i + 1) % n]</code> and the previous element of <code>words[i]</code> is <code>words[(i - 1 + n) % n]</code>, where <code>n</code> is the length of <code>words</code>.</li>
</ul>

<p>Starting from <code>startIndex</code>, you can move to either the next word or the previous word with <code>1</code> step at a time.</p>

<p>Return <em>the <strong>shortest</strong> distance needed to reach the string</em> <code>target</code>. If the string <code>target</code> does not exist in <code>words</code>, return <code>-1</code>.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<pre><strong>Input:</strong> words = ["hello","i","am","leetcode","hello"], target = "hello", startIndex = 1
<strong>Output:</strong> 1
<strong>Explanation:</strong> We start from index 1 and can reach "hello" by
- moving 3 units to the right to reach index 4.
- moving 2 units to the left to reach index 4.
- moving 4 units to the right to reach index 0.
- moving 1 unit to the left to reach index 0.
The shortest distance to reach "hello" is 1.
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre><strong>Input:</strong> words = ["a","b","leetcode"], target = "leetcode", startIndex = 0
<strong>Output:</strong> 1
<strong>Explanation:</strong> We start from index 0 and can reach "leetcode" by
- moving 2 units to the right to reach index 2.
- moving 1 unit to the left to reach index 2.
The shortest distance to reach "leetcode" is 1.</pre>

<p><strong class="example">Example 3:</strong></p>

<pre><strong>Input:</strong> words = ["i","eat","leetcode"], target = "ate", startIndex = 0
<strong>Output:</strong> -1
<strong>Explanation:</strong> Since "ate" does not exist in <code>words</code>, we return -1.
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= words.length &lt;= 100</code></li>
	<li><code>1 &lt;= words[i].length &lt;= 100</code></li>
	<li><code>words[i]</code> and <code>target</code> consist of only lowercase English letters.</li>
	<li><code>0 &lt;= startIndex &lt; words.length</code></li>
</ul>

2515. Кратчайшее расстояние до целевой строки в циклическом массиве
Легко
<p>Вам дан циклический массив строк с индексом <strong>words</code> и строка <code>target</code>. <strong>Циклический массив</strong> означает, что конец массива соединяется с его началом.</p>

<ul>

<li>Формально, следующий элемент <code>words[i]</code> — это <code>words[(i + 1) % n]</code>, а предыдущий элемент <code>words[i]</code> — это <code>words[(i - 1 + n) % n]</code>, где <code>n</code> — длина <code>words</code>.</li>
</ul>

<p>Начиная с <code>startIndex</code>, вы можете переходить либо к следующему слову, либо к предыдущему слову с шагом <code>1</code> за раз.</p>

<p>Возвращает <em>кратчайшее</strong> расстояние, необходимое для достижения строки</em> <code>target</code>. Если строка <code>target</code> не существует в <code>words</code>, верните <code>-1</code>.</p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<pre><strong>Входные данные:</strong> words = ["hello","i","am","leetcode","hello"], target = "hello", startIndex = 1
<strong>Выходные данные:</strong> 1
<strong>Пояснение:</strong> Мы начинаем с индекса 1 и можем достичь "hello",
- переместившись на 3 единицы вправо, чтобы достичь индекса 4.
- переместившись на 2 единицы влево, чтобы достичь индекса 4.
- переместившись на 4 единицы вправо, чтобы достичь индекса 0.
- переместившись на 1 единицу влево, чтобы достичь индекса 0.
Кратчайшее расстояние до "hello" равно 1.
</pre>

<p><strong Пример 2:

Ввод: слова = ["a","b","leetcode", цель = "leetcode", начальный индекс = 0
Вывод: 1
Пояснение: Мы начинаем с индекса 0 и можем достичь "leetcode",
- переместившись на 2 единицы вправо, чтобы достичь индекса 2.
- переместившись на 1 единицу влево, чтобы достичь индекса 2.
Кратчайшее расстояние до "leetcode" равно 1.

Пример 3:

Ввод: слова = ["i","eat","leetcode", цель = "ate", начальный индекс = 0
Вывод: -1
Пояснение: Поскольку "ate" не существует в <code>words</code>, мы возвращаем -1.

</pre>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>1 <= words.length <= 100</code></li>

<li><code>1 <= words[i].length <= 100</code></li>

<li><code>words[i]</code> и <code>target</code> состоят только из строчных английских букв.</li>

<li><code>0 <= startIndex < words.length</code></li>
</ul>
