1674. Minimum Moves to Make Array Complementary

Medium
<p>You are given an integer array <code>nums</code> of <strong>even</strong> length <code>n</code> and an integer <code>limit</code>. In one move, you can replace any integer from <code>nums</code> with another integer between <code>1</code> and <code>limit</code>, inclusive.</p>

<p>The array <code>nums</code> is <strong>complementary</strong> if for all indices <code>i</code> (<strong>0-indexed</strong>), <code>nums[i] + nums[n - 1 - i]</code> equals the same number. For example, the array <code>[1,2,3,4]</code> is complementary because for all indices <code>i</code>, <code>nums[i] + nums[n - 1 - i] = 5</code>.</p>

<p>Return the <em><strong>minimum</strong> number of moves required to make </em><code>nums</code><em> <strong>complementary</strong></em>.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<pre><strong>Input:</strong> nums = [1,2,4,3], limit = 4
<strong>Output:</strong> 1
<strong>Explanation:</strong> In 1 move, you can change nums to [1,2,<u>2</u>,3] (underlined elements are changed).
nums[0] + nums[3] = 1 + 3 = 4.
nums[1] + nums[2] = 2 + 2 = 4.
nums[2] + nums[1] = 2 + 2 = 4.
nums[3] + nums[0] = 3 + 1 = 4.
Therefore, nums[i] + nums[n-1-i] = 4 for every i, so nums is complementary.
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre><strong>Input:</strong> nums = [1,2,2,1], limit = 2
<strong>Output:</strong> 2
<strong>Explanation:</strong> In 2 moves, you can change nums to [<u>2</u>,2,2,<u>2</u>]. You cannot change any number to 3 since 3 &gt; limit.
</pre>

<p><strong class="example">Example 3:</strong></p>

<pre><strong>Input:</strong> nums = [1,2,1,2], limit = 2
<strong>Output:</strong> 0
<strong>Explanation:</strong> nums is already complementary.
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>n == nums.length</code></li>
	<li><code>2 &lt;= n&nbsp;&lt;=&nbsp;10<sup>5</sup></code></li>
	<li><code>1 &lt;= nums[i]&nbsp;&lt;= limit &lt;=&nbsp;10<sup>5</sup></code></li>
	<li><code>n</code> is even.</li>
</ul>

1674. Мінімальна кількість ходів для створення додаткового масиву

Середній
<p>Вам задано цілочисельний масив <code>nums</code> <strong>парної</strong> довжини <code>n</code> та ціле число <code>limit</code>. За один хід ви можете замінити будь-яке ціле число з <code>nums</code> іншим цілим числом від <code>1</code> до <code>limit</code> включно.</p>

<p>Масив <code>nums</code> є <strong>додатковим</strong>, якщо для всіх індексів <code>i</code> (<strong>0-індексованих</strong>), <code>nums[i] + nums[n - 1 - i]</code> дорівнює одному й тому ж числу. Наприклад, масив <code>[1,2,3,4]</code> є додатковим, оскільки для всіх індексів <code>i</code>, <code>nums[i] + nums[n - 1 - i] = 5</code>.</p>

<p>Повертає <em><strong>мінімальну</strong> кількість ходів, необхідних для виконання </em><code>nums</code><em> <strong>додаткових</strong></em>.</p>

<p>&nbsp;</p>
<p><strong class="example">Приклад 1:</strong></p>

<pre><strong>Вхід:</strong> nums = [1,2,4,3], limit = 4
<strong>Вихід:</strong> 1
<strong>Пояснення:</strong> За 1 хід ви можете змінити nums на [1,2,<u>2</u>,3] (підкреслені елементи змінюються).

nums[0] + nums[3] = 1 + 3 = 4.
nums[1] + nums[2] = 2 + 2 = 4.
nums[2] + nums[1] = 2 + 2 = 4.
nums[3] + nums[0] = 3 + 1 = 4.
Отже, nums[i] + nums[n-1-i] = 4 для кожного i, отже, nums є додатковим.
</pre>

<p><strong class="example">Приклад 2:</strong></p>

<pre><strong>Вхід:</strong> nums = [1,2,2,1], ліміт = 2
<strong>Вихід:</strong> 2
<strong>Пояснення:</strong> За 2 ходи ви можете змінити nums на [<u>2</u>,2,2,<u>2</u>]. Ви не можете змінити жодне число на 3, оскільки 3 > ліміт.
</pre>

<p><strong class="example">Приклад 3:</strong></p>

<pre><strong>Вхід:</strong> nums = [1,2,1,2], ліміт = 2
<strong>Вихід:</strong> 0
<strong>Пояснення:</strong> nums вже є додатковим.
</pre>

<p>&nbsp;</p>
<p><strong>Обмеження:</strong></p>

<ul>
<li><code>n == nums.length</code></li>
<li><code>2 &lt;= n&nbsp;&lt;=&nbsp;10<sup>5</sup></code></li>
<li><code>1 &lt;= nums[i]&nbsp;&lt;= limit &lt;=&nbsp;10<sup>5</sup></code></li>
<li><code>n</code> парне.</li>
</ul>

## Пояснення рішення

### Ключова ідея

Масив `nums` довжини `n` є **комплементарним**, якщо для всіх `i`: `nums[i] + nums[n-1-i] = T`, де `T` — одне й те саме число.

Завдання: знайти **мінімальну кількість замін** елементів (кожен елемент можна замінити на число від `1` до `limit`), щоб зробити масив комплементарним.

### Підхід: Difference Array (масив різниць)

Перебирати кожне можливе значення `T` від `2` до `2*limit` і для кожного рахувати кількість ходів — це було б `O(n * limit)`, що занадто повільно. Замість цього використовуємо **техніку масиву різниць** для ефективного оновлення діапазонів.

### Аналіз для однієї пари (a, b)

Для пари `(a, b)` де `a = nums[i]`, `b = nums[n-1-i]`, кількість ходів залежить від цільової суми `T`:

| Діапазон T | Кількість ходів | Пояснення |
|---|---|---|
| `[2, min(a,b)]` | **2 ходи** | Обидва елементи потрібно змінити, бо навіть мінімальний замінений на 1 дає суму > T |
| `[min(a,b)+1, a+b-1]` | **1 хід** | Достатньо змінити один елемент |
| `a + b` | **0 ходів** | Сума вже дорівнює T |
| `[a+b+1, max(a,b)+limit]` | **1 хід** | Достатньо змінити один елемент |
| `[max(a,b)+limit+1, 2*limit]` | **2 ходи** | Обидва елементи потрібно змінити |

### Як працює масив різниць

1. **Базовий рівень**: Вважаємо, що для кожної пари потрібно **2 ходи** для будь-якого `T`. Тобто базова вартість = `n` (бо `n/2` пар × 2 ходи).

2. **Зменшення на 1** для діапазону `[min(a,b)+1, max(a,b)+limit]` — тут достатньо лише 1 ходу.

3. **Зменшення ще на 1** для точки `T = a + b` — тут 0 ходів.

Ці оновлення записуються в масив різниць:
```
diff[min(a,b) + 1]        -= 1   // початок діапазону "1 хід"
diff[max(a,b) + limit + 1] += 1  // кінець діапазону "1 хід"
diff[a + b]                -= 1   // точка "0 ходів"
diff[a + b + 1]            += 1   // кінець точки "0 ходів"
```

4. Після обробки всіх пар проходимо по масиву різниць, обчислюючи **префіксну суму** — це дає фактичну кількість ходів для кожного `T`. Мінімум з них — відповідь.

### Покроковий розбір коду

```javascript
const diff = new Array(2 * limit + 2).fill(0);
```
Створюємо масив різниць розміром `2*limit + 2` (щоб уникнути виходу за межі).

```javascript
for (let i = 0; i < n / 2; i++) {
    const a = nums[i];
    const b = nums[n - 1 - i];
```
Перебираємо кожну пару елементів.

```javascript
    diff[Math.min(a, b) + 1] -= 1;
    diff[Math.max(a, b) + limit + 1] += 1;
```
Відзначаємо діапазон де потрібен максимум 1 хід замість 2.

```javascript
    diff[a + b] -= 1;
    diff[a + b + 1] += 1;
```
Відзначаємо точку де потрібно 0 ходів замість 1.

```javascript
let result = n;
let currentMoves = n;
for (let T = 2; T <= 2 * limit; T++) {
    currentMoves += diff[T];
    result = Math.min(result, currentMoves);
}
```
Обчислюємо префіксну суму для отримання реальних значень і знаходимо мінімум.

### Приклад роботи

Для `nums = [1,2,4,3], limit = 4`:
- Пара (1, 3): `a+b = 4`, діапазон 1 ходу: `[2, 7]`, 0 ходів при `T=4`
- Пара (2, 4): `a+b = 6`, діапазон 1 ходу: `[3, 8]`, 0 ходів при `T=6`
- При `T=4`: пара (1,3) → 0 ходів, пара (2,4) → 1 хід = **1 хід** ✓

### Складність

- **Час**: `O(n + limit)` — один прохід по парах + один прохід по можливих сумах
- **Пам'ять**: `O(limit)` — масив різниць
