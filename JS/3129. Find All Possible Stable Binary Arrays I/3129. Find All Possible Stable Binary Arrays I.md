### Ідея розв’язку
Ми маємо побудувати всі можливі бінарні масиви, які:
- містять рівно `zero` нулів і `one` одиниць;
- будь-який підмасив довжини більшої за `limit` повинен містити і `0`, і `1`.

Це класична задача на **динамічне програмування**.  
Ми можемо визначити `dp[i][j][last]`, де:
- `i` — кількість використаних нулів,
- `j` — кількість використаних одиниць,
- `last` — останній символ (0 або 1),
- і ще треба враховувати, скільки поспіль однакових елементів ми вже поставили.

Тобто стан буде `dp[i][j][last][count]`, де `count` ≤ `limit`.  
Перехід: додаємо новий елемент, якщо не перевищуємо `limit`.

### Код з коментарями українською
```javascript
/**
 * @param {number} zero
 * @param {number} one
 * @param {number} limit
 * @return {number}
 */
var numberOfStableArrays = function(zero, one, limit) {
    const MOD = 1e9 + 7;

    // dp[i][j][last][count] – кількість способів побудувати масив
    // з i нулями та j одиницями, де останній елемент = last,
    // і count – скільки разів поспіль він повторюється.
    let dp = Array.from({length: zero+1}, () =>
        Array.from({length: one+1}, () =>
            [Array(limit+1).fill(0), Array(limit+1).fill(0)]
        )
    );

    // Початкові стани: можемо почати з одного нуля або однієї одиниці
    if (zero > 0) dp[1][0][0][1] = 1;
    if (one > 0) dp[0][1][1][1] = 1;

    for (let i = 0; i <= zero; i++) {
        for (let j = 0; j <= one; j++) {
            for (let last = 0; last <= 1; last++) {
                for (let c = 1; c <= limit; c++) {
                    let val = dp[i][j][last][c];
                    if (!val) continue;

                    // Якщо останній був 0, можемо додати ще один 0
                    if (last === 0 && i < zero && c < limit) {
                        dp[i+1][j][0][c+1] = (dp[i+1][j][0][c+1] + val) % MOD;
                    }
                    // Якщо останній був 0, можемо додати 1
                    if (last === 0 && j < one) {
                        dp[i][j+1][1][1] = (dp[i][j+1][1][1] + val) % MOD;
                    }
                    // Якщо останній був 1, можемо додати ще один 1
                    if (last === 1 && j < one && c < limit) {
                        dp[i][j+1][1][c+1] = (dp[i][j+1][1][c+1] + val) % MOD;
                    }
                    // Якщо останній був 1, можемо додати 0
                    if (last === 1 && i < zero) {
                        dp[i+1][j][0][1] = (dp[i+1][j][0][1] + val) % MOD;
                    }
                }
            }
        }
    }

    // Підрахунок усіх можливих варіантів
    let result = 0;
    for (let last = 0; last <= 1; last++) {
        for (let c = 1; c <= limit; c++) {
            result = (result + dp[zero][one][last][c]) % MOD;
        }
    }

    return result;
};
```

### Пояснення:
- Ми будуємо масив поступово, додаючи `0` або `1`.
- Обмеження `limit` гарантує, що не буде підмасиву довший за `limit` з однакових елементів.

## Детальні умови завдання

Тобі потрібно створити масив із нулів та одиниць, який відповідає трьом критеріям:

## Що таке `Array.from()`?

Цей метод створює новий масив із об'єкта, який схожий на масив або який можна перебрати.

### Синтаксис:

```javascript
Array.from(arrayLike, mapFunction)

```

1. **`arrayLike`**: Об'єкт, у якого є властивість `.length`. Наприклад, `{length: 5}` — це об'єкт, який каже JavaScript: "вдай, що в тебе є 5 елементів".
2. **`mapFunction` (необов'язково)**: Функція, яка заповнює кожен елемент масиву. Це зручніше, ніж просто створити порожній масив, а потім запускати цикл `for`.

**Приклад:**

```javascript
let simple = Array.from({length: 3}, () => 0); 
// Результат: [0, 0, 0]

```

## Покроковий розбір твого коду

Твоя конструкція створює 4-вимірну структуру даних для DP:

### 1. Зовнішній шар (Нулі)

```javascript
let dp = Array.from({length: zero+1}, () => ... );

```

Ми створюємо масив довжиною `zero + 1`. Це буде наш "перший вимір" (кількість використаних нулів). Для кожного елемента цього масиву ми викликаємо функцію, яка створює...

### 2. Другий шар (Одиниці)

```javascript
Array.from({length: one+1}, () => ... );

```

...ще один масив довжиною `one + 1`. Тепер у нас є сітка (матриця) `[zero+1] x [one+1]`.

### 3. Третій та четвертий шари (Остання цифра та ліміт)

```javascript
[Array(limit+1).fill(0), Array(limit+1).fill(0)]

```

Це найцікавіше місце. Замість ще одного `Array.from`, тут використовується звичайний літерал масиву `[]`, який містить два вкладених масиви:

* `Array(limit+1).fill(0)` для випадку, коли остання цифра — **0**.
* `Array(limit+1).fill(0)` для випадку, коли остання цифра — **1**.

Метод `.fill(0)` заповнює ці масиви нулями, щоб ми могли одразу виконувати арифметичні операції (`+ val`).

## Чому не можна просто написати `new Array().fill([])`?

Це найпоширеніша помилка новачків. Якби ти написав так:

```javascript
let wrongDp = new Array(3).fill([0, 0]);

```

То JavaScript створив би **один** масив `[0, 0]` у пам'яті та поклав би **посилання** на нього в усі комірки. Змінивши `wrongDp[0][0]`, ти б автоматично змінив і `wrongDp[1][0]`, і `wrongDp[2][0]`.

**Перевага `Array.from`:**
Він викликає функцію створення нового масиву на кожній ітерації. Тому кожна комірка отримує свій **унікальний** об'єкт у пам'яті.

## Візуалізація структури:

Якщо `zero=1, one=1, limit=1`, структура виглядатиме так:

```javascript
[
  [ // i=0 (нулів використано)
    [[0,0], [0,0]], // j=0 (одиниць використано) -> [останній 0][ліміт], [останній 1][ліміт]
    [[0,0], [0,0]]  // j=1
  ],
  [ // i=1
    [[0,0], [0,0]], // j=0
    [[0,0], [0,0]]  // j=1
  ]
]

```

Це дозволяє звертатися до даних максимально зручно для алгоритму:
`dp[нулі][одиниці][остання_цифра][ліміт_повторів]`

Чи хотів би ти побачити, як переписати це створення через звичайні цикли `for`, щоб порівняти швидкість або читабельність?
