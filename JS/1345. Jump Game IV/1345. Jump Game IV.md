1345. Jump Game IV

Hard

<p>Given an array of&nbsp;integers <code>arr</code>, you are initially positioned at the first index of the array.</p>

<p>In one step you can jump from index <code>i</code> to index:</p>

<ul>
	<li><code>i + 1</code> where:&nbsp;<code>i + 1 &lt; arr.length</code>.</li>
	<li><code>i - 1</code> where:&nbsp;<code>i - 1 &gt;= 0</code>.</li>
	<li><code>j</code> where: <code>arr[i] == arr[j]</code> and <code>i != j</code>.</li>
</ul>

<p>Return <em>the minimum number of steps</em> to reach the <strong>last index</strong> of the array.</p>

<p>Notice that you can not jump outside of the array at any time.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<pre><strong>Input:</strong> arr = [100,-23,-23,404,100,23,23,23,3,404]
<strong>Output:</strong> 3
<strong>Explanation:</strong> You need three jumps from index 0 --&gt; 4 --&gt; 3 --&gt; 9. Note that index 9 is the last index of the array.
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre><strong>Input:</strong> arr = [7]
<strong>Output:</strong> 0
<strong>Explanation:</strong> Start index is the last index. You do not need to jump.
</pre>

<p><strong class="example">Example 3:</strong></p>

<pre><strong>Input:</strong> arr = [7,6,9,6,9,6,9,7]
<strong>Output:</strong> 1
<strong>Explanation:</strong> You can jump directly from index 0 to index 7 which is last index of the array.
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= arr.length &lt;= 5 * 10<sup>4</sup></code></li>
	<li><code>-10<sup>8</sup> &lt;= arr[i] &lt;= 10<sup>8</sup></code></li>
</ul>

1345. Игра на прыжок IV

Сложно

<p>Дано множество целых чисел <code>arr</code>, вы изначально находитесь на первом индексе массива.</p>

<p>За один шаг вы можете перепрыгнуть с индекса <code>i</code> на индекс:</p>

<ul>

<li><code>i + 1</code> где:<code>i + 1</code> arr.length</code>.</li>

<li><code>i - 1</code> где:<code>i - 1 >= 0</code>.</li>

<li><code>j</code> где: <code>arr[i] == arr[j]</code> и <code>i != j</code>.</li>
</ul>

<p>Возвращает <em>минимальное количество шагов</em> для достижения <strong>последнего индекса</strong> массива.</p>

<p>Обратите внимание, что вы не можете выйти за пределы массива ни в какой момент.</p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<pre><strong>Входные данные:</strong> arr = [100,-23,-23,404,100,23,23,23,3,404]
<strong>Вывод:</strong> 3
<strong>Пояснение:</strong> Вам нужно три перехода от индекса 0 -->4 -->3 -->9. Обратите внимание, что индекс 9 — последний индекс массива.

</pre>

<p><strong class="example">Пример 2:</strong></p>

<pre><strong>Вход:</strong> arr = [7]
<strong>Вывод:</strong> 0
<strong>Пояснение:</strong> Начальный индекс — последний индекс. Переход не требуется.

</pre>

<p><strong class="example">Пример 3:</strong></p>

<pre><strong>Входные данные:</strong> arr = [7,6,9,6,9,6,9,7]
<strong>Выходные данные:</strong> 1
<strong>Пояснение:</strong> Вы можете перейти непосредственно с индекса 0 к индексу 7, который является последним индексом массива.

</pre>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>1 <= arr.length <= 5 * 10<sup>4</sup>></code></li>
<li><code>-10<sup>8</sup> <= arr[i] <= 10<sup>8</sup>></code></li>
</ul>

## Пояснення

### Суть задачі

Ми стоїмо на індексі `0` масиву `arr` і хочемо дістатися до останнього індексу `n - 1` за мінімальну кількість кроків. З кожного індексу `i` доступні три типи переходів:

1. **i + 1** — крок вправо
2. **i - 1** — крок вліво
3. **j** — телепортація до будь-якого індексу `j`, де `arr[i] === arr[j]`

### Чому BFS?

Задача зводиться до пошуку **найкоротшого шляху** в незваженому графі. Вершини — це індекси масиву, ребра — допустимі переходи. BFS гарантує, що перший раз, коли ми досягнемо вершини, це буде через найкоротший шлях.

### Ключова оптимізація

Наївний BFS дасть **TLE**, бо для кожного індексу ми можемо мати до `n` сусідів з однаковим значенням. Якщо ми обходимо одну й ту саму групу багато разів — складність зросте до O(n²).

**Розв'язок:** після того як ми додали всіх сусідів за значенням у чергу, ми **видаляємо цю групу з Map** (`graph.delete(arr[i])`). Це безпечно, бо всі ці індекси вже відвідані і знову обходити їх не потрібно. В результаті кожен індекс обробляється рівно один раз, і загальна складність залишається **O(n)**.

### Покрокове пояснення коду

```javascript
var minJumps = function(arr) {
```
- Оголошуємо основну функцію, що приймає масив `arr`.

```javascript
    const n = arr.length;
    if (n === 1) return 0;
```
- Зберігаємо довжину масиву. Якщо масив з одного елемента — ми вже на місці, 0 кроків.

```javascript
    const graph = new Map();
    for (let i = 0; i < n; i++) {
        if (!graph.has(arr[i])) graph.set(arr[i], []);
        graph.get(arr[i]).push(i);
    }
```
- Будуємо словник `graph`: для кожного значення зберігаємо список усіх індексів, де це значення зустрічається. Це дозволяє за O(1) знайти всі індекси для телепортації.

```javascript
    const visited = new Array(n).fill(false);
    const queue = [0];
    visited[0] = true;
    let steps = 0;
```
- `visited` — масив булевих значень, щоб не обходити один індекс двічі.
- `queue` — черга BFS, починаємо з індексу 0.
- `steps` — лічильник кроків (рівнів BFS).

```javascript
    while (queue.length > 0) {
        const size = queue.length;
        const nextQueue = [];
```
- Зовнішній цикл — рівень BFS. `size` фіксує кількість елементів поточного рівня. `nextQueue` збирає елементи наступного рівня.

```javascript
        for (let q = 0; q < size; q++) {
            const i = queue[q];
            if (i === n - 1) return steps;
```
- Обходимо всі вершини поточного рівня. Якщо ми досягли останнього індексу — повертаємо кількість кроків.

```javascript
            if (graph.has(arr[i])) {
                for (const j of graph.get(arr[i])) {
                    if (!visited[j]) {
                        visited[j] = true;
                        nextQueue.push(j);
                    }
                }
                graph.delete(arr[i]);
            }
```
- **Телепортація:** обходимо всі індекси з тим самим значенням. Кожен невідвіданий — додаємо в чергу.
- `graph.delete(arr[i])` — **ключова оптимізація**: видаляємо групу після обробки, бо всі її елементи вже відвідані. Без цього кроку алгоритм отримає TLE на масивах з великою кількістю однакових елементів.

```javascript
            if (i + 1 < n && !visited[i + 1]) {
                visited[i + 1] = true;
                nextQueue.push(i + 1);
            }

            if (i - 1 >= 0 && !visited[i - 1]) {
                visited[i - 1] = true;
                nextQueue.push(i - 1);
            }
```
- Додаємо сусідів `i + 1` та `i - 1`, якщо вони в межах масиву і ще не відвідані.

```javascript
        queue.length = 0;
        queue.push(...nextQueue);
        steps++;
    }
```
- Замінюємо поточну чергу на чергу наступного рівня та збільшуємо лічильник кроків.

```javascript
    return -1;
};
```
- Якщо BFS завершився без досягнення кінця — повертаємо -1 (теоретично недосяжний випадок за умовами задачі, бо `i+1` гарантує зв'язність).

### Приклад роботи

Для `arr = [100, -23, -23, 404, 100, 23, 23, 23, 3, 404]`:

| Крок | Черга | Дія |
|------|-------|-----|
| 0 | [0] | Індекс 0, значення 100. Телепортація → {4}. Сусіди → {1} |
| 1 | [4, 1] | Індекс 4: сусіди → {3, 5}. Індекс 1, значення -23: телепортація → {2}. Сусіди → {} |
| 2 | [3, 5, 2] | Індекс 3, значення 404: телепортація → {9}. **9 = n-1** → відповідь! |

Результат: **3 кроки** (0 → 4 → 3 → 9).

### Складність

- **Часова:** O(n) — кожен індекс додається в чергу максимум один раз, і кожна група значень обходиться рівно один раз завдяки `graph.delete`.
- **Просторова:** O(n) — Map зберігає n індексів, масив `visited` — n елементів, черга — до n елементів.
Суть задачі — три типи переходів (вправо, вліво, телепортація)
Чому BFS — найкоротший шлях у незваженому графі
Ключова оптимізація — graph.delete() після обробки групи однакових значень, щоб уникнути TLE
