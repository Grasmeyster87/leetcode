3761. Minimum Absolute Distance Between Mirror Pairs

Medium

<p>You are given an integer array <code>nums</code>.</p>

<p>A <strong>mirror pair</strong> is a pair of indices <code>(i, j)</code> such that:</p>

<ul>
	<li><code>0 &lt;= i &lt; j &lt; nums.length</code>, and</li>
	<li><code>reverse(nums[i]) == nums[j]</code>, where <code>reverse(x)</code> denotes the integer formed by reversing the digits of <code>x</code>. Leading zeros are omitted after reversing, for example <code>reverse(120) = 21</code>.</li>
</ul>

<p>Return the <strong>minimum</strong> absolute distance between the indices of any mirror pair. The absolute distance between indices <code>i</code> and <code>j</code> is <code>abs(i - j)</code>.</p>

<p>If no mirror pair exists, return <code>-1</code>.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums = [12,21,45,33,54]</span></p>

<p><strong>Output:</strong> <span class="example-io">1</span></p>

<p><strong>Explanation:</strong></p>

<p>The mirror pairs are:</p>

<ul>
	<li>(0, 1) since <code>reverse(nums[0]) = reverse(12) = 21 = nums[1]</code>, giving an absolute distance <code>abs(0 - 1) = 1</code>.</li>
	<li>(2, 4) since <code>reverse(nums[2]) = reverse(45) = 54 = nums[4]</code>, giving an absolute distance <code>abs(2 - 4) = 2</code>.</li>
</ul>

<p>The minimum absolute distance among all pairs is 1.</p>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums = [120,21]</span></p>

<p><strong>Output:</strong> <span class="example-io">1</span></p>

<p><strong>Explanation:</strong></p>

<p>There is only one mirror pair (0, 1) since <code>reverse(nums[0]) = reverse(120) = 21 = nums[1]</code>.</p>

<p>The minimum absolute distance is 1.</p>
</div>

<p><strong class="example">Example 3:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums = [21,120]</span></p>

<p><strong>Output:</strong> <span class="example-io">-1</span></p>

<p><strong>Explanation:</strong></p>

<p>There are no mirror pairs in the array.</p>
</div>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= nums.length &lt;= 10<sup>5</sup></code></li>
	<li><code>1 &lt;= nums[i] &lt;= 10<sup>9</sup></code>​​​​​​​</li>
</ul>

3761. Минимальное абсолютное расстояние между зеркальными парами

Средний уровень сложности

<p>Вам дан целочисленный массив <code>nums</code>.</p>

<p>Зеркальная пара</strong> — это пара индексов <code>(i, j)</code> такая, что:</p>

<ul>

<li><code>0 <= i < j < nums.length</code>, и</li>

<li><code>reverse(nums[i]) == nums[j]</code>, где <code>reverse(x)</code> обозначает целое число, образованное путем перестановки цифр <code>x</code>. После перестановки ведущие нули опускаются, например, <code>reverse(120) = 21</code>.</li>
</ul>

<p>Возвращает <strong>минимальное</strong> абсолютное расстояние между индексами любой зеркальной пары. Абсолютное расстояние между индексами <code>i</code> и <code>j</code> равно <code>abs(i - j)</code>.</p>

<p>Если зеркальной пары не существует, вернуть <code>-1</code>.</p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<div class="example-block">
<p><strong>Входные данные:</strong> <span class="example-io">nums = [12,21,45,33,54]</span></p>

<p><strong>Выходные данные:</strong> <span class="example-io">1</span></p>

<p><strong>Пояснение:</strong></p>

<p>Зеркальные пары:</p>

<ul>

<li>(0, 1) так как <code>reverse(nums[0]) = reverse(12) = 21 = nums[1]</code>, что дает абсолютное расстояние <code>abs(0 - 1) = 1</code>.</li>

<li>(2, 4), поскольку <code>reverse(nums[2]) = reverse(45) = 54 = nums[4]</code>, что дает абсолютное расстояние <code>abs(2 - 4) = 2</code>.</li>
</ul>

<p>Минимальное абсолютное расстояние между всеми парами равно 1.</p>
</div>

<p><strong class="example">Пример 2:</strong></p>

<div class="example-block">
<p><strong>Входные данные:</strong> <span class="example-io">nums = [120,21]</span></p>

<p><strong>Выходные данные:</strong> <span class="example-io">1</span></p>

<p><strong>Пояснение:</strong></p>

<p>Существует только одна зеркальная пара (0, 1), поскольку <code>reverse(nums[0]) = reverse(120) = 21 = nums[1]</code>.</p>

<p>Минимальное абсолютное расстояние равно 1.</p>
</div>

<p><strong class="example">Пример 3:</strong></p>

<div class="example-block">
<p><strong>Входные данные:</strong> <span class="example-io">nums = [21,120]</span></p>

<p><strong>Выходные данные:</strong> <span class="example-io">-1</span></p>

<p><strong>Пояснение:</strong></p>

<p>Существует В массиве нет зеркальных пар.</p>
</div>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>1 <= nums.length <= 10<sup>5</sup></code></li>
<li><code>1 <= nums[i] <= 10<sup>9</sup></code>​​​​​​​</li>
</ul>

Вот оптимальное решение для этой задачи с временной сложностью $O(N)$ и пространственной сложностью $O(N)$.

### Подход к решению

Для поиска минимального расстояния мы можем использовать хеш-таблицу (в JavaScript — `Map`). Проходя по массиву слева направо (индекс `j`), мы будем выполнять два шага:

1. **Проверка совпадения:** Проверять, встречали ли мы ранее число, которое при перевороте (реверсе) дает текущее значение `nums[j]`. Если да, мы вычисляем расстояние между текущим индексом `j` и сохраненным индексом `i`, обновляя минимальное расстояние, если оно меньше найденного ранее.
2. **Сохранение для будущих пар:** Вычислять перевернутое значение текущего числа `reverse(nums[j])` и сохранять его в `Map` вместе с текущим индексом `j`. 

Если одно и то же перевернутое значение встречается несколько раз, перезапись значения в `Map` текущим индексом автоматически гарантирует, что мы сохраняем самый **поздний** (ближайший) индекс, что и требуется для минимизации `abs(i - j)`.

### Код на JavaScript

```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
var minMirrorPairDistance = function(nums) {
    const seenReversed = new Map();
    let minDistance = Infinity;

    for (let j = 0; j < nums.length; j++) {
        const num = nums[j];
        
        // 1. Проверяем, может ли текущее число образовать зеркальную пару 
        // с каким-либо из предыдущих чисел
        if (seenReversed.has(num)) {
            const i = seenReversed.get(num);
            const distance = j - i;
            if (distance < minDistance) {
                minDistance = distance;
            }
        }
        
        // 2. Переворачиваем текущее число математическим путем (это быстрее, чем через строки)
        let n = num;
        let rev = 0;
        while (n > 0) {
            rev = rev * 10 + (n % 10);
            n = Math.floor(n / 10);
        }
        
        // Сохраняем или обновляем индекс перевернутого числа.
        // Перезапись гарантирует, что мы храним самый свежий индекс, 
        // минимизируя расстояние для будущих совпадений.
        seenReversed.set(rev, j);
    }

    return minDistance === Infinity ? -1 : minDistance;
};
```

### Анализ сложности

* **Временная сложность:** $O(N \log_{10} M)$, где $N$ — длина массива `nums`, а $M$ — максимальное значение в массиве (до $10^9$). Математический реверс занимает количество операций, пропорциональное количеству цифр (максимум 10 итераций). Поиск и вставка в `Map` работают за $O(1)$. Таким образом, алгоритм фактически работает за линейное время $O(N)$.
* **Пространственная сложность:** $O(N)$. В худшем случае, когда все числа уникальны, хеш-таблица `seenReversed` будет хранить до $N$ пар ключ-значение.

Этот фрагмент кода — классический и очень эффективный алгоритм для **математического переворота числа**. Он работает значительно быстрее, чем перевод числа в строку, переворот строки и обратный перевод в число, так как не выделяет лишней памяти.

Давайте разберем, как он работает, по строкам:

* **`n % 10` (Остаток от деления на 10):** Эта операция всегда "откусывает" **последнюю цифру** числа. Например, `123 % 10` даст `3`.
* **`rev * 10`:** Это действие **сдвигает** уже собранное число на один разряд влево (добавляет ноль на конце), чтобы освободить место для новой цифры. Например, если у нас уже было собрано `3`, то `3 * 10` сделает из него `30`.
* **`Math.floor(n / 10)`:** Это действие **удаляет последнюю цифру** из исходного числа. Мы делим на 10 (получается `12.3`) и округляем вниз (`Math.floor`), чтобы получить целое число `12`.

### Пошаговый пример (Трассировка)

Давайте посмотрим, как это работает на практике. Допустим, наше исходное число **`n = 123`**, а переменная для перевернутого числа изначально равна нулю: **`rev = 0`**.

Условие цикла `while (n > 0)` означает, что мы будем повторять процесс, пока от числа `n` хоть что-то останется.

**Шаг 1 (Первая итерация):**
* Сейчас `n = 123`.
* Достаем последнюю цифру: `123 % 10` = **`3`**.
* Обновляем `rev`: берем старый `rev` (0), умножаем на 10 (будет 0) и прибавляем 3. Теперь **`rev = 3`**.
* Обрезаем `n`: `Math.floor(123 / 10)` = **`12`**.

**Шаг 2 (Вторая итерация):**
* Сейчас `n = 12` (оно больше 0, продолжаем).
* Достаем последнюю цифру: `12 % 10` = **`2`**.
* Обновляем `rev`: берем старый `rev` (3), сдвигаем влево `3 * 10 = 30` и прибавляем новую цифру 2. Теперь **`rev = 32`**.
* Обрезаем `n`: `Math.floor(12 / 10)` = **`1`**.

**Шаг 3 (Третья итерация):**
* Сейчас `n = 1` (оно больше 0, продолжаем).
* Достаем последнюю цифру: `1 % 10` = **`1`**.
* Обновляем `rev`: берем старый `rev` (32), сдвигаем влево `32 * 10 = 320` и прибавляем новую цифру 1. Теперь **`rev = 321`**.
* Обрезаем `n`: `Math.floor(1 / 10)` = **`0`**.

**Завершение:**
* Сейчас `n = 0`. Условие `while (n > 0)` больше не выполняется.
* Цикл останавливается, и в переменной `rev` хранится готовый результат: **`321`**.

**Бонус: Как обрабатываются нули на конце (например, `120`)?**
По условию задачи, `reverse(120) = 21`. Этот алгоритм справляется с этим автоматически:
На первом шаге `120 % 10` даст `0`. Переменная `rev` станет равна `0 * 10 + 0 = 0`. А уже на следующем шаге придет цифра `2`, и `rev` станет `0 * 10 + 2 = 2`. Таким образом, ведущие нули (которые были нулями на конце) просто исчезают, как и требуется в математике!
