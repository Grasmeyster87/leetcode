3548. Equal Sum Grid Partition II
Hard
<p>You are given an <code>m x n</code> matrix <code>grid</code> of positive integers. Your task is to determine if it is possible to make <strong>either one horizontal or one vertical cut</strong> on the grid such that:</p>

<ul>
	<li>Each of the two resulting sections formed by the cut is <strong>non-empty</strong>.</li>
	<li>The sum of elements in both sections is <b>equal</b>, or can be made equal by discounting <strong>at most</strong> one single cell in total (from either section).</li>
	<li>If a cell is discounted, the rest of the section must <strong>remain connected</strong>.</li>
</ul>

<p>Return <code>true</code> if such a partition exists; otherwise, return <code>false</code>.</p>

<p><strong>Note:</strong> A section is <strong>connected</strong> if every cell in it can be reached from any other cell by moving up, down, left, or right through other cells in the section.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">grid = [[1,4],[2,3]]</span></p>

<p><strong>Output:</strong> <span class="example-io">true</span></p>

<p><strong>Explanation:</strong></p>

<p><img alt="" style="height: 180px; width: 180px;" src="https://assets.leetcode.com/uploads/2025/03/30/lc.jpeg"></p>

<ul>
	<li>A horizontal cut after the first row gives sums <code>1 + 4 = 5</code> and <code>2 + 3 = 5</code>, which are equal. Thus, the answer is <code>true</code>.</li>
</ul>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">grid = [[1,2],[3,4]]</span></p>

<p><strong>Output:</strong> <span class="example-io">true</span></p>

<p><strong>Explanation:</strong></p>

<p><img alt="" style="height: 180px; width: 180px;" src="https://assets.leetcode.com/uploads/2025/04/01/chatgpt-image-apr-1-2025-at-05_28_12-pm.png"></p>

<ul>
	<li>A vertical cut after the first column gives sums <code>1 + 3 = 4</code> and <code>2 + 4 = 6</code>.</li>
	<li>By discounting 2 from the right section (<code>6 - 2 = 4</code>), both sections have equal sums and remain connected. Thus, the answer is <code>true</code>.</li>
</ul>
</div>

<p><strong class="example">Example 3:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">grid = [[1,2,4],[2,3,5]]</span></p>

<p><strong>Output:</strong> <span class="example-io">false</span></p>

<p><strong>Explanation:</strong></p>

<p><strong><img alt="" style="height: 180px; width: 180px;" src="https://assets.leetcode.com/uploads/2025/04/01/chatgpt-image-apr-2-2025-at-02_50_29-am.png"></strong></p>

<ul>
	<li>A horizontal cut after the first row gives <code>1 + 2 + 4 = 7</code> and <code>2 + 3 + 5 = 10</code>.</li>
	<li>By discounting 3 from the bottom section (<code>10 - 3 = 7</code>), both sections have equal sums, but they do not remain connected as it splits the bottom section into two parts (<code>[2]</code> and <code>[5]</code>). Thus, the answer is <code>false</code>.</li>
</ul>
</div>

<p><strong class="example">Example 4:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">grid = [[4,1,8],[3,2,6]]</span></p>

<p><strong>Output:</strong> <span class="example-io">false</span></p>

<p><strong>Explanation:</strong></p>

<p>No valid cut exists, so the answer is <code>false</code>.</p>
</div>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= m == grid.length &lt;= 10<sup>5</sup></code></li>
	<li><code>1 &lt;= n == grid[i].length &lt;= 10<sup>5</sup></code></li>
	<li><code>2 &lt;= m * n &lt;= 10<sup>5</sup></code></li>
	<li><code>1 &lt;= grid[i][j] &lt;= 10<sup>5</sup></code></li>
</ul>
</div>

3548. Разбиение сетки с равной суммой, часть II
Сложная задача
<p>Вам дана матрица <code>m x n</code> сетки из положительных целых чисел. Ваша задача — определить, возможно ли сделать <strong>один горизонтальный или один вертикальный разрез</strong> на сетке таким образом, чтобы:</p>

<ul>

<li>Каждый из двух результирующих разделов, образованных разрезом, был <strong>непустым</strong>.</li>

<li>Сумма элементов в обоих разделах <b>равна</b>, или может быть сделана равной путем исключения <strong>не более</strong> одной ячейки в общей сложности (из любого раздела).</li>

<li>Если ячейка исключена, остальная часть раздела должна <strong>оставаться соединенной</strong>.</li>
</ul>

<p>Верните <code>true</code>, если такое разбиение существует; В противном случае вернуть <code>false</code>.</p>

<p><strong>Примечание:</strong> Раздел считается <strong>связанным</strong>, если до каждой ячейки в нем можно добраться из любой другой ячейки, перемещаясь вверх, вниз, влево или вправо через другие ячейки в разделе.</p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<div class="example-block">
<p><strong>Ввод:</strong> <span class="example-io">grid = [[1,4],[2,3]]</span></p>

<p><strong>Вывод:</strong> <span class="example-io">true</span></p>

<p><strong>Пояснение:</strong></p>

<p><img alt="" style="height: 180px; width: 180px;" src="https://assets.leetcode.com/uploads/2025/03/30/lc.jpeg"></p>

<ul>

<li>Горизонтальный разрез после первой строки дает суммы <code>1 + 4 = 5</code> и <code>2 + 3 = 5</code>, которые равны. Таким образом, ответ — <code>истина</code>.</li>
</ul>
</div>

<p><strong class="example">Пример 2:</strong></p>

<div class="example-block">
<p><strong>Ввод:</strong> <span class="example-io">grid = [[1,2],[3,4]]</span></p>

<p><strong>Вывод:</strong> <span class="example-io">истина</span></p>

<p><strong>Пояснение:</strong></p>

<p><img alt="" style="height: 180px; width: 180px;" src="https://assets.leetcode.com/uploads/2025/04/01/chatgpt-image-apr-1-2025-at-05_28_12-pm.png"></p>

<ul>

<li>Вертикальный разрез после первого столбца дает суммы <code>1 + 3 = 4</code> и <code>2 + 4 = 6</code>.</li>

<li>Вычитая 2 из правого участка (<code>6 - 2 = 4</code>), оба участка имеют равные суммы и остаются соединенными. Таким образом, ответ — <code>истина</code>.</li>
</ul>
</div>

<p><strong class="example">Пример 3:</strong></p>

<div class="example-block">
<p><strong>Ввод:</strong> <span class="example-io">grid = [[1,2,4],[2,3,5]]</span></p>

<p><strong>Вывод:</strong> <span class="example-io">false</span></p>

<p><strong>Пояснение:</strong></p>

<p><strong><img alt="" style="height: 180px; width: 180px;" src="https://assets.leetcode.com/uploads/2025/04/01/chatgpt-image-apr-2-2025-at-02_50_29-am.png"></strong></p>

<ul>

<li>Горизонтальный разрез после первого ряда дает <code>1 + 2 + 4 = 7</code> и <code>2 + 3 + 5 = 10</code>.</li>

<li>Вычитая 3 из нижней части (<code>10 - 3 = 7</code>), обе части имеют равные суммы, но они не остаются соединенными, так как нижняя часть разделяется на две части (<code>[2]</code> и <code>[5]</code>). Таким образом, ответ — <code>ложь</code>.</li>
</ul>
</div>

<p><strong class="example">Пример 4:</strong></p>

<div class="example-block">
<p><strong>Входные данные:</strong> <span class="example-io">grid = [[4,1,8],[3,2,6]]</span></p>

<p><strong>Выходные данные:</strong> <span class="example-io">ложь</span></p>

<p><strong>Пояснение:</strong></p>

<p>Не существует допустимого разреза, поэтому ответ — <code>ложь</code>.</p>
</div>

<li><code>1 <= n == grid[i].length <= 10<sup>5</sup></code></li>

<li><code>2 <= m * n <= 10<sup>5</sup></code></li>
