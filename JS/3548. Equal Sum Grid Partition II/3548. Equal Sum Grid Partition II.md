3548. Equal Sum Grid Partition II
Hard
<p>You are given an <code>m x n</code> matrix <code>grid</code> of positive integers. Your task is to determine if it is possible to make <strong>either one horizontal or one vertical cut</strong> on the grid such that:</p>

<ul>
	<li>Each of the two resulting sections formed by the cut is <strong>non-empty</strong>.</li>
	<li>The sum of elements in both sections is <b>equal</b>, or can be made equal by discounting <strong>at most</strong> one single cell in total (from either section).</li>
	<li>If a cell is discounted, the rest of the section must <strong>remain connected</strong>.</li>
</ul>

<p>Return <code>true</code> if such a partition exists; otherwise, return <code>false</code>.</p>

<p><strong>Note:</strong> A section is <strong>connected</strong> if every cell in it can be reached from any other cell by moving up, down, left, or right through other cells in the section.</p>

<p><strong>Input:</strong> <span class="example-io">grid = [[1,4],[2,3]]</span></p>

<p><strong>Output:</strong> <span class="example-io">true</span></p>

<p><strong>Explanation:</strong></p>

<p><img alt="" style="height: 180px; width: 180px;" src="https://assets.leetcode.com/uploads/2025/03/30/lc.jpeg"></p>

<ul>
	<li>A horizontal cut after the first row gives sums <code>1 + 4 = 5</code> and <code>2 + 3 = 5</code>, which are equal. Thus, the answer is <code>true</code>.</li>
</ul>
</div>

Ця задача вимагає перевірки можливості поділу сітки на дві частини (горизонтальним або вертикальним розрізом) з однаковою сумою. Важливо врахувати правило "дисконтування" однієї клітинки: ми можемо видалити одне число, якщо це допоможе зрівняти суми, але тільки за умови, що частина сітки, з якої видалили число, залишиться зв'язною.

### Аналіз зв'язності прямокутника
Оскільки будь-який розріз (горизонтальний чи вертикальний) створює два нових прямокутники, нам потрібно знати, які клітинки можна видалити з прямокутника розміром $H \times W$, щоб він залишився зв'язним:
1. Якщо **$H > 1$ та $W > 1$**: можна видалити **будь-яку** клітинку. Завжди знайдеться шлях в обхід через сусідні рядки або стовпці.
2. Якщо **$H = 1$ та $W > 1$**: можна видалити тільки **крайні** клітинки (першу або останню в рядку). Видалення внутрішньої розірве рядок на дві частини.
3. Якщо **$H > 1$ та $W = 1$**: можна видалити тільки **крайні** клітинки (верхню або нижню).
4. Якщо **$H = 1$ та $W = 1$**: єдину клітинку можна видалити (залишиться порожня множина, яка вважається зв'язною).

### Алгоритм рішення
1. Обчислюємо загальну суму сітки, а також суми кожного рядка та стовпця.
2. Створюємо універсальну функцію `check`, яка перевіряє розрізи в одному напрямку (горизонтальному). Для вертикальних розрізів ми просто передамо в цю ж функцію "транспоновані" дані.
3. У функції `check` ми ітеруємося по кожному можливому розрізу:
   - Рахуємо суми двох частин ($S_1$ та $S_2$).
   - Якщо $S_1 = S_2$, повертаємо `true`.
   - Якщо $S_1 > S_2$, шукаємо число $v = S_1 - S_2$ у першій частині. Якщо воно є і його видалення не порушує зв'язність — повертаємо `true`.
   - Аналогічно перевіряємо випадок $S_2 > S_1$, шукаючи $v = S_2 - S_1$ у другій частині.

### Реалізація (JavaScript)

```javascript
/**
 * @param {number[][]} grid
 * @return {boolean}
 */
var canPartitionGrid = function(grid) {
    const m = grid.length;
    const n = grid[0].length;

    const rowSums = new Array(m).fill(0);
    const colSums = new Array(n).fill(0);
    let totalSum = 0;

    for (let r = 0; r < m; r++) {
        for (let c = 0; c < n; c++) {
            let v = grid[r][c];
            rowSums[r] += v;
            colSums[c] += v;
            totalSum += v;
        }
    }

    /**
     * Перевіряє розрізи вздовж першого виміру (dim1).
     * dim1 - кількість скибок (рядків/стовпців), dim2 - довжина скибки.
     */
    function check(dim1, dim2, getSliceSum, getCell) {
        // Частотний словник усіх значень у сітці
        const totalCounts = new Map();
        for (let i = 0; i < dim1; i++) {
            for (let j = 0; j < dim2; j++) {
                let v = getCell(i, j);
                totalCounts.set(v, (totalCounts.get(v) || 0) + 1);
            }
        }

        const s1Counts = new Map();
        let s1 = 0;

        // Пробуємо розріз після i-ї скибки (від 0 до dim1-2)
        for (let i = 0; i < dim1 - 1; i++) {
            s1 += getSliceSum(i);
            // Додаємо значення поточної скибки до статистики першої секції
            for (let j = 0; j < dim2; j++) {
                let v = getCell(i, j);
                s1Counts.set(v, (s1Counts.get(v) || 0) + 1);
            }

            let s2 = totalSum - s1;

            // 1. Пряма рівність
            if (s1 === s2) return true;

            // 2. Спробуємо прибрати елемент із S1, щоб вона стала рівною S2
            if (s1 > s2) {
                let v = s1 - s2;
                if (s1Counts.has(v)) {
                    let h = i + 1, w = dim2;
                    // Перевірка зв'язності:
                    if (h > 1 && w > 1) return true; // Прямокутник
                    if (h === 1 && w > 1) { // Один рядок
                        if (getCell(0, 0) === v || getCell(0, w - 1) === v) return true;
                    } else if (h > 1 && w === 1) { // Один стовпець
                        if (getCell(0, 0) === v || getCell(i, 0) === v) return true;
                    } else if (h === 1 && w === 1) { // Одна клітинка
                        return true;
                    }
                }
            }

            // 3. Спробуємо прибрати елемент із S2
            if (s2 > s1) {
                let v = s2 - s1;
                let countInS2 = (totalCounts.get(v) || 0) - (s1Counts.get(v) || 0);
                if (countInS2 > 0) {
                    let h = dim1 - 1 - i, w = dim2;
                    if (h > 1 && w > 1) return true;
                    if (h === 1 && w > 1) {
                        if (getCell(dim1 - 1, 0) === v || getCell(dim1 - 1, w - 1) === v) return true;
                    } else if (h > 1 && w === 1) {
                        if (getCell(i + 1, 0) === v || getCell(dim1 - 1, 0) === v) return true;
                    } else if (h === 1 && w === 1) {
                        return true;
                    }
                }
            }
        }
        return false;
    }

    // Перевірка горизонтальних розрізів
    if (check(m, n, (i) => rowSums[i], (i, j) => grid[i][j])) return true;
    
    // Перевірка вертикальних розрізів (міняємо ролями рядки та стовпці)
    if (check(n, m, (i) => colSums[i], (i, j) => grid[j][i])) return true;

    return false;
};
```

### Чому це працює?
* **Складність:** Алгоритм проходить по сітці кілька разів, що дає часову складність $O(M \times N)$. Оскільки $M \times N \le 10^5$, це рішення легко вкладається в ліміти часу.
* **Пам'ять:** Використовується Map для підрахунку значень, що займає $O(M \times N)$ пам'яті в найгіршому випадку.
* **Гнучкість:** Функція `check` абстрагована від того, чи ми ріжемо рядки чи стовпці, що робить код лаконічним.
