2452. Words Within Two Edits of Dictionary

Medium

<p>You are given two string arrays, <code>queries</code> and <code>dictionary</code>. All words in each array comprise of lowercase English letters and have the same length.</p>

<p>In one <strong>edit</strong> you can take a word from <code>queries</code>, and change any letter in it to any other letter. Find all words from <code>queries</code> that, after a <strong>maximum</strong> of two edits, equal some word from <code>dictionary</code>.</p>

<p>Return<em> a list of all words from </em><code>queries</code><em>, </em><em>that match with some word from </em><code>dictionary</code><em> after a maximum of <strong>two edits</strong></em>. Return the words in the <strong>same order</strong> they appear in <code>queries</code>.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<pre><strong>Input:</strong> queries = ["word","note","ants","wood"], dictionary = ["wood","joke","moat"]
<strong>Output:</strong> ["word","note","wood"]
<strong>Explanation:</strong>
- Changing the 'r' in "word" to 'o' allows it to equal the dictionary word "wood".
- Changing the 'n' to 'j' and the 't' to 'k' in "note" changes it to "joke".
- It would take more than 2 edits for "ants" to equal a dictionary word.
- "wood" can remain unchanged (0 edits) and match the corresponding dictionary word.
Thus, we return ["word","note","wood"].
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre><strong>Input:</strong> queries = ["yes"], dictionary = ["not"]
<strong>Output:</strong> []
<strong>Explanation:</strong>
Applying any two edits to "yes" cannot make it equal to "not". Thus, we return an empty array.
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= queries.length, dictionary.length &lt;= 100</code></li>
	<li><code>n == queries[i].length == dictionary[j].length</code></li>
	<li><code>1 &lt;= n &lt;= 100</code></li>
	<li>All <code>queries[i]</code> and <code>dictionary[j]</code> are composed of lowercase English letters.</li>
</ul>

2452. Слова, соответствующие двум изменениям в словаре

Средний уровень сложности

<p>Вам даны два строковых массива: <code>queries</code> и <code>dictionary</code>. Все слова в каждом массиве состоят из строчных английских букв и имеют одинаковую длину.</p>

<p>За одно <strong>изменение</strong> вы можете взять слово из <code>queries</code> и изменить любую букву в нем на любую другую. Найдите все слова из <code>queries</code>, которые после <strong>максимума</strong> двух изменений совпадают с каким-либо словом из <code>dictionary</code>.</p>

<p>Верните список всех слов из </em><code>queries</code><em>, которые совпадают с каким-либо словом из </em><code>dictionary</code><em> после максимум <strong>двух изменений</strong></em>. Возвращает слова в том же порядке, в котором они встречаются в запросах.

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<pre><strong>Входные данные:</strong> queries = ["word","note","ants","wood"], dictionary = ["wood","joke","moat"]
<strong>Выходные данные:</strong> ["word","note","wood"]
<strong>Пояснение:</strong>
- Замена буквы 'r' в слове "word" на 'o' позволяет ему соответствовать словарному слову "wood".

- Замена буквы 'n' на 'j' и буквы 't' на 'k' в слове "note" меняет его на "joke".

- Для того, чтобы "ants" соответствовало словарному слову, потребуется более двух правок.

— Слово «wood» может оставаться неизменным (0 правок) и соответствовать слову из словаря.

Таким образом, мы возвращаем ["word","note","wood"].

</pre>

<p><strong class="example">Пример 2:</strong></p>

<pre><strong>Входные данные:</strong> queries = ["yes"], dictionary = ["not"]
<strong>Выходные данные:</strong> []
<strong>Пояснение:</strong>
Применение любых двух правок к "yes" не может сделать его равным "not". Таким образом, мы возвращаем пустой массив.

</pre>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>1 <= queries.length, dictionary.length <= 100</code></li>

<li><code>n == queries[i].length == dictionary[j].length</code></li>

<li><code>1 <= n <= 100</code></li>
<li>Все <code>queries[i]</code> и <code>dictionary[j]</code> состоят из строчных английских букв.</li>
</ul>

Насправді, ця задача **не потребує динамічного програмування**. 

Динамічне програмування (наприклад, алгоритм для обчислення відстані Левенштейна) зазвичай потрібне, коли ми можемо *видаляти* або *додавати* символи, через що довжина слів змінюється. У цій задачі довжина слів однакова, і ми можемо лише *замінювати* символи. Це означає, що нам просто потрібно знайти **відстань Геммінга** (Hamming distance) між двома рядками.

Зважаючи на дуже малі обмеження в задачі (розмір масивів до 100, довжина слова до 100), найгірший сценарій вимагатиме лише $100 \times 100 \times 100 = 1,000,000$ ітерацій. Для сучасних процесорів і рушія V8 у JavaScript це виконується за долі мілісекунди.

Найбільш швидким і оптимальним підходом тут є **повний перебір (Brute Force) з оптимізацією «раннього виходу» (Early Exit)**.

### Як працює алгоритм з раннім виходом:
1. Беремо слово з `queries`.
2. Порівнюємо його зі словом з `dictionary` посимвольно.
3. Рахуємо неспівпадіння. **Якщо кількість неспівпадінь стає більшою за 2, ми негайно перериваємо цикл порівняння (`break`)**, бо далі перевіряти немає сенсу.
4. Якщо ми знайшли хоча б одне слово у словнику, яке підходить (має $\le 2$ відмінності), ми додаємо слово з `queries` у результат і **негайно переходимо до наступного слова з `queries`** (нам не треба шукати інші збіги для цього ж слова).

### Реалізація на JavaScript:

```javascript
/**
 * @param {string[]} queries
 * @param {string[]} dictionary
 * @return {string[]}
 */
var twoEditWords = function (queries, dictionary) {
    const result = [];
    
    // Перебираємо кожне слово із запитів
    for (let i = 0; i < queries.length; i++) {
        const query = queries[i];
        
        // Перебираємо кожне слово зі словника
        for (let j = 0; j < dictionary.length; j++) {
            const dictWord = dictionary[j];
            let diffCount = 0;
            
            // Посимвольне порівняння двох слів
            for (let k = 0; k < query.length; k++) {
                if (query[k] !== dictWord[k]) {
                    diffCount++;
                }
                
                // Оптимізація раннього виходу: 
                // якщо розбіжностей вже більше 2, перериваємо перевірку цього слова
                if (diffCount > 2) {
                    break;
                }
            }
            
            // Якщо знайшли слово, яке відрізняється не більше ніж на 2 символи
            if (diffCount <= 2) {
                result.push(query);
                // Оскільки слово з queries вже підійшло, шукати інші збіги у словнику не потрібно
                break; 
            }
        }
    }
    
    return result;
};
```

### Чому це найшвидший спосіб:
* **Часова складність:** $O(Q \cdot D \cdot L)$, де $Q$ — кількість запитів, $D$ — кількість слів у словнику, $L$ — довжина слова. Завдяки `break`, у більшості випадків цикл перериватиметься на перших кількох символах, тому реальний час виконання буде значно меншим за теоретичний максимум.
* **Просторова складність:** $O(1)$ додаткової пам'яті (не враховуючи масив `result` для відповіді), оскільки ми просто порівнюємо символи на місці без створення нових рядків чи матриць, як це було б у динамічному програмуванні.
