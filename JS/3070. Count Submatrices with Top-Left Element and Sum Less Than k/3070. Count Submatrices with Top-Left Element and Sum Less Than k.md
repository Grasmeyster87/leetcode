Це задача з  — ключова ідея тут **prefix sum (2D префіксні суми)**.

---

## 🔍 Спостереження

Нам потрібні **всі підматриці, які починаються з (0,0)**.

Тобто будь-яка підматриця має вигляд:

```
(0,0) → (i,j)
```

👉 Це означає:

* ми не перебираємо всі можливі підматриці
* тільки всі праві нижні кути `(i, j)`

---

## 💡 Ідея рішення

Будуємо **2D prefix sum**, де:

```
prefix[i][j] = сума елементів від (0,0) до (i,j)
```

Формула:

```
prefix[i][j] = grid[i][j]
             + prefix[i-1][j]
             + prefix[i][j-1]
             - prefix[i-1][j-1]
```

---

## 🎯 Що це дає

Тепер:

👉 кожна підматриця (0,0 → i,j) має суму = `prefix[i][j]`

Просто:

```
рахуємо кількість prefix[i][j] <= k
```

---

## ⚡ Складність

* Час: **O(m * n)**
* Пам'ять: **O(1)** (якщо рахувати прямо в grid)

---

## ✅ Оптимальне рішення (JS)

```js
var countSubmatrices = function(grid, k) {
    const m = grid.length;
    const n = grid[0].length;

    let count = 0;

    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            if (i > 0) grid[i][j] += grid[i - 1][j];
            if (j > 0) grid[i][j] += grid[i][j - 1];
            if (i > 0 && j > 0) grid[i][j] -= grid[i - 1][j - 1];

            if (grid[i][j] <= k) count++;
        }
    }

    return count;
};
```

---

## 🧠 Чому це працює

* Ми накопичуємо суму з (0,0)
* Кожна клітинка = окрема підматриця
* Не потрібно вкладених циклів по всіх підматрицях (що було б O(n⁴))
