2839. Check if Strings Can be Made Equal With Operations I

<p>You are given two strings <code>s1</code> and <code>s2</code>, both of length <code>4</code>, consisting of <strong>lowercase</strong> English letters.</p>

<p>You can apply the following operation on any of the two strings <strong>any</strong> number of times:</p>

<ul>
	<li>Choose any two indices <code>i</code> and <code>j</code> such that <code>j - i = 2</code>, then <strong>swap</strong> the two characters at those indices in the string.</li>
</ul>

<p>Return <code>true</code><em> if you can make the strings </em><code>s1</code><em> and </em><code>s2</code><em> equal, and </em><code>false</code><em> otherwise</em>.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<pre><strong>Input:</strong> s1 = "abcd", s2 = "cdab"
<strong>Output:</strong> true
<strong>Explanation:</strong> We can do the following operations on s1:
- Choose the indices i = 0, j = 2. The resulting string is s1 = "cbad".
- Choose the indices i = 1, j = 3. The resulting string is s1 = "cdab" = s2.
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre><strong>Input:</strong> s1 = "abcd", s2 = "dacb"
<strong>Output:</strong> false
<strong>Explanation:</strong> It is not possible to make the two strings equal.
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>s1.length == s2.length == 4</code></li>
	<li><code>s1</code> and <code>s2</code> consist only of lowercase English letters.</li>
</ul>

2839. Проверка равенства строк с помощью операции I

<p>Вам даны две строки <code>s1</code> и <code>s2</code>, обе длиной <code>4</code>, состоящие из <strong>строчных</strong> английских букв.</p>

<p>Вы можете применить следующую операцию к любой из двух строк <strong>любое</strong> количество раз:</p>

<ul>

<li>Выберите любые два индекса <code>i</code> и <code>j</code> так, чтобы <code>j - i = 2</code>, затем <strong>поменяйте местами</strong> два символа в этих индексах в строке.</li>
</ul>

<p>Верните <code>true</code><em>, если вы можете сделать строки </em><code>s1</code><em> и </em><code>s2</code><em> равными, и </em><code>false</code><em> otherwise</em>.</p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<pre><strong>Входные данные:</strong> s1 = "abcd", s2 = "cdab"
<strong>Выходные данные:</strong> true
<strong>Пояснение:</strong> Мы можем выполнить следующие операции над s1:
- Выбрать индексы i = 0, j = 2. Результирующая строка: s1 = "cbad".

- Выбрать индексы i = 1, j = 3. Результирующая строка: s1 = "cdab" = s2.

</pre>

<p><strong class="example">Пример 2:</strong></p>

<pre><strong>Входные данные:</strong> s1 = "abcd", s2 = "dacb"
<strong>Выходные данные:</strong> false
<strong>Пояснение:</strong> Невозможно сделать две строки равными.

</pre>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>s1.length == s2.length == 4</code></li>

<li><code>s1</code> и <code>s2</code> состоят только из строчных английских букв.</li>
</ul>
</div>
