3546. Equal Sum Grid Partition I
Medium
<p>You are given an <code>m x n</code> matrix <code>grid</code> of positive integers. Your task is to determine if it is possible to make <strong>either one horizontal or one vertical cut</strong> on the grid such that:</p>

<ul>
	<li>Each of the two resulting sections formed by the cut is <strong>non-empty</strong>.</li>
	<li>The sum of the elements in both sections is <strong>equal</strong>.</li>
</ul>

<p>Return <code>true</code> if such a partition exists; otherwise return <code>false</code>.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">grid = [[1,4],[2,3]]</span></p>

<p><strong>Output:</strong> <span class="example-io">true</span></p>

<p><strong>Explanation:</strong></p>

<p>A horizontal cut between row 0 and row 1 results in two non-empty sections, each with a sum of 5. Thus, the answer is <code>true</code>.</p>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">grid = [[1,3],[2,4]]</span></p>

<p><strong>Output:</strong> <span class="example-io">false</span></p>

<p><strong>Explanation:</strong></p>

<p>No horizontal or vertical cut results in two non-empty sections with equal sums. Thus, the answer is <code>false</code>.</p>
</div>

	<li><code>1 &lt;= n == grid[i].length &lt;= 10<sup>5</sup></code></li>
	<li><code>2 &lt;= m * n &lt;= 10<sup>5</sup></code></li>
	<li><code>1 &lt;= grid[i][j] &lt;= 10<sup>5</sup></code></li>

3546. Разбиение сетки с равной суммой элементов I
Средний уровень сложности
<p>Вам дана матрица <code>m x n</code> сеткой из положительных целых чисел. Ваша задача — определить, возможно ли сделать <strong>один горизонтальный или один вертикальный разрез</strong> на сетке таким образом, чтобы:</p>

<ul>

<li>Каждый из двух результирующих разрезов является <strong>непустым</strong>.</li>

<li>Сумма элементов в обоих разрезах <strong>равна</strong>.</li>
</ul>

<p>Верните <code>true</code>, если такое разбиение существует; В противном случае вернуть <code>false</code>.</p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<div class="example-block">
<p><strong>Ввод:</strong> <span class="example-io">grid = [[1,4],[2,3]]</span></p>

<p><strong>Вывод:</strong> <span class="example-io">true</span></p>

<p><strong>Пояснение:</strong></p>

<p><img alt="" style="width: 200px;" src="https://assets.leetcode.com/uploads/2025/03/30/lc.png"><img alt="" style="width: 200px; height: 200px;" src="https://assets.leetcode.com/uploads/2025/03/30/lc.jpeg"></p>

<p>Горизонтальный разрез между строкой 0 и строкой 1 приводит к двум непустым секциям, сумма значений каждой из которых равна 5. Таким образом, ответ — <code>истина</code>.</p>
</div>

<p><strong class="example">Пример 2:</strong></p>

<div class="example-block">
<p><strong>Входные данные:</strong> <span class="example-io">grid = [[1,3],[2,4]]</span></p>

<p><strong>Выходные данные:</strong> <span class="example-io">false</span></p>

<p><strong>Пояснение:</strong></p>

<p>Ни один горизонтальный или вертикальный разрез не приводит к двум непустым секциям с равными суммами. Таким образом, ответ — <code>ложь</code>.</p>
</div>

<p><strong>Ограничения:</strong></p>

<ul>

<li><code>1 <= m == grid.length <= 10<sup>5</sup></code></li>
<li><code>1 <= n == grid[i].length <= 10<sup>5</sup></code></li>
<li><code>2 <= m * n <= 10<sup>5</sup></code></li>
<li><code>1 <= grid[i][j] <= 10<sup>5</sup></code></li>
</ul>

Твоя логіка абсолютно правильна: задача дійсно зводиться до пошуку "точки перелому" або по горизонталі (між рядками), або по вертикалі (між стовпцями).

Оскільки обмеження $m \times n \le 10^5$, нам потрібно знайти рішення за лінійний час відносно кількості елементів — $O(m \cdot n)$. Якщо ми будемо щоразу повністю перераховувати суми частин, ми вийдемо за межі ліміту часу.

Ось як це зробити максимально ефективно:

---

### Оптимізований алгоритм

1.  **Загальна сума:** Спочатку порахуй суму абсолютно всіх чисел у матриці (`totalSum`).
    * Якщо `totalSum` не ділиться на 2 без залишку, ти **одразу** можеш повертати `false`, бо розрізати цілі числа на дві рівні цілі суми неможливо.
2.  **Цільова сума:** Наша мета — знайти такий розріз, де сума однієї частини дорівнює $target = totalSum / 2$.
3.  **Горизонтальний розріз:**
    * Йди по рядках зверху вниз.
    * Додавай суму поточного рядка до накопичувальної змінної `runningSum`.
    * Після кожного рядка (крім останнього, бо секції мають бути не порожніми) перевіряй: якщо `runningSum === target`, повертай `true`.
4.  **Вертикальний розріз:**
    * Йди по стовпцях зліва направо.
    * Для кожного стовпця обчисли його суму (пройшовши по всіх рядках для цього індексу `j`).
    * Додавай суму стовпця до `runningSum`.
    * Після кожного стовпця (крім останнього) перевіряй: якщо `runningSum === target`, повертай `true`.

---

### Реалізація (JavaScript)

```javascript
/**
 * @param {number[][]} grid
 * @return {boolean}
 */
var canPartitionGrid = function(grid) {
    const m = grid.length;
    const n = grid[0].length;
    
    let totalSum = 0;
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            totalSum += grid[i][j];
        }
    }

    // Якщо сума непарна, рівний поділ неможливий
    if (totalSum % 2 !== 0) return false;
    const target = totalSum / 2;

    // 1. Перевірка горизонтального розрізу
    let rowAccumulator = 0;
    for (let i = 0; i < m - 1; i++) { // m - 1, щоб не залишати порожню секцію
        for (let j = 0; j < n; j++) {
            rowAccumulator += grid[i][j];
        }
        if (rowAccumulator === target) return true;
    }

    // 2. Перевірка вертикального розрізу
    let colAccumulator = 0;
    for (let j = 0; j < n - 1; j++) { // n - 1, щоб не залишати порожню секцію
        for (let i = 0; i < m; i++) {
            colAccumulator += grid[i][j];
        }
        if (colAccumulator === target) return true;
    }

    return false;
};
```

### Чому це працює швидко?
* Ми проходимо по матриці для обчислення загальної суми: $O(m \cdot n)$.
* Ми проходимо для перевірки рядків: $O(m \cdot n)$.
* Ми проходимо для перевірки стовпців: $O(m \cdot n)$.
* **Загальна складність:** $O(m \cdot n)$, що ідеально вписується в ліміти.

> [!TIP]
> Якщо матриця дуже велика, можна спочатку обчислити суми всіх рядків та суми всіх стовпців в окремі масиви. Це дозволить зробити фінальну перевірку розрізів за $O(m)$ та $O(n)$ відповідно.
