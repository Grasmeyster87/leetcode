2615. Sum of Distances

Medium

<p>You are given a <strong>0-indexed</strong> integer array <code>nums</code>. There exists an array <code>arr</code> of length <code>nums.length</code>, where <code>arr[i]</code> is the sum of <code>|i - j|</code> over all <code>j</code> such that <code>nums[j] == nums[i]</code> and <code>j != i</code>. If there is no such <code>j</code>, set <code>arr[i]</code> to be <code>0</code>.</p>

<p>Return <em>the array </em><code>arr</code><em>.</em></p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<pre><strong>Input:</strong> nums = [1,3,1,1,2]
<strong>Output:</strong> [5,0,3,4,0]
<strong>Explanation:</strong> 
When i = 0, nums[0] == nums[2] and nums[0] == nums[3]. Therefore, arr[0] = |0 - 2| + |0 - 3| = 5. 
When i = 1, arr[1] = 0 because there is no other index with value 3.
When i = 2, nums[2] == nums[0] and nums[2] == nums[3]. Therefore, arr[2] = |2 - 0| + |2 - 3| = 3. 
When i = 3, nums[3] == nums[0] and nums[3] == nums[2]. Therefore, arr[3] = |3 - 0| + |3 - 2| = 4. 
When i = 4, arr[4] = 0 because there is no other index with value 2. 

</pre>

<p><strong class="example">Example 2:</strong></p>

<pre><strong>Input:</strong> nums = [0,5,3]
<strong>Output:</strong> [0,0,0]
<strong>Explanation:</strong> Since each element in nums is distinct, arr[i] = 0 for all i.
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= nums.length &lt;= 10<sup>5</sup></code></li>
	<li><code>0 &lt;= nums[i] &lt;= 10<sup>9</sup></code></li>
</ul>

2615. Сумма расстояний

Средний уровень сложности

<p>Вам дан массив целых чисел <strong>nums</code> с индексацией 0</strong>. Существует массив <code>arr</code> длиной <code>nums.length</code>, где <code>arr[i]</code> — сумма <code>|i - j|</code> по всем <code>j</code> таким, что <code>nums[j] == nums[i]</code> и <code>j != i</code>. Если такого <code>j</code> не существует, установите <code>arr[i]</code> равным <code>0</code>.</p>

<p>Возвращает <em>массив</em><code>arr</code><em>.</em></p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<pre><strong>Входные данные:</strong> nums = [1,3,1,1,2]
<strong>Выходные данные:</strong> [5,0,3,4,0]
<strong>Пояснение:</strong>

Когда i = 1, arr[1] = 0, потому что нет другого индекса со значением 3.
Когда i = 2, nums[2] == nums[0] и nums[2] == nums[3]. Следовательно, arr[2] = |2 - 0| + |2 - 3| = 3.
Когда i = 3, nums[3] == nums[0] и nums[3] == nums[2]. Следовательно, arr[3] = |3 - 0| + |3 - 2| = 4.
Когда i = 4, arr[4] = 0, потому что нет другого индекса со значением 2.

</pre>

<pre><strong>Входные данные:</strong> nums = [0,5,3]
<strong>Выходные данные:</strong> [0,0,0]
<strong>Пояснение:</strong> Поскольку каждый элемент в nums уникален, arr[i] = 0 для всех i.

Ось оптимізований і повністю робочий варіант функції. 

Ваш початковий начерк з використанням вкладених циклів мав би часову складність `O(N^2)`. Оскільки довжина масиву може сягати **100 000** елементів, такий підхід призведе до перевищення ліміту часу (Time Limit Exceeded). 

Щоб вирішити завдання за час `O(N)`, потрібно згрупувати індекси однакових чисел за допомогою хеш-таблиці (`Map`), а потім використати математику префіксних сум для обчислення відстаней без повторного перебору.

### Оновлений код (JavaScript)

```javascript
/**
 * @param {number[]} nums
 * @return {number[]}
 */
var distance = function(nums) {
    // Ініціалізуємо результуючий масив нулями
    const res = new Array(nums.length).fill(0);
    // Map для зберігання індексів кожного унікального числа
    const map = new Map();

    // 1. Групуємо індекси за значеннями елементів
    for (let i = 0; i < nums.length; i++) {
        if (!map.has(nums[i])) {
            map.set(nums[i], []);
        }
        map.get(nums[i]).push(i);
    }

    // 2. Обчислюємо відстані для кожної групи однакових елементів
    for (const indices of map.values()) {
        const n = indices.length;
        
        // Якщо елемент зустрічається лише раз, сума відстаней залишається 0
        if (n === 1) continue;

        // Знаходимо загальну суму всіх індексів для даного числа
        let totalSum = 0;
        for (let i = 0; i < n; i++) {
            totalSum += indices[i];
        }

        let leftSum = 0;
        let rightSum = totalSum;

        // Проходимо по кожному індексу в групі
        for (let p = 0; p < n; p++) {
            const index = indices[p];
            
            // Віднімаємо поточний індекс від суми елементів праворуч
            rightSum -= index;

            // Обчислюємо суму відстаней для елементів зліва
            // Формула: (кількість елементів зліва * поточний індекс) - сума їх індексів
            const leftPart = p * index - leftSum;

            // Обчислюємо суму відстаней для елементів справа
            // Формула: сума їх індексів - (кількість елементів справа * поточний індекс)
            const rightPart = rightSum - (n - 1 - p) * index;

            // Записуємо результат
            res[index] = leftPart + rightPart;

            // Додаємо поточний індекс до суми елементів зліва для наступної ітерації
            leftSum += index;
        }
    }

    return res;
};
```

### Як це працює:
1. **Групування:** Ми проходимо по масиву `nums` і зберігаємо всі індекси для кожного унікального числа у словник `map`. Наприклад, для `nums = [1,3,1,1,2]` число `1` матиме масив індексів `[0, 2, 3]`.
2. **Префіксні суми:** Замість того, щоб порівнювати кожен індекс з кожним (що довго), ми рухаємось по відсортованому масиву індексів `[0, 2, 3]`. Ми знаємо суму всіх індексів зліва (`leftSum`) і суму всіх індексів справа (`rightSum`).
3. **Обчислення:** Для поточного індексу ми можемо миттєво порахувати суму модулів різниць за формулами, наведеними в коментарях. Це дозволяє обробити кожну групу за лінійний час.
