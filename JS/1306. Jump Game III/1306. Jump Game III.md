1306. Jump Game III

Medium
<p>Given an array of non-negative integers <code>arr</code>, you are initially positioned at <code>start</code>&nbsp;index of the array. When you are at index <code>i</code>, you can jump&nbsp;to <code>i + arr[i]</code> or <code>i - arr[i]</code>, check if you can reach&nbsp;<strong>any</strong> index with value 0.</p>

<p>Notice that you can not jump outside of the array at any time.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<pre><strong>Input:</strong> arr = [4,2,3,0,3,1,2], start = 5
<strong>Output:</strong> true
<strong>Explanation:</strong> 
All possible ways to reach at index 3 with value 0 are: 
index 5 -&gt; index 4 -&gt; index 1 -&gt; index 3 
index 5 -&gt; index 6 -&gt; index 4 -&gt; index 1 -&gt; index 3 
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre><strong>Input:</strong> arr = [4,2,3,0,3,1,2], start = 0
<strong>Output:</strong> true 
<strong>Explanation: 
</strong>One possible way to reach at index 3 with value 0 is: 
index 0 -&gt; index 4 -&gt; index 1 -&gt; index 3
</pre>

<p><strong class="example">Example 3:</strong></p>

<pre><strong>Input:</strong> arr = [3,0,2,1,2], start = 2
<strong>Output:</strong> false
<strong>Explanation: </strong>There is no way to reach at index 1 with value 0.
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= arr.length &lt;= 5 * 10<sup>4</sup></code></li>
	<li><code>0 &lt;= arr[i] &lt;&nbsp;arr.length</code></li>
	<li><code>0 &lt;= start &lt; arr.length</code></li>
</ul>

1306. Игра в прыжки III

Средний уровень сложности
<p>Дано множество неотрицательных целых чисел <code>arr</code>, вы изначально находитесь в <code>start</code>&nbsp;индексе массива. Находясь на индексе <code>i</code>, вы можете перейти к <code>i + arr[i]</code> или <code>i - arr[i]</code>, проверьте, можете ли вы достичь любого индекса со значением 0.</p>

<p>Обратите внимание, что вы не можете выйти за пределы массива ни в какой момент времени.</p>

<p></p>
<p><strong class="example">Пример 1:</strong></p>

<pre><strong>Входные данные:</strong> arr = [4,2,3,0,3,1,2], start = 5
<strong>Выходные данные:</strong> true
<strong>Пояснение:</strong>
Все возможные способы достижения индекса 3 со значением 0:
индекс 5 -> индекс 4 -> индекс 1 -> индекс 3
индекс 5 > индекс 6 > индекс 4 > индекс 1 > индекс 3
</pre>

<p><strong class="example">Пример 2:</strong></p>

<pre><strong>Входные данные:</strong> arr = [4,2,3,0,3,1,2], start = 0
<strong>Выходные данные:</strong> true
<strong>Пояснение:
</strong>Один из возможных способов достичь индекса 3 со значением 0:
индекс 0 > индекс 4 > индекс 1 > индекс 3
</pre>

<p><strong class="example">Пример 3:</strong></p>

<pre><strong>Входные данные:</strong> arr = [3,0,2,1,2], start = 2
<strong>Выходные данные:</strong> false
<strong>Пояснение:</strong>Невозможно достичь индекса 1 со значением 0.
</pre>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>1 <= arr.length <= 5 * 10<sup>4</sup></code></li>
<li><code>0 <= arr[i] <&nbsp;arr.length</code></li>
<li><code>0 <= start < arr.length</code></li>
</ul>

## Алгоритм — BFS (пошук в ширину)

### Ідея

Задачу можна представити як **обхід графа**: кожен індекс — це вершина, а з індексу `i` є ребра до `i + arr[i]` та `i - arr[i]` (якщо вони в межах масиву). Потрібно перевірити, чи існує шлях від `start` до будь-якої вершини зі значенням `0`.

### Покрокова логіка

1. **Ініціалізація** — створюємо масив `visited` для позначення відвіданих індексів та чергу `queue` зі стартовим індексом.
2. **Цикл BFS** — дістаємо індекс `i` з черги:
   - Якщо `arr[i] === 0` — знайшли цільовий індекс, повертаємо `true`.
   - Інакше обчислюємо два сусідні індекси: `i + arr[i]` (стрибок вправо) та `i - arr[i]` (стрибок вліво).
   - Для кожного сусіда: якщо він в межах масиву і ще не відвіданий — позначаємо як відвіданий та додаємо в чергу.
3. **Результат** — якщо черга спорожніла і ми не знайшли `0` — повертаємо `false`.

### Порядкове пояснення коду

```javascript
var canReach = function(arr, start) {
    const n = arr.length;
    // Uint8Array ефективніший за звичайний масив для булевих прапорців
    const visited = new Uint8Array(n);
    const queue = [start];
    visited[start] = 1;

    while (queue.length > 0) {
        const i = queue.shift();             // дістаємо наступний індекс з черги

        if (arr[i] === 0) return true;       // ціль досягнута!

        // перебираємо обидва можливі стрибки
        for (const next of [i + arr[i], i - arr[i]]) {
            if (next >= 0 && next < n && !visited[next]) {
                visited[next] = 1;           // позначаємо як відвіданий
                queue.push(next);            // додаємо в чергу для подальшого обходу
            }
        }
    }

    return false;                            // жоден індекс зі значенням 0 недосяжний
};
```

### Складність

| | Значення |
|---|---|
| **Час** | O(n) — кожен індекс відвідується максимум один раз |
| **Пам'ять** | O(n) — масив `visited` + черга у найгіршому випадку |
