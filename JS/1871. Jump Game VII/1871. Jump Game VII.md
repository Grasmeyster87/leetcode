1871. Jump Game VII

Medium
<p>You are given a <strong>0-indexed</strong> binary string <code>s</code> and two integers <code>minJump</code> and <code>maxJump</code>. In the beginning, you are standing at index <code>0</code>, which is equal to <code>'0'</code>. You can move from index <code>i</code> to index <code>j</code> if the following conditions are fulfilled:</p>

<ul>
	<li><code>i + minJump &lt;= j &lt;= min(i + maxJump, s.length - 1)</code>, and</li>
	<li><code>s[j] == '0'</code>.</li>
</ul>

<p>Return <code>true</code><i> if you can reach index </i><code>s.length - 1</code><i> in </i><code>s</code><em>, or </em><code>false</code><em> otherwise.</em></p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<pre><strong>Input:</strong> s = "<u>0</u>11<u>0</u>1<u>0</u>", minJump = 2, maxJump = 3
<strong>Output:</strong> true
<strong>Explanation:</strong>
In the first step, move from index 0 to index 3. 
In the second step, move from index 3 to index 5.
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre><strong>Input:</strong> s = "01101110", minJump = 2, maxJump = 3
<strong>Output:</strong> false
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>2 &lt;= s.length &lt;= 10<sup>5</sup></code></li>
	<li><code>s[i]</code> is either <code>'0'</code> or <code>'1'</code>.</li>
	<li><code>s[0] == '0'</code></li>
	<li><code>1 &lt;= minJump &lt;= maxJump &lt; s.length</code></li>
</ul>

## Найшвидше рішення (BFS + Мікрооптимізації V8)

### Ідея алгоритму
Щоб досягти максимальної швидкості (близько 5 ms на LeetCode), ми використовуємо **Пошук у ширину (BFS)** замість класичного динамічного програмування. 
Головна перевага BFS полягає в тому, що ми обробляємо лише ті індекси, яких ми **реально** можемо досягти, тоді як DP змушує нас проходити кожен індекс масиву.

### Оптимізації для швидкодії
1. **Використання `Int32Array` замість звичайного масиву `[]` для черги:**
   Звичайні масиви в JavaScript — це хеш-таблиці (об'єкти), які можуть динамічно змінювати розмір, що викликає збирання сміття (Garbage Collection) і сповільнює роботу. Типізований масив `Int32Array` виділяє суцільний блок пам'яті один раз, що працює блискавично.
2. **Заміна методів черги (`.push()`, `.shift()`) на ручні вказівники (`head`, `tail`):**
   Виклик функцій для масиву має додаткові витрати (overhead). Використання двох змінних для керування чергою дає змогу звертатися до елементів за `O(1)` з мінімальними затримками.
3. **Уникнення повторних перевірок за допомогою `furthest`:**
   Ми зберігаємо змінну `furthest`, яка вказує на найдальший індекс, який ми вже перевіряли. Коли ми шукаємо нові індекси для стрибка, ми починаємо з `max(i + minJump, furthest + 1)`. Це гарантує, що ми ніколи не перевіряємо один і той самий символ двічі. Завдяки цьому внутрішній цикл виконається сумарно не більше ніж $N$ разів.
4. **Порівняння через `charCodeAt()`:**
   Вираз `s[j] === '0'` змушує JS-рушій щоразу створювати новий рядок з одного символу. Замість цього ми використовуємо `s.charCodeAt(j) === 48`, що зводиться до швидкого порівняння двох чисел.

### Складність
- **Часова складність:** $\mathcal{O}(N)$ — Кожен індекс додається в чергу максимум один раз. Перевірка внутрішнього циклу ніколи не дублюється завдяки змінній `furthest`.
- **Просторова складність:** $\mathcal{O}(N)$ — Для зберігання черги `Int32Array` розміром $N$.

### Код рішення
```javascript
/**
 * @param {string} s
 * @param {number} minJump
 * @param {number} maxJump
 * @return {boolean}
 */
var canReach = function(s, minJump, maxJump) {
    const n = s.length;
    // 49 — це ASCII-код символу '1'
    if (s.charCodeAt(n - 1) === 49) return false;
    
    // Використовуємо типізований масив Int32Array замість звичайного масиву
    // для максимальної швидкодії (V8 обробляє його значно швидше, без реаллокацій)
    const q = new Int32Array(n);
    let head = 0;
    let tail = 0;
    
    q[tail++] = 0; // Початковий індекс 0
    let furthest = 0; // Найвіддаленіший індекс, який ми вже перевіряли
    
    while (head < tail) {
        let i = q[head++];
        
        let start = i + minJump;
        // Щоб уникнути повторної перевірки одних і тих же елементів
        if (start <= furthest) {
            start = furthest + 1;
        }
        
        let end = i + maxJump;
        if (end >= n) {
            end = n - 1;
        }
        
        for (let j = start; j <= end; j++) {
            // 48 — це ASCII-код символу '0'
            // charCodeAt працює швидше
            if (s.charCodeAt(j) === 48) {
                if (j === n - 1) return true;
                q[tail++] = j;
            }
        }
        
        // Оновлюємо максимально перевірену відстань
        furthest = i + maxJump;
    }
    
    return false;
};
```
