2069. Walking Robot Simulation II

Medium

<p>A <code>width x height</code> grid is on an XY-plane with the <strong>bottom-left</strong> cell at <code>(0, 0)</code> and the <strong>top-right</strong> cell at <code>(width - 1, height - 1)</code>. The grid is aligned with the four cardinal directions (<code>"North"</code>, <code>"East"</code>, <code>"South"</code>, and <code>"West"</code>). A robot is <strong>initially</strong> at cell <code>(0, 0)</code> facing direction <code>"East"</code>.</p>

<p>The robot can be instructed to move for a specific number of <strong>steps</strong>. For each step, it does the following.</p>

<ol>
	<li>Attempts to move <strong>forward one</strong> cell in the direction it is facing.</li>
	<li>If the cell the robot is <strong>moving to</strong> is <strong>out of bounds</strong>, the robot instead <strong>turns</strong> 90 degrees <strong>counterclockwise</strong> and retries the step.</li>
</ol>

<p>After the robot finishes moving the number of steps required, it stops and awaits the next instruction.</p>

<p>Implement the <code>Robot</code> class:</p>

<ul>
	<li><code>Robot(int width, int height)</code> Initializes the <code>width x height</code> grid with the robot at <code>(0, 0)</code> facing <code>"East"</code>.</li>
	<li><code>void step(int num)</code> Instructs the robot to move forward <code>num</code> steps.</li>
	<li><code>int[] getPos()</code> Returns the current cell the robot is at, as an array of length 2, <code>[x, y]</code>.</li>
	<li><code>String getDir()</code> Returns the current direction of the robot, <code>"North"</code>, <code>"East"</code>, <code>"South"</code>, or <code>"West"</code>.</li>
</ul>

robot.step(2);  // It moves one step East to (5, 0), and faces East.
                // Moving the next step East would be out of bounds, so it turns and faces North.

robot.step(1);  // It moves one step North to (5, 2), and faces <strong>North</strong> (not West).
robot.step(4);  // Moving the next step North would be out of bounds, so it turns and faces West.
                // Then, it moves four steps West to (1, 2), and faces West.
robot.getPos(); // return [1, 2]
robot.getDir(); // return "West"

2069. Моделирование шагающего робота II

Средний уровень сложности

<p>На плоскости XY расположена сетка размером <code>ширина x высота</code>, при этом нижняя левая ячейка находится в точке <code>(0, 0)</code>, а верхняя правая ячейка — в точке <code>(ширина - 1, высота - 1)</code>. Сетка выровнена по четырем основным направлениям (<code>"Север"</code>, <code>"Восток"</code>, <code>"Юг"</code> и <code>"Запад"</code>). Робот изначально находится в ячейке <code>(0, 0)</code>, повернувшись в направлении <code>"Восток"</code>.</p>

<p>Роботу можно дать команду на перемещение на определенное количество <strong>шагов"</strong>. На каждом шаге робот выполняет следующие действия.</p>

<ol>

<li>Пытается переместиться на одну клетку вперед в направлении, в котором он находится.</li>

<li>Если клетка, в которую перемещается робот, выходит за пределы игровой зоны, робот вместо этого поворачивается на 90 градусов против часовой стрелки и повторяет шаг.</li>
</ol>

<p>После того, как робот завершит перемещение на необходимое количество шагов, он останавливается и ожидает следующей инструкции.</p>

<p>Реализуйте класс <code>Robot</code>:</p>

<ul>

<li><code>Robot(int width, int height)</code> Инициализирует сетку шириной x высотой, устанавливая робота в точке (0, 0) в направлении "на восток".</li>

<li><code>void step(int num)</code> Инструктирует робота двигаться вперед на <code>num</code> шагов.</li>

<li><code>int[] getPos()</code> Возвращает текущую ячейку, в которой находится робот, в виде массива длиной 2, <code>[x, y]</code>.</li>

<li><code>String getDir()</code> Возвращает текущее направление движения робота: <code>"Север"</code>, <code>"Восток"</code>, <code>"Юг"</code> или <code>"Запад"</code>.</li>
</ul>

Ось ефективне рішення для цієї задачі. 

Оскільки робот рухається виключно по периметру сітки, а кількість кроків `num` може бути дуже великою (до 100 000), покрокова симуляція призведе до помилки Time Limit Exceeded. Замість цього набагато ефективніше обчислити загальну довжину периметра і визначати нову позицію за допомогою математичного залишку від ділення (modulo). Це знижує складність методу `step` до $O(1)$.

Код навмисно розбитий на чіткі, модульні функції для обчислення координат (`getPos`) та напрямку (`getDir`), уникаючи створення однієї перевантаженої функції. Така структура робить логіку прозорою і дозволяє зручно протестувати методи, після чого зробити атомарний коміт прямо в єдину гілку вашого проекту.

```javascript
/**
 * @param {number} width
 * @param {number} height
 */
var Robot = function(width, height) {
    this.width = width;
    this.height = height;
    
    // Загальна кількість кроків для повного обходу периметра
    this.perimeter = 2 * (width - 1) + 2 * (height - 1);
    
    // Поточна позиція на периметрі (від 0 до perimeter - 1)
    this.currentPos = 0; 
    
    // Прапорець для відстеження того, чи робот вже зрушив з місця.
    // Це важливо для точки (0,0): на початку напрямок "East", а після проходження кола - "South".
    this.hasMoved = false; 
};

/** * @param {number} num
 * @return {void}
 */
Robot.prototype.step = function(num) {
    this.hasMoved = true;
    this.currentPos = (this.currentPos + num) % this.perimeter;
};

/**
 * @return {number[]}
 */
Robot.prototype.getPos = function() {
    let p = this.currentPos;
    let w = this.width;
    let h = this.height;

    // Нижня грань
    if (p < w) {
        return [p, 0];
    }
    // Права грань
    if (p < w + h - 1) {
        return [w - 1, p - w + 1];
    }
    // Верхня грань
    if (p < 2 * w + h - 2) {
        return [w - 1 - (p - (w + h - 2)), h - 1];
    }
    // Ліва грань
    return [0, h - 1 - (p - (2 * w + h - 3))];
};

/**
 * @return {string}
 */
Robot.prototype.getDir = function() {
    let p = this.currentPos;
    let w = this.width;
    let h = this.height;

    // Спеціальний випадок: робот у стартовій точці
    if (p === 0) {
        return this.hasMoved ? "South" : "East";
    }
    // Нижня грань (рухався на Схід)
    if (p < w) {
        return "East";
    }
    // Права грань (рухався на Північ)
    if (p < w + h - 1) {
        return "North";
    }
    // Верхня грань (рухався на Захід)
    if (p < 2 * w + h - 2) {
        return "West";
    }
    // Ліва грань (рухався на Південь)
    return "South";
};

/** * Your Robot object will be instantiated and called as such:
 * var obj = new Robot(width, height)
 * obj.step(num)
 * var param_2 = obj.getPos()
 * var param_3 = obj.getDir()
 */
```

### Пояснення логіки:
* **Периметр:** Для сітки `width x height` формула периметра — `2 * (width - 1) + 2 * (height - 1)`. Всі рухи закольцьовані навколо цього значення.
* **Позиціонування (`getPos`):** Ми перевіряємо, на який з чотирьох відрізків периметра (нижній, правий, верхній чи лівий) потрапляє значення `currentPos`, і математично вираховуємо точні координати `[x, y]`.
* **Напрямок (`getDir`):** Напрямок безпосередньо залежить від того, на якій грані зараз стоїть робот. Якщо він перебуває у точці `0` (початковій позиції), напрямок буде `"East"` до першого кроку і `"South"` у всіх наступних випадках, коли він робить повне коло і повертається у `(0, 0)`.
