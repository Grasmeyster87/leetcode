2946. Matrix Similarity After Cyclic Shifts
Easy<
<p>You are given an <code>m x n</code> integer matrix <code>mat</code> and an integer <code>k</code>. The matrix rows are 0-indexed.</p>

<p>The following proccess happens <code>k</code> times:</p>

<ul>
	<li><strong>Even-indexed</strong> rows (0, 2, 4, ...) are cyclically shifted to the left.</li>
</ul>

<p><img style="width: 283px; height: 90px;" src="https://assets.leetcode.com/uploads/2024/05/19/lshift.jpg"></p>

<ul>
	<li><strong>Odd-indexed</strong> rows (1, 3, 5, ...) are cyclically shifted to the right.</li>
</ul>

<p><img style="width: 283px; height: 90px;" src="https://assets.leetcode.com/uploads/2024/05/19/rshift-stlone.jpg"></p>

<p>Return <code>true</code> if the final modified matrix after <code>k</code> steps is identical to the original matrix, and <code>false</code> otherwise.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">mat = [[1,2,3],[4,5,6],[7,8,9]], k = 4</span></p>

<p><strong>Output:</strong> <span class="example-io">false</span></p>

<p><strong>Explanation:</strong></p>

<p>In each step left shift is applied to rows 0 and 2 (even indices), and right shift to row 1 (odd index).</p>

<p><img style="width: 857px; height: 150px;" src="https://assets.leetcode.com/uploads/2024/05/19/t1-2.jpg"></p>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">mat = [[1,2,1,2],[5,5,5,5],[6,3,6,3]], k = 2</span></p>

<p><strong>Output:</strong> <span class="example-io">true</span></p>

<p><strong>Explanation:</strong></p>

<p><img style="width: 632px; height: 150px;" src="https://assets.leetcode.com/uploads/2024/05/19/t1-3.jpg"></p>
</div>

<p><strong class="example">Example 3:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">mat = [[2,2],[2,2]], k = 3</span></p>

<p><strong>Output:</strong> <span class="example-io">true</span></p>

<p><strong>Explanation:</strong></p>

<p>As all the values are equal in the matrix, even after performing cyclic shifts the matrix will remain the same.</p>
</div>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= mat.length &lt;= 25</code></li>
	<li><code>1 &lt;= mat[i].length &lt;= 25</code></li>
	<li><code>1 &lt;= mat[i][j] &lt;= 25</code></li>
	<li><code>1 &lt;= k &lt;= 50</code></li>
</ul>
</div>

2946. Подобие матриц после циклических сдвигов
Просто<
<p>Вам дана целочисленная матрица <code>m x n</code> и целое число <code>k</code>. Строки матрицы имеют индексацию 0.</p>

<p>Следующий процесс происходит <code>k</code> раз:</p>

<ul>

<li><strong>Строки с четной индексацией</strong> (0, 2, 4, ...) циклически сдвигаются влево.</li>
</ul>

<p><img style="width: 283px; height: 90px;" src="https://assets.leetcode.com/uploads/2024/05/19/lshift.jpg"></p>

<ul>

<li><strong>Строки с нечетными индексами</strong> (1, 3, 5, ...) циклически сдвигаются вправо.</li>
</ul>

<p><img style="width: 283px; height: 90px;" src="https://assets.leetcode.com/uploads/2024/05/19/rshift-stlone.jpg"></p>

<p>Возвращает <code>true</code>, если итоговая модифицированная матрица после <code>k</code> шагов идентична исходной матрице, и <code>false</code> в противном случае.</p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<div class="example-block">
<p><strong>Входные данные:</strong> <span class="example-io">mat = [[1,2,3],[4,5,6],[7,8,9]], k = 4</span></p>

<p><strong>Выходные данные:</strong> <span class="example-io">false</span></p>

<p><strong>Пояснение:</strong></p>

<p>На каждом шаге сдвиг влево применяется к строкам 0 и 2 (четные индексы), а сдвиг вправо — к строке 1 (нечетный индекс).</p>

<p><img style="width: 857px; height: 150px;" src="https://assets.leetcode.com/uploads/2024/05/19/t1-2.jpg"></p>
</div>

<p><strong class="example">Пример 2:</strong></p>

<div class="example-block">
<p><strong>Ввод:</strong> <span class="example-io">mat = [[1,2,1,2],[5,5,5,5],[6,3,6,3]], k = 2</span></p>

<p><strong>Вывод:</strong> <span class="example-io">true</span></p>

<p><strong>Пояснение:</strong></p>

<p><img style="width: 632px; height: 150px;" src="https://assets.leetcode.com/uploads/2024/05/19/t1-3.jpg"></p>
</div>

<p><strong class="example">Пример 3:</strong></p>

<div class="example-block">
<p><strong>Входные данные:</strong> <span class="example-io">mat = [[2,2],[2,2]], k = 3</span></p>

<p><strong>Выходные данные:</strong> <span class="example-io">true</span></p>

<p><strong>Пояснение:</strong></p>

<p>Поскольку все значения в матрице равны, даже после выполнения циклических сдвигов матрица останется неизменной то же самое.</p>
</div>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>1 <= mat.length <= 25</code></li>

<li><code>1 <= mat[i].length <= 25</code></li>

<li><code>1 <= mat[i][j] <= 25</code></li>

<li><code>1 <= k <= 50</code></li>
</ul>
</div>
