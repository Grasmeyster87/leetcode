3689. Maximum Total Subarray Value I

Medium
<p>You are given an integer array <code>nums</code> of length <code>n</code> and an integer <code>k</code>.</p>

<p>You need to choose <strong>exactly</strong> <code>k</code> non-empty <span data-keyword="subarray-nonempty" class=" cursor-pointer relative text-dark-blue-s text-sm"><button type="button" aria-haspopup="dialog" aria-expanded="false" aria-controls="radix-_r_1p_" data-state="closed" class="">subarrays</button></span> <code>nums[l..r]</code> of <code>nums</code>. Subarrays may overlap, and the exact same subarray (same <code>l</code> and <code>r</code>) <strong>can</strong> be chosen more than once.</p>

<p>The <strong>value</strong> of a subarray <code>nums[l..r]</code> is defined as: <code>max(nums[l..r]) - min(nums[l..r])</code>.</p>

<p>The <strong>total value</strong> is the sum of the <strong>values</strong> of all chosen subarrays.</p>

<p>Return the <strong>maximum</strong> possible total value you can achieve.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums = [1,3,2], k = 2</span></p>

<p><strong>Output:</strong> <span class="example-io">4</span></p>

<p><strong>Explanation:</strong></p>

<p>One optimal approach is:</p>

<ul>
	<li>Choose <code>nums[0..1] = [1, 3]</code>. The maximum is 3 and the minimum is 1, giving a value of <code>3 - 1 = 2</code>.</li>
	<li>Choose <code>nums[0..2] = [1, 3, 2]</code>. The maximum is still 3 and the minimum is still 1, so the value is also <code>3 - 1 = 2</code>.</li>
</ul>

<p>Adding these gives <code>2 + 2 = 4</code>.</p>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums = [4,2,5,1], k = 3</span></p>

<p><strong>Output:</strong> <span class="example-io">12</span></p>

<p><strong>Explanation:</strong></p>

<p>One optimal approach is:</p>

<ul>
	<li>Choose <code>nums[0..3] = [4, 2, 5, 1]</code>. The maximum is 5 and the minimum is 1, giving a value of <code>5 - 1 = 4</code>.</li>
	<li>Choose <code>nums[0..3] = [4, 2, 5, 1]</code>. The maximum is 5 and the minimum is 1, so the value is also <code>4</code>.</li>
	<li>Choose <code>nums[2..3] = [5, 1]</code>. The maximum is 5 and the minimum is 1, so the value is again <code>4</code>.</li>
</ul>

<p>Adding these gives <code>4 + 4 + 4 = 12</code>.</p>
</div>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= n == nums.length &lt;= 5 * 10<sup>​​​​​​​4</sup></code></li>
	<li><code>0 &lt;= nums[i] &lt;= 10<sup>9</sup></code></li>
	<li><code>1 &lt;= k &lt;= 10<sup>5</sup></code></li>
</ul>

3689. Максимальне загальне значення підмасиву I

Середній
<p>Вам задано цілочисельний масив <code>nums</code> довжини <code>n</code> та ціле число <code>k</code>.</p>

<p>Вам потрібно вибрати <strong>рівно</strong> <code>k</code> непорожніх <span data-keyword="subarray-nonempty" class=" cursor-pointer relative text-dark-blue-s text-sm"><button type="button" aria-haspopup="dialog" aria-expanded="false" aria-controls="radix-_r_1p_" data-state="closed" class="">підмасивів</button></span> <code>nums[l..r]</code> з <code>nums</code>. Підмасиви можуть перекриватися, і той самий підмасив (однакові <code>l</code> та <code>r</code>) <strong>можна</strong> вибрати більше одного разу.</p>

<p><strong>Значення</strong> підмасиву <code>nums[l..r]</code> визначається як: <code>max(nums[l..r]) - min(nums[l..r])</code>.</p>

<p><strong>Загальне значення</strong> – це сума <strong>значень</strong> усіх вибраних підмасивів.</p>

<p>Повертає <strong>максимальне</strong> можливе загальне значення, якого ви можете досягти.</p>

<p>&nbsp;</p>
<p><strong class="example">Приклад 1:</strong></p>

<div class="example-block">
<p><strong>Вхід:</strong> <span class="example-io">nums = [1,3,2], k = 2</span></p>

<p><strong>Вивід:</strong> <span class="example-io">4</span></p>

<p><strong>Пояснення:</strong></p>

<p>Один з оптимальних підходів:</p>

<ul>
<li>Виберіть <code>nums[0..1] = [1, 3]</code>. Максимум дорівнює 3, а мінімум – 1, що дає значення <code>3 - 1 = 2</code>.</li>
<li>Виберіть <code>nums[0..2] = [1, 3, 2]</code>. Максимум все ще дорівнює 3, а мінімум — 1, тому значення також дорівнює <code>3 - 1 = 2</code>.</li>
</ul>

<p>Додавання цих чисел дає <code>2 + 2 = 4</code>.</p>
</div>

<p><strong class="example">Приклад 2:</strong></p>

<div class="example-block">
<p><strong>Вхід:</strong> <span class="example-io">числа = [4,2,5,1], k = 3</span></p>

<p><strong>Вихід:</strong> <span class="example-io">12</span></p>

<p><strong>Пояснення:</strong></p>

<p>Один з оптимальних підходів:</p>

<ul>
<li>Виберіть <code>числа[0..3] = [4, 2, 5, 1]</code>. Максимум дорівнює 5, а мінімум – 1, що дає значення <code>5 - 1 = 4</code>.</li>
<li>Виберіть <code>nums[0..3] = [4, 2, 5, 1]</code>. Максимум дорівнює 5, а мінімум – 1, тому значення також дорівнює <code>4</code>.</li>
<li>Виберіть <code>nums[2..3] = [5, 1]</code>. Максимум – 5, а мінімум – 1, тому значення знову дорівнює <code>4</code>.</li>
</ul>

<p>Додавання цих чисел дає <code>4 + 4 + 4 = 12</code>.</p>
</div>

<p>&nbsp;</p>
<p><strong>Обмеження:</strong></p>

<ul>
<li><code>1 <= n == nums.length <= 5 * 10<sup>​​​​​​​4</sup></code></li>
<li><code>0 <= nums[i] <= 10<sup>9</sup></code></li>
<li><code>1 <= k <= 10<sup>5</sup></code></li>
</ul>

Для **максимальної швидкодії** потрібно уникнути використання `Math.min(...nums)` і `Math.max(...nums)`, оскільки вони працюють за **O(n)** і викликаються для всього масиву. Замість цього можна **знайти мінімальний і максимальний елементи в одному проході** по масиву, що зменшить кількість операцій і прискорить роботу.

---

## **Оптимізоване рішення**

Ось оптимізована версія коду, яка знаходить `min` і `max` в **одному проході**:

```javascript
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
var maxTotalValue = function(nums, k) {
    let minVal = nums[0];
    let maxVal = nums[0];

    for (let i = 1; i < nums.length; i++) {
        if (nums[i] < minVal) minVal = nums[i];
        if (nums[i] > maxVal) maxVal = nums[i];
    }

    return k * (maxVal - minVal);
};
```

---

## **Чому це швидше?**

1. **Один прохід по масиву** замість двох (`Math.min` і `Math.max`).
2. **Зменшення кількості операцій** — не потрібно викликати функції `Math.min` і `Math.max`, які також працюють за **O(n)**.
3. **Менше навантаження на процесор** — менше викликів функцій і менше обчислень.

---

## **Часова складність**
- **O(n)** — один прохід по масиву для знаходження `min` і `max`.
- **O(1)** — обчислення результату.

---

## **Простір пам’яті**
- **O(1)** — не використовуються додаткові структури даних.

---

## **Порівняння з попереднім рішенням**
| Рішення | Часова складність | Кількість проходів | Швидкість |
|---------|------------------|---------------------|-----------|
| `Math.min` + `Math.max` | O(n) | 2 | Повільніше |
| **Оптимізоване** | **O(n)** | **1** | **Швидше** |
