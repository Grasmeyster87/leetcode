Эта функция использует изящный, хотя и немного абстрактный способ манипуляции массивами в JavaScript. Давай разберем её «на пальцах», используя конкретный пример матрицы $2 \times 2$.

### Исходная матрица (`mat`):
```javascript
const mat = [
  [1, 2],
  [3, 4]
];
```

---

### Шаг 1: Внешний `.map()` — Создание новых строк
```javascript
matrix[0].map((_, colIndex) => ... )
```
* **Что происходит:** Мы берем первую строку матрицы (`[1, 2]`) и итерируемся по её индексам.
* **Зачем:** В итоговой повернутой матрице будет столько же строк, сколько было столбцов в оригинале. Перебирая `colIndex` (0, затем 1), мы фактически говорим: «Сейчас мы соберем новую первую строку, а потом новую вторую».



---

### Шаг 2: Внутренний `.map()` — Извлечение столбца
```javascript
matrix.map(row => row[colIndex])
```
Теперь мы находимся внутри цикла для конкретного столбца (например, `colIndex = 0`).
* **Для `colIndex = 0`:** Мы заходим в каждую строку оригинала (`row`) и берем из нее элемент под индексом `0`. 
    * Из первой строки `[1, 2]` берем `1`.
    * Из второй строки `[3, 4]` берем `3`.
    * **Результат:** получаем массив `[1, 3]`. Это элементы **первого столбца**.



---

### Шаг 3: Метод `.reverse()` — Поворот по часовой стрелке
```javascript
.reverse()
```
Если мы просто оставим `[1, 3]`, то при подстановке в новую матрицу мы получим *транспонированную* матрицу (отраженную по диагонали). Чтобы получить именно **поворот по часовой стрелке**, элементы столбца должны идти в обратном порядке.
* Наш массив `[1, 3]` превращается в **`[3, 1]`**.

---

### Полная трассировка (Trace) примера $2 \times 2$

1.  **Первая итерация (`colIndex = 0`):**
    * Внутренний map собирает 0-й столбец: `[1, 3]`.
    * Применяем reverse: `[3, 1]`.
    * *Это становится нашей первой строкой.*

2.  **Вторая итерация (`colIndex = 1`):**
    * Внутренний map собирает 1-й столбец: `[2, 4]`.
    * Применяем reverse: `[4, 2]`.
    * *Это становится нашей второй строкой.*

**Итог:**
```javascript
[
  [3, 1],
  [4, 2]
]
```
Матрица успешно повернута на 90 градусов.

---

### Почему это работает для условий задачи?
* **Квадратная форма:** Код опирается на то, что количество строк равно количеству столбцов ($n \times n$), что гарантировано условиями задачи.
* **Масштабируемость:** Этот метод работает для любого $n$ в диапазоне от 1 до 10, указанном в ограничениях.

**Совет:** Этот подход создает *новые* массивы на каждой итерации. Для матриц $10 \times 10$ это не проблема, но если бы матрица была $1000 \times 1000$, такой код работал бы медленно из-за нагрузки на память. В таких случаях лучше менять элементы местами прямо в исходном массиве (in-place).
