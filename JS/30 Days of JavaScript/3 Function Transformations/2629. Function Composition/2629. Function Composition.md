2629. Function Composition

Given an array of functions [f1, f2, f3, ..., fn], return a new function fn that is the function composition of the array of functions.

The function composition of [f(x), g(x), h(x)] is fn(x) = f(g(h(x))).

The function composition of an empty list of functions is the identity function f(x) = x.

You may assume each function in the array accepts one integer as input and returns one integer as output.

 

Example 1:

Input: functions = [x => x + 1, x => x * x, x => 2 * x], x = 4
Output: 65
Explanation:
Evaluating from right to left ...
Starting with x = 4.
2 * (4) = 8
(8) * (8) = 64
(64) + 1 = 65

Example 2:

Input: functions = [x => 10 * x, x => 10 * x, x => 10 * x], x = 1
Output: 1000
Explanation:
Evaluating from right to left ...
10 * (1) = 10
10 * (10) = 100
10 * (100) = 1000

Example 3:

Input: functions = [], x = 42
Output: 42
Explanation:
The composition of zero functions is the identity function

 

Constraints:

    -1000 <= x <= 1000
    0 <= functions.length <= 1000
    all functions accept and return a single integer

2629. Композиция функций

Дано множество функций [f1, f2, f3, ..., fn]. Верните новую функцию fn, являющуюся композицией функций из этого множества.

Композиция функций [f(x), g(x), h(x)] — это fn(x) = f(g(h(x))).

Композиция функций пустого списка функций — это тождественная функция f(x) = x.

Можно предположить, что каждая функция в массиве принимает на вход одно целое число и возвращает на выход одно целое число.

Пример 1:

Входные данные: functions = [x => x + 1, x => x * x, x => 2 * x], x = 4
Выходные данные: 65
Пояснение:
Вычисление справа налево...
Начиная с x = 4.
2 * (4) = 8
(8) * (8) = 64
(64) + 1 = 65

Пример 2:

Входные данные: functions = [x => 10 * x, x => 10 * x, x => 10 * x], x = 1
Выходные данные: 1000
Пояснение:
Вычисление справа налево...
10 * (1) = 10
10 * (10) = 100
10 * (100) = 1000

Пример 3:

Входные данные: functions = [], x = 42
Выходные данные: 42
Пояснение:
Композиция нулевых функций — это тождественная функция.

Ограничения:

-1000 <= x <= 1000
0 <= functions.length <= 1000
все функции принимают и возвращают одно целое число.
