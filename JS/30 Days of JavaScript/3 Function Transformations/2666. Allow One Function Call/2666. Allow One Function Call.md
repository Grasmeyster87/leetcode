2666. Allow One Function Call

Given a function fn, return a new function that is identical to the original function except that it ensures fn is called at most once.

    The first time the returned function is called, it should return the same result as fn.
    Every subsequent time it is called, it should return undefined.

 

Example 1:

Input: fn = (a,b,c) => (a + b + c), calls = [[1,2,3],[2,3,6]]
Output: [{"calls":1,"value":6}]
Explanation:
const onceFn = once(fn);
onceFn(1, 2, 3); // 6
onceFn(2, 3, 6); // undefined, fn was not called

Example 2:

Input: fn = (a,b,c) => (a * b * c), calls = [[5,7,4],[2,3,6],[4,6,8]]
Output: [{"calls":1,"value":140}]
Explanation:
const onceFn = once(fn);
onceFn(5, 7, 4); // 140
onceFn(2, 3, 6); // undefined, fn was not called
onceFn(4, 6, 8); // undefined, fn was not called

 

Constraints:

    calls is a valid JSON array
    1 <= calls.length <= 10
    1 <= calls[i].length <= 100
    2 <= JSON.stringify(calls).length <= 1000

2666. Разрешить один вызов функции


Дана функция fn, верните новую функцию, идентичную исходной функции, за исключением того, что она гарантирует вызов fn не более одного раза.

При первом вызове возвращаемой функции она должна возвращать тот же результат, что и fn.

При каждом последующем вызове она должна возвращать undefined.

Пример 1:

Вход: fn = (a,b,c) => (a + b + c), calls = [[1,2,3],[2,3,6]]
Выход: [{"calls":1,"value":6}]
Пояснение:
const onceFn = once(fn);
onceFn(1, 2, 3); // 6
onceFn(2, 3, 6); // не определено, функция fn не была вызвана

Пример 2:

Входные данные: fn = (a,b,c) => (a * b * c), calls = [[5,7,4],[2,3,6],[4,6,8]]
Выходные данные: [{"calls":1,"value":140}]
Пояснение:
const onceFn = once(fn);
onceFn(5, 7, 4); // 140
onceFn(2, 3, 6); // не определено, функция fn не была вызвана
onceFn(4, 6, 8); // не определено, функция fn не была вызвана

Ограничения:

calls — допустимый массив JSON

1 <= calls.length <= 10

1 <= calls[i].length <= 100

2 <= JSON.stringify(calls).length <= 1000
