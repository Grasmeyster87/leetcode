Hint

Write code that enhances all arrays such that you can call the array.last() method on any array and it will return the last element. If there are no elements in the array, it should return -1.

You may assume the array is the output of JSON.parse.

 

Example 1:

Input: nums = [null, {}, 3]
Output: 3
Explanation: Calling nums.last() should return the last element: 3.

Example 2:

Input: nums = []
Output: -1
Explanation: Because there are no elements, return -1.

 

Constraints:

    arr is a valid JSON array
    0 <= arr.length <= 1000

Подсказка

Напишите код, который расширяет возможности всех массивов таким образом, чтобы метод array.last() можно было вызвать для любого массива, и он возвращал бы последний элемент. Если в массиве нет элементов, он должен возвращать -1.

Вы можете предположить, что массив является результатом выполнения JSON.parse.

Пример 1:

Вход: nums = [null, {}, 3]
Выход: 3
Пояснение: Вызов nums.last() должен возвращать последний элемент: 3.

Пример 2:

Вход: nums = []
Выход: -1
Пояснение: Поскольку элементов нет, верните -1.

Ограничения:

arr — допустимый JSON-массив

0 <= arr.length <= 1000
