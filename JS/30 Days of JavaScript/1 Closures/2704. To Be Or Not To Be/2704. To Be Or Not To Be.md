2704. To Be Or Not To Be

Write a function expect that helps developers test their code. It should take in any value val and return an object with the following two functions.

    toBe(val) accepts another value and returns true if the two values === each other. If they are not equal, it should throw an error "Not Equal".
    notToBe(val) accepts another value and returns true if the two values !== each other. If they are equal, it should throw an error "Equal".

 

Example 1:

Input: func = () => expect(5).toBe(5)
Output: {"value": true}
Explanation: 5 === 5 so this expression returns true.

Example 2:

Input: func = () => expect(5).toBe(null)
Output: {"error": "Not Equal"}
Explanation: 5 !== null so this expression throw the error "Not Equal".

Example 3:

Input: func = () => expect(5).notToBe(null)
Output: {"value": true}
Explanation: 5 !== null so this expression returns true.

2704. Быть или не быть

Напишите функцию expect, которая поможет разработчикам тестировать свой код. Она должна принимать любое значение val и возвращать объект со следующими двумя функциями.

toBe(val) принимает другое значение и возвращает true, если два значения равны друг другу. Если они не равны, должна быть выброшена ошибка "Не равно".

notToBe(val) принимает другое значение и возвращает true, если два значения не равны друг другу. Если они равны, должна быть выброшена ошибка "Равно".

Пример 1:

Вход: func = () => expect(5).toBe(5)
Выход: {"value": true}
Пояснение: 5 === 5, поэтому это выражение возвращает true.

Пример 2:

Входные данные: func = () => expect(5).toBe(null)
Выходные данные: {"error": "Не равно"}
Пояснение: 5 !== null, поэтому это выражение выдает ошибку "Не равно".

Пример 3:

Входные данные: func = () => expect(5).notToBe(null)
Выходные данные: {"value": true}
Пояснение: 5 !== null, поэтому это выражение возвращает true.
