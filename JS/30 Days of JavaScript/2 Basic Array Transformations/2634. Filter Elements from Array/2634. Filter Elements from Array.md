2634. Filter Elements from Array
Easy

Hint

Given an integer array arr and a filtering function fn, return a filtered array filteredArr.

The fn function takes one or two arguments:

    arr[i] - number from the arr
    i - index of arr[i]

filteredArr should only contain the elements from the arr for which the expression fn(arr[i], i) evaluates to a truthy value. A truthy value is a value where Boolean(value) returns true.

Please solve it without the built-in Array.filter method.

 

Example 1:

Input: arr = [0,10,20,30], fn = function greaterThan10(n) { return n > 10; }
Output: [20,30]
Explanation:
const newArray = filter(arr, fn); // [20, 30]
The function filters out values that are not greater than 10

Example 2:

Input: arr = [1,2,3], fn = function firstIndex(n, i) { return i === 0; }
Output: [1]
Explanation:
fn can also accept the index of each element
In this case, the function removes elements not at index 0

Example 3:

Input: arr = [-2,-1,0,1,2], fn = function plusOne(n) { return n + 1 }
Output: [-2,0,1,2]
Explanation:
Falsey values such as 0 should be filtered out

 

Constraints:

    0 <= arr.length <= 1000
    -109 <= arr[i] <= 109

2634. Фильтрация элементов из массива

Дана целочисленная матрица arr и функция фильтрации fn. Верните отфильтрованный массив filteredArr.

Функция fn принимает один или два аргумента:

arr[i] - число из массива arr

i - индекс arr[i]

filteredArr должен содержать только те элементы из массива arr, для которых выражение fn(arr[i], i) принимает истинное значение. Истинное значение - это значение, для которого Boolean(value) возвращает true.

Пожалуйста, решите задачу без использования встроенного метода Array.filter.

Пример 1:

Входные данные: arr = [0,10,20,30], fn = function greaterThan10(n) { return n > 10; }
Вывод: [20,30]
Пояснение:
const newArray = filter(arr, fn); // [20, 30]
Функция отфильтровывает значения, не превышающие 10

Пример 2:

Входные данные: arr = [1,2,3], fn = function firstIndex(n, i) { return i === 0; }
Вывод: [1]
Пояснение:
fn также может принимать индекс каждого элемента.
В этом случае функция удаляет элементы, не находящиеся по индексу 0.

Пример 3:

Входные данные: arr = [-2,-1,0,1,2], fn = function plusOne(n) { return n + 1 }
Вывод: [-2,0,1,2]
Пояснение:
Ложные значения, такие как 0, должны быть отфильтрованы.

Ограничения:

0 <= arr.length <= 1000

-109 <= arr[i] <= 109
