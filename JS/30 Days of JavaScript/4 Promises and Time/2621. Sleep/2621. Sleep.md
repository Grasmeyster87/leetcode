2621. Sleep

Given a positive integer millis, write an asynchronous function that sleeps for millis milliseconds. It can resolve any value.

Note that minor deviation from millis in the actual sleep duration is acceptable.

 

Example 1:

Input: millis = 100
Output: 100
Explanation: It should return a promise that resolves after 100ms.
let t = Date.now();
sleep(100).then(() => {
  console.log(Date.now() - t); // 100
});

Example 2:

Input: millis = 200
Output: 200
Explanation: It should return a promise that resolves after 200ms.

 

Constraints:

    1 <= millis <= 1000

2621. Сон

Дано положительное целое число millis. Напишите асинхронную функцию, которая приостанавливает сон на millis миллисекунд. Она может принимать любое значение.

Обратите внимание, что небольшое отклонение от millis в фактической продолжительности сна допустимо.

Пример 1:

Вход: millis = 100
Выход: 100
Пояснение: Функция должна возвращать промис, который разрешается через 100 мс.
let t = Date.now();

sleep(100).then(() => {
console.log(Date.now() - t); // 100
});

Пример 2:

Вход: millis = 200
Выход: 200
Пояснение: Функция должна возвращать промис, который разрешается через 200 мс.

Ограничения:

1 <= millis <= 1000
