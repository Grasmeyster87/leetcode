2637. Promise Time Limit
Medium
premium lock iconCompanies
Hint

Given an asynchronous function fn and a time t in milliseconds, return a new time limited version of the input function. fn takes arguments provided to the time limited function.

The time limited function should follow these rules:

    If the fn completes within the time limit of t milliseconds, the time limited function should resolve with the result.
    If the execution of the fn exceeds the time limit, the time limited function should reject with the string "Time Limit Exceeded".

 

Example 1:

Input: 
fn = async (n) => { 
  await new Promise(res => setTimeout(res, 100)); 
  return n * n; 
}
inputs = [5]
t = 50
Output: {"rejected":"Time Limit Exceeded","time":50}
Explanation:
const limited = timeLimit(fn, t)
const start = performance.now()
let result;
try {
   const res = await limited(...inputs)
   result = {"resolved": res, "time": Math.floor(performance.now() - start)};
} catch (err) {
   result = {"rejected": err, "time": Math.floor(performance.now() - start)};
}
console.log(result) // Output

The provided function is set to resolve after 100ms. However, the time limit is set to 50ms. It rejects at t=50ms because the time limit was reached.

Example 2:

Input: 
fn = async (n) => { 
  await new Promise(res => setTimeout(res, 100)); 
  return n * n; 
}
inputs = [5]
t = 150
Output: {"resolved":25,"time":100}
Explanation:
The function resolved 5 * 5 = 25 at t=100ms. The time limit is never reached.

Example 3:

Input: 
fn = async (a, b) => { 
  await new Promise(res => setTimeout(res, 120)); 
  return a + b; 
}
inputs = [5,10]
t = 150
Output: {"resolved":15,"time":120}
Explanation:
​​​​The function resolved 5 + 10 = 15 at t=120ms. The time limit is never reached.

Example 4:

Input: 
fn = async () => { 
  throw "Error";
}
inputs = []
t = 1000
Output: {"rejected":"Error","time":0}
Explanation:
The function immediately throws an error.

 

Constraints:

    0 <= inputs.length <= 10
    0 <= t <= 1000
    fn returns a promise

2637. Ограничение времени выполнения промиса
Средний
Премиум значок блокировки Компании
Подсказка

Дана асинхронная функция fn и время t в миллисекундах. Верните новую версию входной функции с ограничением времени. Функция fn принимает аргументы, переданные функции с ограничением времени.

Функция с ограничением времени должна соответствовать следующим правилам:

Если функция fn завершается в течение времени, ограниченного t миллисекундами, функция с ограничением времени должна завершиться с результатом.

Если выполнение функции fn превышает лимит времени, функция с ограничением времени должна отклонить запрос со строкой "Превышен лимит времени".

Пример 1:

Входные данные:
fn = async (n) => {
await new Promise(res => setTimeout(res, 100));
return n * n;

}
входные данные = [5]
t = 50
Вывод: {"отклонено":"Превышен лимит времени","время":50}
Пояснение:
const limited = timeLimit(fn, t)
const start = performance.now()
let result;
try {
const res = await limited(...inputs)
result = {"решено": res, "время": Math.floor(performance.now() - start)};

} catch (err) {
result = {"отклонено": err, "время": Math.floor(performance.now() - start)};

}
console.log(result) // Вывод

Предоставленная функция настроена на разрешение через 100 мс. Однако лимит времени установлен на 50 мс. Она отклоняет запрос при t=50 мс, потому что был достигнут лимит времени.

Пример 2:

Входные данные:
fn = async (n) => {
await new Promise(res => setTimeout(res, 100));
return n * n;
}
inputs = [5]
t = 150
Выходные данные: {"resolved":25,"time":100}
Пояснение:
Функция разрешилась за 5 * 5 = 25 при t=100 мс. Лимит времени никогда не достигается.

Пример 3:

Входные данные:
fn = async (a, b) => {
await new Promise(res => setTimeout(res, 120));
return a + b;
}
входные данные = [5,10]
t = 150
Выход: {"resolved":15,"time":120}
Пояснение:
Функция разрешила 5 + 10 = 15 при t = 120 мс. Лимит времени никогда не достигается.

Пример 4:

Входные данные:
fn = async () => {
throw "Error";

}
входные данные = []
t = 1000
Выход: {"rejected":"Error","time":0}
Пояснение:
Функция немедленно выдает ошибку.
