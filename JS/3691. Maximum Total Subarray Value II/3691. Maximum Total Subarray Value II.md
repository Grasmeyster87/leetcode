3691. Maximum Total Subarray Value II

Hard
<p>You are given an integer array <code>nums</code> of length <code>n</code> and an integer <code>k</code>.</p>

<p>You must select <strong>exactly</strong> <code>k</code> <strong>distinct</strong> <span data-keyword="subarray-nonempty" class=" cursor-pointer relative text-dark-blue-s text-sm"><button type="button" aria-haspopup="dialog" aria-expanded="false" aria-controls="radix-_r_1p_" data-state="closed" class="">subarrays</button></span> <code>nums[l..r]</code> of <code>nums</code>. Subarrays may overlap, but the exact same subarray (same <code>l</code> and <code>r</code>) <strong>cannot</strong> be chosen more than once.</p>

<p>The <strong>value</strong> of a subarray <code>nums[l..r]</code> is defined as: <code>max(nums[l..r]) - min(nums[l..r])</code>.</p>

<p>The <strong>total value</strong> is the sum of the <strong>values</strong> of all chosen subarrays.</p>

<p>Return the <strong>maximum</strong> possible total value you can achieve.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums = [1,3,2], k = 2</span></p>

<p><strong>Output:</strong> <span class="example-io">4</span></p>

<p><strong>Explanation:</strong></p>

<p>One optimal approach is:</p>

<ul>
	<li>Choose <code>nums[0..1] = [1, 3]</code>. The maximum is 3 and the minimum is 1, giving a value of <code>3 - 1 = 2</code>.</li>
	<li>Choose <code>nums[0..2] = [1, 3, 2]</code>. The maximum is still 3 and the minimum is still 1, so the value is also <code>3 - 1 = 2</code>.</li>
</ul>

<p>Adding these gives <code>2 + 2 = 4</code>.</p>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums = [4,2,5,1], k = 3</span></p>

<p><strong>Output:</strong> <span class="example-io">12</span></p>

<p><strong>Explanation:</strong></p>

<p>One optimal approach is:</p>

<ul>
	<li>Choose <code>nums[0..3] = [4, 2, 5, 1]</code>. The maximum is 5 and the minimum is 1, giving a value of <code>5 - 1 = 4</code>.</li>
	<li>Choose <code>nums[1..3] = [2, 5, 1]</code>. The maximum is 5 and the minimum is 1, so the value is also <code>4</code>.</li>
	<li>Choose <code>nums[2..3] = [5, 1]</code>. The maximum is 5 and the minimum is 1, so the value is again <code>4</code>.</li>
</ul>

<p>Adding these gives <code>4 + 4 + 4 = 12</code>.</p>
</div>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= n == nums.length &lt;= 5 * 10<sup>​​​​​​​4</sup></code></li>
	<li><code>0 &lt;= nums[i] &lt;= 10<sup>9</sup></code></li>
	<li><code>1 &lt;= k &lt;= min(10<sup>5</sup>, n * (n + 1) / 2)</code></li>
</ul>

3691. Максимальне загальне значення підмасиву II

Складно
<p>Вам задано цілочисельний масив <code>nums</code> довжини <code>n</code> та ціле число <code>k</code>.</p>

<p>Ви повинні вибрати <strong>рівно</strong> <code>k</code> <strong>різних</strong> <span data-keyword="subarray-nonempty" class=" cursor-pointer relative text-dark-blue-s text-sm"><button type="button" aria-haspopup="dialog" aria-expanded="false" aria-controls="radix-_r_1p_" data-state="closed" class="">підмасивів</button></span> <code>nums[l..r]</code> з <code>nums</code>. Підмасиви можуть перекриватися, але той самий підмасив (однакові <code>l</code> та <code>r</code>) <strong>не можна</strong> вибрати більше одного разу.</p>

<p><strong>Значення</strong> підмасиву <code>nums[l..r]</code> визначається як: <code>max(nums[l..r]) - min(nums[l..r])</code>.</p>

<p><strong>Загальне значення</strong> – це сума <strong>значень</strong> усіх вибраних підмасивів.</p>

<p>Повертає <strong>максимальне</strong> можливе загальне значення, якого ви можете досягти.</p>

<p>&nbsp;</p>
<p><strong class="example">Приклад 1:</strong></p>

<div class="example-block">
<p><strong>Вхід:</strong> <span class="example-io">nums = [1,3,2], k = 2</span></p>

<p><strong>Вивід:</strong> <span class="example-io">4</span></p>

<p><strong>Пояснення:</strong></p>

<p>Один з оптимальних підходів:</p>

<ul>
<li>Виберіть <code>nums[0..1] = [1, 3]</code>. Максимум дорівнює 3, а мінімум – 1, що дає значення <code>3 - 1 = 2</code>.</li>
<li>Виберіть <code>nums[0..2] = [1, 3, 2]</code>. Максимум все ще дорівнює 3, а мінімум — 1, тому значення також дорівнює <code>3 - 1 = 2</code>.</li>
</ul>

<p>Додавання цих чисел дає <code>2 + 2 = 4</code>.</p>
</div>

<div class="example-block">
<p><strong>Вхід:</strong> <span class="example-io">числа = [4,2,5,1], k = 3</span></p>

<p><strong>Вихід:</strong> <span class="example-io">12</span></p>

<p>Один з оптимальних підходів:</p>

<ul>

<li>Виберіть <code>nums[1..3] = [2, 5, 1]</code>. Максимум дорівнює 5, а мінімум – 1, тому значення також дорівнює <code>4</code>.</li>
<li>Виберіть <code>nums[2..3] = [5, 1]</code>. Максимум – 5, а мінімум – 1, тому значення знову дорівнює <code>4</code>.</li>
</ul>

<p>Додавання цих чисел дає <code>4 + 4 + 4 = 12</code>.</p>

<ul>
<li><code>1 <= n == nums.length <= 5 * 10<sup>​​​​​​​4</sup></code></li>
<li><code>0 <= nums[i] <= 10<sup>9</sup></code></li>
<li><code>1 <= k <= min(10<sup>5</sup>, n * (n + 1) / 2)</code></li>

### Пояснення рішення і покроковий розбір коду

#### Коротко
**Мета** — вибрати рівно `k` різних підмасивів так, щоб сума `max - min` по кожному була максимальною.  
**Ідея** — для швидкого обчислення `max` і `min` на будь-якому відрізку використовуємо **Sparse Table** (O(1)-запит). Далі генеруємо кандидати «ледачо» через **max-heap**: для кожного лівого індексу `i` початково кладемо сегмент `[i, n-1]`. Кожного разу беремо з купи сегмент з найбільшим значенням, додаємо його в результат і, якщо можливо, замінюємо праву межу `r` на `r-1` (пушимо `[l, r-1]`). Повторюємо `k` разів.

---

#### Чому це працює
- Для фіксованого лівого індексу `l` значення `v(l, r) = max(nums[l..r]) - min(nums[l..r])` **монотонно не зростає** при зменшенні `r`. Тому, почавши з найбільшого `r = n-1` і поступово зменшуючи `r`, ми перетинаємо всі можливі підмасиви з тим самим `l` у порядку невід’ємного спадання їх значення.  
- Використовуючи max-heap, завжди беремо глобально найкращий доступний підмасив. Оскільки для кожного `l` ми породжуємо наступний кандидат лише після вибору поточного, ми не генеруємо всі `O(n^2)` підмасиви одразу — пам’ять і час керовані.

---

#### Складність
- **Побудова Sparse Table:** O(n log n) часу і пам’яті.  
- **k витягів з купи:** кожен `pop`/`push` — O(log n), отже O(k log n).  
- **Разом:** **O(n log n + k log n)** часу, пам’ять O(n log n).

---

#### Обмеження і зауваження
- Для сум використовуємо `Number`. Для гарантованої безпеки при дуже великих сум можна перейти на `BigInt`.  
- Алгоритм припускає `k <= total_subarrays`; якщо heap спорожніє раніше, цикл зупиняється.  
- Sparse Table підходить, бо запити на максимум/мінімум статичні.

---

### Код з покроковими коментарями

```javascript
// Функція, яку викликає раннер: maxTotalValue(nums, k)
function maxTotalValue(nums, k) {
  // n — довжина масиву
  const n = nums.length;
  if (n === 0 || k === 0) return 0; // швидкий випадок

  // Побудова таблиці логарифмів: lg[len] = floor(log2(len))
  const lg = new Array(n + 1).fill(0);
  for (let i = 2; i <= n; ++i) lg[i] = lg[i >> 1] + 1;
  const LOG = lg[n] + 1; // кількість рівнів у Sparse Table

  // Ініціалізація Sparse Table для максимуму і мінімуму
  const stMax = Array.from({ length: LOG }, () => new Array(n));
  const stMin = Array.from({ length: LOG }, () => new Array(n));
  for (let i = 0; i < n; ++i) {
    stMax[0][i] = nums[i]; // рівень 0 зберігає самі елементи
    stMin[0][i] = nums[i];
  }

  // Побудова вищих рівнів: для кожного j беремо два інтервали довжини 2^(j-1)
  for (let j = 1; j < LOG; ++j) {
    const half = 1 << (j - 1); // довжина половини інтервалу
    for (let i = 0; i + (1 << j) <= n; ++i) {
      // максимум на інтервалі довжини 2^j = max з двох половин
      stMax[j][i] = Math.max(stMax[j - 1][i], stMax[j - 1][i + half]);
      // мінімум аналогічно
      stMin[j][i] = Math.min(stMin[j - 1][i], stMin[j - 1][i + half]);
    }
  }

  // Функція, що повертає max(nums[L..R]) - min(nums[L..R]) за O(1)
  const getDiff = (L, R) => {
    const j = lg[R - L + 1]; // найбільший степінь двійки, що вміщується
    const mx = Math.max(stMax[j][L], stMax[j][R - (1 << j) + 1]);
    const mn = Math.min(stMin[j][L], stMin[j][R - (1 << j) + 1]);
    return mx - mn;
  };

  // Проста реалізація max-heap (пріоритетна черга за полем val)
  class MaxHeap {
    constructor() { this.a = []; } // масив-купка
    size() { return this.a.length; }
    push(node) {
      this.a.push(node);
      this._siftUp(this.a.length - 1); // піднімаємо новий елемент
    }
    pop() {
      if (this.a.length === 0) return null;
      const top = this.a[0];
      const last = this.a.pop();
      if (this.a.length > 0) {
        this.a[0] = last;
        this._siftDown(0); // опускаємо замінник
      }
      return top;
    }
    _siftUp(i) {
      while (i > 0) {
        const p = (i - 1) >> 1;
        if (this.a[p].val >= this.a[i].val) break;
        [this.a[p], this.a[i]] = [this.a[i], this.a[p]];
        i = p;
      }
    }
    _siftDown(i) {
      const n = this.a.length;
      while (true) {
        let l = i * 2 + 1;
        let r = i * 2 + 2;
        let largest = i;
        if (l < n && this.a[l].val > this.a[largest].val) largest = l;
        if (r < n && this.a[r].val > this.a[largest].val) largest = r;
        if (largest === i) break;
        [this.a[i], this.a[largest]] = [this.a[largest], this.a[i]];
        i = largest;
      }
    }
  }

  // Ініціалізуємо купу сегментами [i, n-1] для всіх i
  const heap = new MaxHeap();
  for (let i = 0; i < n; ++i) {
    heap.push({ val: getDiff(i, n - 1), l: i, r: n - 1 });
  }

  // Витягуємо k разів найкращий сегмент і породжуємо наступний для того ж l
  let ans = 0;
  for (let t = 0; t < k; ++t) {
    const cur = heap.pop();
    if (!cur) break; // якщо купа порожня — вихід
    ans += cur.val; // додаємо значення сегмента до відповіді
    if (cur.r > cur.l) {
      const nr = cur.r - 1; // зменшуємо праву межу
      heap.push({ val: getDiff(cur.l, nr), l: cur.l, r: nr }); // пушимо новий кандидат
    }
  }
  return ans;
}

// Приклади
// console.log(maxTotalValue([1,3,2], 2)); // очікується 4
// console.log(maxTotalValue([4,2,5,1], 3)); // очікується 12
```

---

#### Коротке резюме
- **Sparse Table** дає O(1)-запити `max`/`min`.  
- **Max-heap** + «ледача» генерація сегментів дозволяє отримати `k` найкращих підмасивів без повної перебірної генерації.  
- Алгоритм ефективний для заданих обмежень і простий у реалізації.  

Якщо хочете, можу додати **версію з BigInt**, або пояснити, як змінити підхід, щоб зменшити пам’ять (наприклад, замінити Sparse Table на сегментне дерево з O(log n) запитом).
