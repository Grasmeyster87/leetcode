1594. Maximum Non Negative Product in a Matrix>
<br>Hint
<p>You are given a <code>m x n</code> matrix <code>grid</code>. Initially, you are located at the top-left corner <code>(0, 0)</code>, and in each step, you can only <strong>move right or down</strong> in the matrix.</p>

<p>Among all possible paths starting from the top-left corner <code>(0, 0)</code> and ending in the bottom-right corner <code>(m - 1, n - 1)</code>, find the path with the <strong>maximum non-negative product</strong>. The product of a path is the product of all integers in the grid cells visited along the path.</p>

<p>Return the <em>maximum non-negative product <strong>modulo</strong> </em><code>10<sup>9</sup> + 7</code>. <em>If the maximum product is <strong>negative</strong>, return </em><code>-1</code>.</p>

<p>Notice that the modulo is performed after getting the maximum product.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>
<img alt="" style="width: 244px; height: 245px;" src="https://assets.leetcode.com/uploads/2021/12/23/product1.jpg">
<pre><strong>Input:</strong> grid = [[-1,-2,-3],[-2,-3,-3],[-3,-3,-2]]
<strong>Output:</strong> -1
<strong>Explanation:</strong> It is not possible to get non-negative product in the path from (0, 0) to (2, 2), so return -1.
</pre>

<p><strong class="example">Example 2:</strong></p>
<img alt="" style="width: 244px; height: 245px;" src="https://assets.leetcode.com/uploads/2021/12/23/product2.jpg">
<pre><strong>Input:</strong> grid = [[1,-2,1],[1,-2,1],[3,-4,1]]
<strong>Output:</strong> 8
<strong>Explanation:</strong> Maximum non-negative product is shown (1 * 1 * -2 * -4 * 1 = 8).
</pre>

<p><strong class="example">Example 3:</strong></p>
<img alt="" style="width: 164px; height: 165px;" src="https://assets.leetcode.com/uploads/2021/12/23/product3.jpg">
<pre><strong>Input:</strong> grid = [[1,3],[0,-4]]
<strong>Output:</strong> 0
<strong>Explanation:</strong> Maximum non-negative product is shown (1 * 0 * -4 = 0).
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>m == grid.length</code></li>
	<li><code>n == grid[i].length</code></li>
	<li><code>1 &lt;= m, n &lt;= 15</code></li>
	<li><code>-4 &lt;= grid[i][j] &lt;= 4</code>
</ul>

1594. Максимальное неотрицательное произведение в матрице>
<br>Подсказка
<p>Вам дана матрица размером <code>m x n</code> в виде сетки</code>. Изначально вы находитесь в верхнем левом углу <code>(0, 0)</code>, и на каждом шаге вы можете двигаться только вправо или вниз</strong> по матрице.</p>

<p>Среди всех возможных путей, начинающихся из верхнего левого угла <code>(0, 0)</code> и заканчивающихся в нижнем правом углу <code>(m - 1, n - 1)</code>, найдите путь с <strong>максимальным неотрицательным произведением</strong>. Произведение элементов пути — это произведение всех целых чисел в ячейках сетки, посещенных вдоль пути.</p>

<p>Возвращает <em>максимальное неотрицательное произведение по модулю</strong> </em><code>10<sup>9</sup> + 7</code>. <em>Если максимальное произведение <strong>отрицательное</strong>, возвращает </em><code>-1</code>.</p>

<p>Обратите внимание, что операция взятия остатка от деления выполняется после получения максимального произведения.</p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>
<img alt="" style="width: 244px; height: 245px;" src="https://assets.leetcode.com/uploads/2021/12/23/product1.jpg">
<pre><strong>Входные данные:</strong> grid = [[-1,-2,-3],[-2,-3,-3],[-3,-3,-2]]
<strong>Выходные данные:</strong> -1
<strong>Пояснение:</strong> Невозможно получить неотрицательное произведение на пути от (0, 0) до (2, 2), поэтому возвращаем -1.

</pre>

<p><strong class="example">Пример 2:</strong></p>
<img alt="" style="width: 244px; height: 245px;" src="https://assets.leetcode.com/uploads/2021/12/23/product2.jpg">
<pre><strong>Ввод:</strong> grid = [[1,-2,1],[1,-2,1],[3,-4,1]]
<strong>Вывод:</strong> 8
<strong>Пояснение:</strong> Показано максимальное неотрицательное произведение (1 * 1 * -2 * -4 * 1 = 8).

</pre>

<p><strong class="example">Пример 3:</strong></p>
<img alt="" style="width: 164px; height: 165px;" src="https://assets.leetcode.com/uploads/2021/12/23/product3.jpg">
<pre><strong>Входные данные:</strong> grid = [[1,3],[0,-4]]
<strong>Выходные данные:</strong> 0
<strong>Пояснение:</strong> Показано максимальное неотрицательное произведение (1 * 0 * -4 = 0).

</pre>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>m == grid.length</code></li>

<li><code>n == grid[i].length</code></li>

<li><code>1 <= m, n <= 15</code></li>
<li><code>-4 <= grid[i][j] <= 4</code>
</ul>
