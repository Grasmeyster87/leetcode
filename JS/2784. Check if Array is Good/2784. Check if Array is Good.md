2784. Check if Array is Good

Easy
<p>You are given an integer array <code>nums</code>. We consider an array <strong>good </strong>if it is a permutation of an array <code>base[n]</code>.</p>

<p><code>base[n] = [1, 2, ..., n - 1, n, n] </code>(in other words, it is an array of length <code>n + 1</code> which contains <code>1</code> to <code>n - 1 </code>exactly once, plus two occurrences of <code>n</code>). For example, <code>base[1] = [1, 1]</code> and<code> base[3] = [1, 2, 3, 3]</code>.</p>

<p>Return <code>true</code> <em>if the given array is good, otherwise return</em><em> </em><code>false</code>.</p>

<p><strong>Note: </strong>A permutation of integers represents an arrangement of these numbers.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<pre><strong>Input:</strong> nums = [2, 1, 3]
<strong>Output:</strong> false
<strong>Explanation:</strong> Since the maximum element of the array is 3, the only candidate n for which this array could be a permutation of base[n], is n = 3. However, base[3] has four elements but array nums has three. Therefore, it can not be a permutation of base[3] = [1, 2, 3, 3]. So the answer is false.
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre><strong>Input:</strong> nums = [1, 3, 3, 2]
<strong>Output:</strong> true
<strong>Explanation:</strong> Since the maximum element of the array is 3, the only candidate n for which this array could be a permutation of base[n], is n = 3. It can be seen that nums is a permutation of base[3] = [1, 2, 3, 3] (by swapping the second and fourth elements in nums, we reach base[3]). Therefore, the answer is true.</pre>

<p><strong class="example">Example 3:</strong></p>

<pre><strong>Input:</strong> nums = [1, 1]
<strong>Output:</strong> true
<strong>Explanation:</strong> Since the maximum element of the array is 1, the only candidate n for which this array could be a permutation of base[n], is n = 1. It can be seen that nums is a permutation of base[1] = [1, 1]. Therefore, the answer is true.</pre>

<p><strong class="example">Example 4:</strong></p>

<pre><strong>Input:</strong> nums = [3, 4, 4, 1, 2, 1]
<strong>Output:</strong> false
<strong>Explanation:</strong> Since the maximum element of the array is 4, the only candidate n for which this array could be a permutation of base[n], is n = 4. However, base[4] has five elements but array nums has six. Therefore, it can not be a permutation of base[4] = [1, 2, 3, 4, 4]. So the answer is false.
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= nums.length &lt;= 100</code></li>
	<li><code>1 &lt;= num[i] &lt;= 200</code></li>
</ul>

2784. Перевірка, чи масив є правильним

Легко
<p>Вам задано цілочисельний масив <code>nums</code>. Ми вважаємо масив <strong>правильним</strong>, якщо він є перестановкою масиву <code>base[n]</code>.</p>

<p><code>base[n] = [1, 2, ..., n - 1, n, n] </code>(іншими словами, це масив довжини <code>n + 1</code>, який містить від <code>1</code> до <code>n - 1 </code>рівно один раз, плюс два входження <code>n</code>). Наприклад, <code>base[1] = [1, 1]</code> та<code> base[3] = [1, 2, 3, 3]</code>.</p>

<p>Повертає <code>true</code> <em>якщо заданий масив правильний, інакше повертає</em><em> </em><code>false</code>.</p>

<p><strong>Примітка: </strong>Перестановка цілих чисел представляє собою розташування цих чисел.</p>

<p>&nbsp;</p>
<p><strong class="example">Приклад 1:</strong></p>

<pre><strong>Вхід:</strong> nums = [2, 1, 3]
<strong>Вихід:</strong> false
<strong>Пояснення:</strong> Оскільки максимальний елемент масиву дорівнює 3, єдиним кандидатом n, для якого цей масив може бути перестановкою base[n], є n = 3. Однак, base[3] має чотири елементи, але масив nums має три. Отже, він не може бути перестановкою base[3] = [1, 2, 3, 3]. Отже, відповідь хибна.
</pre>

<p><strong class="example">Приклад 2:</strong></p>

<pre><strong>Вхід:</strong> nums = [1, 3, 3, 2]
<strong>Вихід:</strong> true
<strong>Пояснення:</strong> Оскільки максимальний елемент масиву дорівнює 3, єдиним кандидатом n, для якого цей масив може бути перестановкою base[n], є n = 3. Видно, що nums є перестановкою base[3] = [1, 2, 3, 3] (помінявши місцями другий та четвертий елементи в nums, ми отримуємо base[3]). Отже, відповідь істинна.</pre>

<p><strong class="example">Приклад 3:</strong></p>

<pre><strong>Вхід:</strong> nums = [1, 1]
<strong>Вихід:</strong> true
<strong>Пояснення:</strong> Оскільки максимальний елемент масиву дорівнює 1, єдиним кандидатом n, для якого цей масив може бути перестановкою base[n], є n = 1. Видно, що nums є перестановкою base[1] = [1, 1]. Отже, відповідь істинна.</pre>

<p><strong class="example">Приклад 4:</strong></p>

<pre><strong>Вхід:</strong> nums = [3, 4, 4, 1, 2, 1]
<strong>Вихід:</strong> false
<strong>Пояснення:</strong> Оскільки максимальний елемент масиву дорівнює 4, єдиним кандидатом n, для якого цей масив може бути перестановкою base[n], є n = 4. Однак, base[4] має п'ять елементів, а масив nums має шість. Отже, він не може бути перестановкою base[4] = [1, 2, 3, 4, 4]. Отже, відповідь хибна.

</pre>

<p>&nbsp;</p>
<p><strong>Обмеження:</strong></p>

<ul>
<li><code>1 <= nums.length <= 100</code></li>
<li><code>1 <= num[i] <= 200</code></li>
</ul>
