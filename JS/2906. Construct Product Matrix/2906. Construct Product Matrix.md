2906. Construct Product Matrix

Hint

Given a 0-indexed 2D integer matrix grid of size n * m, we define a 0-indexed 2D matrix p of size n * m as the product matrix of grid if the following condition is met:

    Each element p[i][j] is calculated as the product of all elements in grid except for the element grid[i][j]. This product is then taken modulo 12345.

Return the product matrix of grid.

 

Example 1:

Input: grid = [[1,2],[3,4]]
Output: [[24,12],[8,6]]
Explanation: p[0][0] = grid[0][1] * grid[1][0] * grid[1][1] = 2 * 3 * 4 = 24
p[0][1] = grid[0][0] * grid[1][0] * grid[1][1] = 1 * 3 * 4 = 12
p[1][0] = grid[0][0] * grid[0][1] * grid[1][1] = 1 * 2 * 4 = 8
p[1][1] = grid[0][0] * grid[0][1] * grid[1][0] = 1 * 2 * 3 = 6
So the answer is [[24,12],[8,6]].

Example 2:

Input: grid = [[12345],[2],[1]]
Output: [[2],[0],[0]]
Explanation: p[0][0] = grid[0][1] * grid[0][2] = 2 * 1 = 2.
p[0][1] = grid[0][0] * grid[0][2] = 12345 * 1 = 12345. 12345 % 12345 = 0. So p[0][1] = 0.
p[0][2] = grid[0][0] * grid[0][1] = 12345 * 2 = 24690. 24690 % 12345 = 0. So p[0][2] = 0.
So the answer is [[2],[0],[0]].

 

Constraints:

    1 <= n == grid.length <= 105
    1 <= m == grid[i].length <= 105
    2 <= n * m <= 105
    1 <= grid[i][j] <= 109

2906. Построение матрицы произведений
Средний уровень сложности
Темы

Подсказка

Дана двумерная целочисленная матрица grid размером n * m с индексацией 0. Мы определяем двумерную матрицу p размером n * m с индексацией 0 как матрицу произведений grid, если выполняется следующее условие:

Каждый элемент p[i][j] вычисляется как произведение всех элементов grid, кроме элемента grid[i][j]. Затем это произведение берется по модулю 12345.

Вернуть матрицу произведений grid.

Пример 1:

Входные данные: grid = [[1,2],[3,4]]
Выходные данные: [[24,12],[8,6]]
Пояснение: p[0][0] = grid[0][1] * grid[1][0] * grid[1][1] = 2 * 3 * 4 = 24
p[0][1] = grid[0][0] * grid[1][0] * grid[1][1] = 1 * 3 * 4 = 12
p[1][0] = grid[0][0] * grid[0][1] * grid[1][1] = 1 * 2 * 4 = 8
p[1][1] = grid[0][0] * grid[0][1] * grid[1][0] = 1 * 2 * 3 = 6
Таким образом, ответ: [[24,12],[8,6]].

Пример 2:

Входные данные: grid = [[12345],[2],[1]]
Выходные данные: [[2],[0],[0]]
Пояснение: p[0][0] = grid[0][1] * grid[0][2] = 2 * 1 = 2.
p[0][1] = grid[0][0] * grid[0][2] = 12345 * 1 = 12345. 12345 % 12345 = 0. Следовательно, p[0][1] = 0.
p[0][2] = grid[0][0] * grid[0][1] = 12345 * 2 = 24690. 24690 % 12345 = 0. Следовательно, p[0][2] = 0.
Таким образом, ответ: [[2],[0],[0]].

Ограничения:

1 <= n == grid.length <= 105
1 <= m == grid[i].length <= 105
2 <= n * m <= 105
1 <= grid[i][j] <= 109


Це чудове питання! Плутанина виникає через те, що в українській (та інших слов'янських) мовах слово **"модуль"** має два абсолютно різних значення в математиці та програмуванні.

### 1. Різниця між значеннями

* **Абсолютна величина (Absolute Value):** Це те, про що ви згадали: $|-1| = 1$. Це відстань від числа до нуля. В програмуванні це зазвичай функція `abs()`.
* **Остача від ділення (Modulo Operation):** В контексті криптографії, алгоритмів та цієї задачі, слово "модуль" означає **остачу від цілочисельного ділення**. В програмуванні це оператор `%`.

Коли в задачі написано "taken modulo 12345", це означає:
$$x \pmod{12345}$$
Тобто ми ділимо число на $12345$ і беремо лише те, що залишилося.

---

### 2. Чому в Прикладі 2 результат 0?

Давайте розберемо крок за кроком на основі вашої умови:

1.  У нас є число $12345$.
2.  Нам потрібно знайти його значення "за модулем $12345$".
3.  Рахуємо: $12345 / 12345 = 1$ (ціла частина) і **остача $0$**.
4.  Оскільки $12345$ ділиться на $12345$ націло, остача дорівнює $0$.


**Ще кілька прикладів для закріплення:**
* $12346 \pmod{12345} = 1$ (бо $12345$ входить один раз і залишається $1$).
* $10 \pmod{12345} = 10$ (бо $12345$ входить нуль разів і залишається $10$).
* $24690 \pmod{12345} = 0$ (бо це рівно $12345 \times 2$).

---

### 3. Навіщо це в задачі?

В цій задачі добуток усіх чисел у матриці може бути неймовірно величезним (наприклад, $10^9$ у степені $10^5$). Таке число не поміститься в пам'ять жодного комп'ютера. Тому програмістів просять повертати результат "за модулем" — це тримає числа в межах діапазону від $0$ до $12344$.

**Порада для вирішення:**
Оскільки вам потрібно знайти добуток усіх елементів, крім одного, найкраща стратегія тут — використати **Prefix Products** (префіксні добутки) та **Suffix Products** (суфіксні добутки). Ви проходите матрицю один раз з початку до кінця і один раз з кінця до початку, перемножуючи числа та застосовуючи `% 12345` на кожному кроці.
