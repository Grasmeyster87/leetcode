3474. Lexicographically Smallest Generated String
<br> Hard
<p>You are given two strings, <code>str1</code> and <code>str2</code>, of lengths <code>n</code> and <code>m</code>, respectively.</p>

<p>A string <code>word</code> of length <code>n + m - 1</code> is defined to be <strong>generated</strong> by <code>str1</code> and <code>str2</code> if it satisfies the following conditions for <strong>each</strong> index <code>0 &lt;= i &lt;= n - 1</code>:</p>

<ul>
	<li>If <code>str1[i] == 'T'</code>, the <strong><span data-keyword="substring-nonempty" class=" cursor-pointer relative text-dark-blue-s text-sm"><button type="button" aria-haspopup="dialog" aria-expanded="false" aria-controls="radix-:r1s:" data-state="closed" class="">substring</button></span></strong> of <code>word</code> with size <code>m</code> starting at index <code>i</code> is <strong>equal</strong> to <code>str2</code>, i.e., <code>word[i..(i + m - 1)] == str2</code>.</li>
	<li>If <code>str1[i] == 'F'</code>, the <strong><span data-keyword="substring-nonempty" class=" cursor-pointer relative text-dark-blue-s text-sm"><button type="button" aria-haspopup="dialog" aria-expanded="false" aria-controls="radix-:r1t:" data-state="closed" class="">substring</button></span></strong> of <code>word</code> with size <code>m</code> starting at index <code>i</code> is <strong>not equal</strong> to <code>str2</code>, i.e., <code>word[i..(i + m - 1)] != str2</code>.</li>
</ul>

<p>Return the <strong><span data-keyword="lexicographically-smaller-string" class=" cursor-pointer relative text-dark-blue-s text-sm"><button type="button" aria-haspopup="dialog" aria-expanded="false" aria-controls="radix-:r1u:" data-state="closed" class="">lexicographically smallest</button></span></strong> possible string that can be <strong>generated</strong> by <code>str1</code> and <code>str2</code>. If no string can be generated, return an empty string <code>""</code>.</p>

Розумію, формулювання на LeetCode іноді бувають занадто сухими та заплутаними. Давай розберемо цей приклад крок за кроком, уявивши, що ми просто дебажимо масив.

Ось наші вхідні дані:
* `str1 = "TFTF"` (довжина `n = 4`)
* `str2 = "ab"` (довжина `m = 2`)

Завдання просить нас створити новий рядок `word`. Його загальна довжина буде `n + m - 1`, тобто `4 + 2 - 1 = 5` символів.

Уявимо наш майбутній рядок як масив із 5 порожніх слотів:
`[ ?, ?, ?, ?, ? ]`

### Що означають `T` та `F`?
Ми проходимо по кожному індексу `str1` від 0 до 3. Кожна літера каже нам, що має відбуватися у **вікні з 2 символів** (бо довжина `str2` = 2), яке починається з цього індексу:
* **'T' (True):** Це вікно **мусить** бути точно таким самим, як `str2` (тобто `"ab"`).
* **'F' (False):** Це вікно **не може** дорівнювати `str2` (тобто будь-що, окрім `"ab"`).

---

### Крок 1: Жорстко фіксуємо всі умови 'T'
Найпростіше почати з `'T'`, бо вони прямо кажуть, які символи ми зобов'язані поставити.

* **Індекс 0 (`str1[0] == 'T'`):** Вікно, що починається з індексу 0 (слоти 0 та 1), має бути `"ab"`.
    Записуємо: `[ 'a', 'b', ?, ?, ? ]`

* **Індекс 2 (`str1[2] == 'T'`):** Вікно, що починається з індексу 2 (слоти 2 та 3), має бути `"ab"`.
    Записуємо: `[ 'a', 'b', 'a', 'b', ? ]`

На цьому етапі наш рядок виглядає як `"abab?"`.

---

### Крок 2: Перевіряємо умови 'F'
Тепер треба переконатися, що наші вже заповнені літери не порушують правила `'F'`.

* **Індекс 1 (`str1[1] == 'F'`):** Вікно з індексу 1 (слоти 1 та 2) **не повинно** бути `"ab"`.
    Дивимось у наш масив: на слотах 1 і 2 зараз стоять літери `'b'` та `'a'`, тобто підрядок `"ba"`. Рядок `"ba"` не дорівнює `"ab"`. Отже, умова виконана!

* **Індекс 3 (`str1[3] == 'F'`):** Вікно з індексу 3 (слоти 3 та 4) **не повинно** бути `"ab"`.
    Дивимось у масив: на 3-му індексі стоїть `'b'`, а на 4-му — `?`. Підрядок виглядає як `"b?"`. Оскільки він починається на `'b'`, він уже ніколи не стане `"ab"`, що б ми не поставили замість знака питання. Умова в безпеці.

---

### Крок 3: "Лексикографічно найменший"
У нас залишився один незаповнений слот:
`[ 'a', 'b', 'a', 'b', ? ]`

Щоб рядок був лексикографічно найменшим (тобто йшов якомога раніше в алфавітному порядку), ми маємо ставити на порожні місця найменші можливі літери від `'a'` до `'z'`.

Ми перевірили на попередньому кроці, що умова для індексу 3 (`"b?" != "ab"`) виконається при **будь-якій** літері. Тому ми сміливо беремо першу літеру алфавіту — **`'a'`**.

Підставляємо її:
`[ 'a', 'b', 'a', 'b', 'a' ]`

### Підсумок
Виходить рядок `"ababa"`. 
Якби ми поставили замість знака питання `'b'`, вийшов би рядок `"ababb"`. Він теж не порушує жодних правил (це видно у поясненні до задачі). Але `"ababa"` стоїть в алфавіті перед `"ababb"`, тому саме він є правильною відповіддю.
