1752. Check if Array Is Sorted and Rotated

Easy
<p>Given an array <code>nums</code>, return <code>true</code><em> if the array was originally sorted in non-decreasing order, then rotated <strong>some</strong> number of positions (including zero)</em>. Otherwise, return <code>false</code>.</p>

<p>There may be <strong>duplicates</strong> in the original array.</p>

<p><strong>Note:</strong> An array <code>A</code> rotated by <code>x</code> positions results in an array <code>B</code> of the same length such that <code>B[i] == A[(i+x) % A.length]</code> for every valid index <code>i</code>.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<pre><strong>Input:</strong> nums = [3,4,5,1,2]
<strong>Output:</strong> true
<strong>Explanation:</strong> [1,2,3,4,5] is the original sorted array.
You can rotate the array by x = 2 positions to begin on the element of value 3: [3,4,5,1,2].
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre><strong>Input:</strong> nums = [2,1,3,4]
<strong>Output:</strong> false
<strong>Explanation:</strong> There is no sorted array once rotated that can make nums.
</pre>

<p><strong class="example">Example 3:</strong></p>

<pre><strong>Input:</strong> nums = [1,2,3]
<strong>Output:</strong> true
<strong>Explanation:</strong> [1,2,3] is the original sorted array.
You can rotate the array by x = 0 positions (i.e. no rotation) to make nums.
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= nums.length &lt;= 100</code></li>
	<li><code>1 &lt;= nums[i] &lt;= 100</code></li>
</ul>

1752. Проверка сортировки и поворота массива

Просто
<p>Дано массив <code>nums</code>, вернуть <code>true</code><em>, если массив изначально был отсортирован в порядке убывания, а затем повернут на <strong>некоторое</strong> количество позиций (включая ноль)</em>. В противном случае вернуть <code>false</code>.</p>

<p>В исходном массиве могут быть <strong>дубликаты</strong>.</p>

<p><strong>Примечание:</strong> Массив <code>A</code>, повернутый на <code>x</code> позиций, приводит к массиву <code>B</code> той же длины, что <code>B[i] == A[(i+x) % A.length]</code> для каждого допустимого индекса <code>i</code>.</p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<pre><strong>Входные данные:</strong> nums = [3,4,5,1,2]
<strong>Выходные данные:</strong> true
<strong>Пояснение:</strong> [1,2,3,4,5] — это исходный отсортированный массив.

Вы можете повернуть массив на x = 2 позиции, чтобы начать с элемента со значением 3: [3,4,5,1,2].

</pre>

<p><strong class="example">Пример 2:</strong></p>

<pre><strong>Входные данные:</strong> nums = [2,1,3,4]
<strong>Выходные данные:</strong> false
<strong>Пояснение:</strong> После поворота нет отсортированного массива, который мог бы содержать nums.

</pre>

<p><strong class="example">Пример 3:</strong></p>

<pre><strong>Входные данные:</strong> nums = [1,2,3]
<strong>Выходные данные:</strong> true
<strong>Пояснение:</strong> [1,2,3] — это исходный отсортированный массив.
Вы можете повернуть массив на x = 0 позиций (т.е. без поворота), чтобы получить nums.
</pre>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>1 <= nums.length <= 100</code></li>

<li><code>1 <= nums[i] <= 100</code></li>
</ul>
