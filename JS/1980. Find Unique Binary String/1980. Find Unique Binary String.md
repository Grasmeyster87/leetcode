
1980. Find Unique Binary String

<p>Given an array of strings <code>nums</code> containing <code>n</code> <strong>unique</strong> binary strings each of length <code>n</code>, return <em>a binary string of length </em><code>n</code><em> that <strong>does not appear</strong> in </em><code>nums</code><em>. If there are multiple answers, you may return <strong>any</strong> of them</em>.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<pre><strong>Input:</strong> nums = ["01","10"]
<strong>Output:</strong> "11"
<strong>Explanation:</strong> "11" does not appear in nums. "00" would also be correct.
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre><strong>Input:</strong> nums = ["00","01"]
<strong>Output:</strong> "11"
<strong>Explanation:</strong> "11" does not appear in nums. "10" would also be correct.
</pre>

<p><strong class="example">Example 3:</strong></p>

<pre><strong>Input:</strong> nums = ["111","011","001"]
<strong>Output:</strong> "101"
<strong>Explanation:</strong> "101" does not appear in nums. "000", "010", "100", and "110" would also be correct.
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>n == nums.length</code></li>
	<li><code>1 &lt;= n &lt;= 16</code></li>
	<li><code>nums[i].length == n</code></li>
	<li><code>nums[i] </code>is either <code>'0'</code> or <code>'1'</code>.</li>
	<li>All the strings of <code>nums</code> are <strong>unique</strong>.</li>
</ul>

1980. Найти уникальную двоичную строку

<p>Дано массив строк <code>nums</code>, содержащий <code>n</code> <strong>уникальных</strong> двоичных строк длиной <code>n</code>. Верните <em>двоичную строку длиной </em><code>n</code><em>, которая <strong>не встречается</strong> в </em><code>nums</code><em>. Если есть несколько ответов, вы можете вернуть <strong>любой</strong> из них</em>.</p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<pre><strong>Входные данные:</strong> nums = ["01","10"]
<strong>Выходные данные:</strong> "11"
<strong>Пояснение:</strong> "11" не встречается в nums. "00" также будет правильным ответом.
</pre>

<p><strong class="example">Пример 2:</strong></p>

<pre><strong>Ввод:</strong> nums = ["00","01"]
<strong>Вывод:</strong> "11"
<strong>Пояснение:</strong> "11" не встречается в nums. "10" также было бы правильным.

</pre>

<p><strong class="example">Пример 3:</strong></p>

<pre><strong>Ввод:</strong> nums = ["111","011","001"]
<strong>Вывод:</strong> "101"
<strong>Пояснение:</strong> "101" не встречается в nums. "000", "010", "100" и "110" также были бы правильными.

</pre>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>n == nums.length</code></li>

<li><code>1 <= n <= 16</code></li>

<li><code>nums[i].length == n</code></li>

<li><code>nums[i] </code>либо <code>'0'</code>, либо <code>'1'</code>.</li>

<li>Все строки <code>nums</code> являются <strong>уникальными</strong>.</li>
</ul>

Для розв’язання цієї задачі найкраще підходить **Діагональний метод Кантора**. Це елегантний алгоритм, який дозволяє знайти рядок, що гарантовано відсутній у списку, лише за один прохід.

### Алгоритм: Діагональний метод Кантора

Основна ідея полягає в тому, щоб створити новий рядок довжиною $n$, де кожен $i$-й символ відрізняється від $i$-го символу $i$-го рядка у вхідному масиві `nums`.

Таким чином, наш результат буде гарантовано відрізнятися від:

* Першого рядка — у першому символі.
* Другого рядка — у другому символі.
* ...і так далі до $n$-го рядка.

---

### Реалізація (JavaScript)

Ось готовий код для вашого файлу `1980. Find Unique Binary String.js`:

```javascript
/**
 * @param {string[]} nums
 * @return {string}
 */
var findDifferentBinaryString = function(nums) {
    let result = "";
    
    for (let i = 0; i < nums.length; i++) {
        // Беремо i-й символ з i-го рядка
        let currentChar = nums[i][i];
        
        // Додаємо до результату протилежний символ
        // Якщо був '0', додаємо '1', якщо '1' — додаємо '0'
        result += (currentChar === '0' ? '1' : '0');
    }
    
    return result;
};

```

---

### Чому це працює? (Приклад)

Розглянемо **Example 3**: `nums = ["111", "011", "001"]`

1. **$i = 0$**: Дивимось на `nums[0][0]` (це `'1'`). Наш `result` стає `"0"`.
2. **$i = 1$**: Дивимось на `nums[1][1]` (це `'1'`). Наш `result` стає `"00"`.
3. **$i = 2$**: Дивимось на `nums[2][2]` (це `'1'`). Наш `result` стає `"000"`.

Результат `"000"` не входить до початкового списку. Навіть якщо варіантів відповіді декілька, цей метод завжди знаходить один із них.

### Складність

* **Часова складність**: $O(n)$, де $n$ — кількість рядків (та їхня довжина). Ми проходимо по масиву лише один раз.
* **Просторова складність**: $O(1)$, якщо не враховувати пам'ять, необхідну для зберігання результуючого рядка.
