# 🔍 Що означає “перевернути по вертикалі”

Є підматриця `k × k`.

**Вертикальний flip = поміняти місцями рядки:**

```
верх ↕ низ
```

Тобто:

```
рядок 0 ↔ рядок k-1
рядок 1 ↔ рядок k-2
...
```

---

# 🧱 Конкретний приклад

```
x = 1, y = 0, k = 3
```

Матриця:

```
[1,  2,  3,  4]
[5,  6,  7,  8]   ← x = 1
[9, 10, 11, 12]
[13,14, 15,16]
```

### Підматриця (3×3):

```
[5,  6,  7]      ← row = x + 0
[9, 10, 11]      ← row = x + 1
[13,14, 15]      ← row = x + 2
```

---

# 🔄 Що треба зробити

Поміняти:

```
[5,6,7]     ↔    [13,14,15]
```

Середній рядок:

```
[9,10,11]  (залишається)
```

---

# 🧠 Як це зробити в коді

## 1. Ідемо тільки по ПОЛОВИНІ рядків

```js
for (let i = 0; i < Math.floor(k / 2); i++)
```

Чому?

* Бо ми міняємо **парами**
* Якщо пройти всі — зробиш подвійний swap назад

---

## 2. Обчислюємо які рядки міняти

```js
topRow = x + i
bottomRow = x + k - 1 - i
```

### Приклад:

| i | topRow  | bottomRow                |
| - | ------- | ------------------------ |
| 0 | x+0 = 1 | x+2 = 3                  |
| 1 | x+1 = 2 | x+1 = 2 (стоп, середина) |

---

## 3. Чому `x + k - 1 - i`

Це ключова формула.

👉 `x + k - 1` = останній рядок підматриці
👉 `- i` = рухаємося вгору

---

# 📦 4. Тепер важливо: ми НЕ міняємо весь рядок

❗ Тільки частину `[y ... y + k - 1]`

```js
for (let j = 0; j < k; j++) {
    col = y + j
}
```

---

# 🔁 5. Swap елементів

```js
[grid[topRow][col], grid[bottomRow][col]] =
[grid[bottomRow][col], grid[topRow][col]];
```

---

# 🔬 Покроково (реально як працює)

### i = 0:

```
topRow = 1
bottomRow = 3
```

Цикл по колонках:

| col | swap   |
| --- | ------ |
| 0   | 5 ↔ 13 |
| 1   | 6 ↔ 14 |
| 2   | 7 ↔ 15 |

---

# 📊 Візуально

Було:

```
[5,  6,  7]
[9, 10, 11]
[13,14,15]
```

Стало:

```
[13,14,15]
[9,10,11]
[5,  6,  7]
```

# ⚠️ Часті помилки

### ❌ 1. Робити reverse рядка

```js
grid[row].reverse()
```

👉 це горизонтальний flip (не те)

---

### ❌ 2. Міняти весь рядок

```js
grid[topRow] = grid[bottomRow]
```

👉 ти зачепиш елементи поза підматрицею

---

### ❌ 3. Неправильна формула

```js
bottomRow = x + k - i   ❌
```

👉 правильно:

```js
x + k - 1 - i
```

---

# 💡 Коротка модель в голові

Уяви:

```
i = відстань від верху
```

Тоді:

```
верх = x + i
низ  = x + (k - 1 - i)
```
