796. Rotate String

Easy

<p>Given two strings <code>s</code> and <code>goal</code>, return <code>true</code> <em>if and only if</em> <code>s</code> <em>can become</em> <code>goal</code> <em>after some number of <strong>shifts</strong> on</em> <code>s</code>.</p>

<p>A <strong>shift</strong> on <code>s</code> consists of moving the leftmost character of <code>s</code> to the rightmost position.</p>

<ul>
	<li>For example, if <code>s = "abcde"</code>, then it will be <code>"bcdea"</code> after one shift.</li>
</ul>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>
<pre><strong>Input:</strong> s = "abcde", goal = "cdeab"
<strong>Output:</strong> true
</pre><p><strong class="example">Example 2:</strong></p>
<pre><strong>Input:</strong> s = "abcde", goal = "abced"
<strong>Output:</strong> false
</pre>
<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= s.length, goal.length &lt;= 100</code></li>
	<li><code>s</code> and <code>goal</code> consist of lowercase English letters.</li>
</ul>
<br> <hr> <br>

796. Поворот строки

Просто

<p>Даны две строки <code>s</code> и <code>goal</code>. Верните <code>true</code> тогда и только тогда, когда</em> <code>s</code> <em>может стать</em> <code>goal</code> <em>после некоторого количества <strong>сдвигов</strong> над</em> <code>s</code>.</p>

<p>Сдвиг</strong> над <code>s</code> заключается в перемещении самого левого символа <code>s</code> в самую правую позицию.</p>

<ul>

<li>Например, если <code>s = "abcde"</code>, то после одного сдвига он станет <code>"bcdea"</code>.</li>
</ul>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>
<pre><strong>Ввод:</strong> s = "abcde", goal = "cdeab"
<strong>Вывод:</strong> true
</pre><p><strong class="example">Пример 2:</strong></p>
<pre><strong>Ввод:</strong> s = "abcde", goal = "abced"
<strong>Вывод:</strong> false
</pre>
<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>1 <= s.length, goal.length <= 100</code></li>

<li><code>s</code> и <code>goal</code> состоят из строчных английских букв.</li>
</ul>

Добре, поясню детально, як працює цей вираз:

```js
(s + s).includes(goal)
```

### Кроки
1. **`s + s`**  
   Це конкатенація рядка `s` із самим собою.  
   Наприклад:  
   ```js
   let s = "abcde";
   console.log(s + s); // "abcdeabcde"
   ```

2. **`includes(goal)`**  
   Метод `includes` перевіряє, чи містить рядок певний підрядок.  
   ```js
   "abcdeabcde".includes("cdeab"); // true
   ```

### Чому це працює
Якщо `goal` є циклічним зсувом `s`, то він обов’язково з’явиться всередині рядка `s + s`.  
- Приклад:  
  - `s = "abcde"`  
  - `goal = "cdeab"`  
  - `s + s = "abcdeabcde"`  
  - `"cdeab"` дійсно є підрядком у цьому рядку.

А якщо `goal` не є зсувом, то він просто не зустрінеться в `s + s`.

### Візуальна аналогія
Уяви, що ти написав слово `abcde` двічі підряд:  
```
abcdeabcde
```
Тепер будь-який "поворот" цього слова (наприклад, `cdeab`, `deabc`, `eabcd`) можна знайти всередині цього подвійного рядка.
