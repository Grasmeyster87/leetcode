1391. Check if There is a Valid Path in a Grid

Medium

<p>You are given an <code>m x n</code> <code>grid</code>. Each cell of <code>grid</code> represents a street. The street of <code>grid[i][j]</code> can be:</p>

<ul>
	<li><code>1</code> which means a street connecting the left cell and the right cell.</li>
	<li><code>2</code> which means a street connecting the upper cell and the lower cell.</li>
	<li><code>3</code> which means a street connecting the left cell and the lower cell.</li>
	<li><code>4</code> which means a street connecting the right cell and the lower cell.</li>
	<li><code>5</code> which means a street connecting the left cell and the upper cell.</li>
	<li><code>6</code> which means a street connecting the right cell and the upper cell.</li>
</ul>

A valid path in the grid is a path that starts from the upper left cell <code>(0, 0)</code> and ends at the bottom-right cell <code>(m - 1, n - 1)</code>. <strong>The path should only follow the streets</strong>.</p>

<p><strong>Notice</strong> that you are <strong>not allowed</strong> to change any street.</p>

<p>Return <code>true</code><em> if there is a valid path in the grid or </em><code>false</code><em> otherwise</em>.</p>

Ваш підхід з використанням структури даних **Union-Find (Система неперетинних множин)** — це чудове та надійне архітектурне рішення для цієї задачі. Проте у вашому коді є дві суттєві помилки: одна пов'язана зі специфікою JavaScript, а інша — з логікою перевірки з'єднань.

Ось детальний розбір помилок та варіанти вирішення задачі.

---

### 🔍 Розбір помилок у вашому коді

**1. Специфіка роботи `.includes()` з масивами в JavaScript**
У вашій умові ви використовуєте `.includes([dr, dc])`. У JavaScript масиви передаються за посиланням. Метод `.includes()` не перевіряє вміст масиву, він перевіряє, чи є це **той самий об'єкт** у пам'яті. 
* Вираз `[[1, 0]].includes([1, 0])` завжди повертатиме `false`.

**2. Логічна помилка у перевірці `grid[nr][nc] === streetType`**
Дві однакові вулиці, що знаходяться поруч, не обов'язково з'єднуються. Наприклад, якщо ми маємо дві вулиці типу `4` (йде вниз і вправо), розташовані горизонтально поруч, то ліва вулиця спрямовує шлях у праву, але права вулиця `4` приймає з'єднання **тільки зверху або зліва** (її виходи: вниз і вправо). Отже, просто перевіряти, чи типи вулиць однакові — недостатньо і місцями помилково.

### ✅ Варіант 1: Виправлений ваш код (Union-Find)

Щоб виправити логіку, нам потрібно перевірити лише одне: чи має сусідня клітинка напрямок, **протилежний** до того, яким ми прийшли до неї (`-dr` та `-dc`). Ми можемо використати метод `.some()` для порівняння значень координат.

```javascript
function hasValidPath(grid) {
    if (!grid || !grid.length || !grid[0].length) return false;

    const m = grid.length;
    const n = grid[0].length;
    const parent = Array.from({ length: m * n }, (_, i) => i);

    function find(x) {
        if (parent[x] !== x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }

    function union(x, y) {
        const rootX = find(x);
        const rootY = find(y);
        if (rootX !== rootY) {
            parent[rootY] = rootX;
        }
    }

    const connections = {
        1: [[0, 1], [0, -1]],    // Right and Left
        2: [[1, 0], [-1, 0]],    // Down and Up
        3: [[1, 0], [0, -1]],    // Down and Left
        4: [[1, 0], [0, 1]],     // Down and Right
        5: [[-1, 0], [0, -1]],   // Up and Left
        6: [[-1, 0], [0, 1]]     // Up and Right
    };

    for (let r = 0; r < m; r++) {
        for (let c = 0; c < n; c++) {
            const cellIndex = r * n + c;
            const streetType = grid[r][c];

            for (const [dr, dc] of connections[streetType]) {
                const nr = r + dr;
                const nc = c + dc;

                // Перевіряємо, чи не вийшли ми за межі сітки
                if (nr >= 0 && nr < m && nc >= 0 && nc < n) {
                    const neighborType = grid[nr][nc];
                    
                    // Замість .includes() використовуємо .some() для перевірки значень.
                    // Перевіряємо, чи сусідня вулиця має вихід, спрямований назад до нас (-dr, -dc).
                    const canConnectBack = connections[neighborType].some(
                        ([ndr, ndc]) => ndr === -dr && ndc === -dc
                    );

                    if (canConnectBack) {
                        const neighborIndex = nr * n + nc;
                        union(cellIndex, neighborIndex);
                    }
                }
            }
        }
    }

    return find(0) === find(m * n - 1);
}
```

### 🚀 Варіант 2: Більш ефективне рішення (DFS)

Хоча Union-Find працює чудово, у цій задачі він робить зайву роботу, перевіряючи всю сітку. Задача полягає лише в тому, щоб знайти шлях від `(0, 0)` до `(m-1, n-1)`. 

Використання **DFS (Пошук у глибину)** або **BFS (Пошук у ширину)** є більш ефективним, оскільки:
1. Алгоритм почнеться з `(0, 0)` і піде лише дозволеними шляхами.
2. Він миттєво зупиниться (short-circuit), як тільки досягне кінцевої точки `(m-1, n-1)`, не перевіряючи інші, не пов'язані з основним шляхом вулиці.

**Реалізація за допомогою DFS:**

```javascript
function hasValidPath(grid) {
    const m = grid.length;
    const n = grid[0].length;
    
    // Масив для відстеження відвіданих клітинок, щоб уникнути зациклення
    const visited = Array.from({ length: m }, () => Array(n).fill(false));

    const connections = {
        1: [[0, 1], [0, -1]], 
        2: [[1, 0], [-1, 0]], 
        3: [[1, 0], [0, -1]], 
        4: [[1, 0], [0, 1]],  
        5: [[-1, 0], [0, -1]],
        6: [[-1, 0], [0, 1]]  
    };

    function dfs(r, c) {
        // Якщо ми досягли кінцевої точки - шлях знайдено
        if (r === m - 1 && c === n - 1) return true;
        
        visited[r][c] = true;

        for (const [dr, dc] of connections[grid[r][c]]) {
            const nr = r + dr;
            const nc = c + dc;

            // Якщо сусід валідний і ми там ще не були
            if (nr >= 0 && nr < m && nc >= 0 && nc < n && !visited[nr][nc]) {
                const neighborType = grid[nr][nc];
                
                // Перевіряємо чи сусідня клітинка з'єднується з нашою поточною
                const canConnectBack = connections[neighborType].some(
                    ([ndr, ndc]) => ndr === -dr && ndc === -dc
                );

                // Якщо з'єднання є, йдемо далі в глибину
                if (canConnectBack) {
                    if (dfs(nr, nc)) return true;
                }
            }
        }
        
        return false;
    }

    return dfs(0, 0);
}
```
