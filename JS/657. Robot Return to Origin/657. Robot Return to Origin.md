657. Robot Return to Origin
<br>Easy
<br>
<p>There is a robot starting at the position <code>(0, 0)</code>, the origin, on a 2D plane. Given a sequence of its moves, judge if this robot <strong>ends up at </strong><code>(0, 0)</code> after it completes its moves.</p>

<p>You are given a string <code>moves</code> that represents the move sequence of the robot where <code>moves[i]</code> represents its <code>i<sup>th</sup></code> move. Valid moves are <code>'R'</code> (right), <code>'L'</code> (left), <code>'U'</code> (up), and <code>'D'</code> (down).</p>

<p>Return <code>true</code><em> if the robot returns to the origin after it finishes all of its moves, or </em><code>false</code><em> otherwise</em>.</p>

<p><strong>Note</strong>: The way that the robot is "facing" is irrelevant. <code>'R'</code> will always make the robot move to the right once, <code>'L'</code> will always make it move left, etc. Also, assume that the magnitude of the robot's movement is the same for each move.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<pre><strong>Input:</strong> moves = "UD"
<strong>Output:</strong> true
<strong>Explanation</strong>: The robot moves up once, and then down once. All moves have the same magnitude, so it ended up at the origin where it started. Therefore, we return true.
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre><strong>Input:</strong> moves = "LL"
<strong>Output:</strong> false
<strong>Explanation</strong>: The robot moves left twice. It ends up two "moves" to the left of the origin. We return false because it is not at the origin at the end of its moves.
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= moves.length &lt;= 2 * 10<sup>4</sup></code></li>
	<li><code>moves</code> only contains the characters <code>'U'</code>, <code>'D'</code>, <code>'L'</code> and <code>'R'</code>.</li>
</ul>

657. Возвращение робота в начало координат
<br>Просто
<br>
<p>Робот начинает движение из позиции <code>(0, 0)</code>, начала координат, на двумерной плоскости. Имея последовательность его ходов, определите, окажется ли этот робот в <strong>позаверии</strong><code>(0, 0)</code> после завершения своих ходов.</p>

<p>Вам дана строка <code>moves</code>, представляющая последовательность ходов робота, где <code>moves[i]</code> представляет его <code>i<sup>-й</sup> ход.</code> Допустимые ходы: <code>'R'</code> (вправо), <code>'L'</code> (влево), <code>'U'</code> (вверх) и <code>'D'</code> (вниз).</p>

<p>Возвращает <code>true</code><em>, если робот возвращается в исходную точку после завершения всех своих ходов, или </em><code>false</code><em> в противном случае</em>.</p>

<p><strong>Примечание</strong>: Направление взгляда робота не имеет значения. Функция `<code>'R'</code>` всегда заставляет робота двигаться вправо один раз, `<code>'L'</code>` всегда заставляет его двигаться влево и т.д. Также предположим, что величина движения робота одинакова для каждого движения.

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<pre><strong>Входные данные:</strong> moves = "UD"
<strong>Выходные данные:</strong> true
<strong>Пояснение</strong>: Робот движется вверх один раз, а затем вниз один раз. Все движения имеют одинаковую величину, поэтому он вернулся в исходную точку. Следовательно, мы возвращаем true ... </pre>

<p><strong class="example">Пример 2:</strong></p>

<pre><strong>Входные данные:</strong> moves = "LL"
<strong>Выходные данные:</strong> false
<strong>Пояснение</strong>: Робот дважды перемещается влево. В итоге он оказывается на два "хода" левее начала координат. Мы возвращаем false, потому что в конце своих перемещений он не находится в начале координат.

</pre>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>1 <= moves.length <= 2 * 10<sup>4</sup></code></li>

<li><code>moves</code> содержит только символы <code>'U'</code>, <code>'D'</code>, <code>'L'</code> и <code>'R'</code>.</li>
</ul>
