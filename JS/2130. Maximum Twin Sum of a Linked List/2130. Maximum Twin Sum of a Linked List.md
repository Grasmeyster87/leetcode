
2130. Maximum Twin Sum of a Linked List

Medium
<p>In a linked list of size <code>n</code>, where <code>n</code> is <strong>even</strong>, the <code>i<sup>th</sup></code> node (<strong>0-indexed</strong>) of the linked list is known as the <strong>twin</strong> of the <code>(n-1-i)<sup>th</sup></code> node, if <code>0 &lt;= i &lt;= (n / 2) - 1</code>.</p>

<ul>
	<li>For example, if <code>n = 4</code>, then node <code>0</code> is the twin of node <code>3</code>, and node <code>1</code> is the twin of node <code>2</code>. These are the only nodes with twins for <code>n = 4</code>.</li>
</ul>

<p>The <strong>twin sum </strong>is defined as the sum of a node and its twin.</p>

<p>Given the <code>head</code> of a linked list with even length, return <em>the <strong>maximum twin sum</strong> of the linked list</em>.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>
<img alt="" style="width: 250px; height: 70px;" src="https://assets.leetcode.com/uploads/2021/12/03/eg1drawio.png">
<pre><strong>Input:</strong> head = [5,4,2,1]
<strong>Output:</strong> 6
<strong>Explanation:</strong>
Nodes 0 and 1 are the twins of nodes 3 and 2, respectively. All have twin sum = 6.
There are no other nodes with twins in the linked list.
Thus, the maximum twin sum of the linked list is 6. 
</pre>

<p><strong class="example">Example 2:</strong></p>
<img alt="" style="width: 250px; height: 70px;" src="https://assets.leetcode.com/uploads/2021/12/03/eg2drawio.png">
<pre><strong>Input:</strong> head = [4,2,2,3]
<strong>Output:</strong> 7
<strong>Explanation:</strong>
The nodes with twins present in this linked list are:
- Node 0 is the twin of node 3 having a twin sum of 4 + 3 = 7.
- Node 1 is the twin of node 2 having a twin sum of 2 + 2 = 4.
Thus, the maximum twin sum of the linked list is max(7, 4) = 7. 
</pre>

<p><strong class="example">Example 3:</strong></p>
<img alt="" style="width: 200px; height: 88px;" src="https://assets.leetcode.com/uploads/2021/12/03/eg3drawio.png">
<pre><strong>Input:</strong> head = [1,100000]
<strong>Output:</strong> 100001
<strong>Explanation:</strong>
There is only one node with a twin in the linked list having twin sum of 1 + 100000 = 100001.
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li>The number of nodes in the list is an <strong>even</strong> integer in the range <code>[2, 10<sup>5</sup>]</code>.</li>
	<li><code>1 &lt;= Node.val &lt;= 10<sup>5</sup></code></li>
</ul>

2130. Максимальная сумма двойников в связанном списке

Средний уровень сложности
<p>В связанном списке размером <code>n</code>, где <code>n</code> является <strong>четным</strong>, <code>i<sup>-й</sup></code> узел (<strong>с 0-индексом</strong>) связанного списка называется <strong>двойником</strong> <code>(n-1-i)<sup>-го</sup></code> узла, если <code>0 <= i <= (n / 2) - 1</code>.</p>

<ul>

<li>Например, если <code>n = 4</code>, то узел <code>0</code> является двойником узла <code>3</code>, а узел <code>1</code> является двойником узла <code>2</code>. Это единственные узлы с двойниками для <code>n = 4</code>.</li>
</ul>

<p>Сумма двойников</strong> определяется как сумма узла и его двойника.</p>

<p>Учитывая <code>голову</code> связанного списка четной длины, верните <em>максимальную сумму двойников</strong> связанного списка</em>.</p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>
<img alt="" style="width: 250px; height: 70px;" src="https://assets.leetcode.com/uploads/2021/12/03/eg1drawio.png">
<pre><strong>Входные данные:</strong> head = [5,4,2,1]
<strong>Выходные данные:</strong> 6
<strong>Пояснение:</strong>
Узлы 0 и 1 являются близнецами узлов 3 и 2 соответственно. Сумма близнецов всех узлов равна 6.
В связанном списке нет других узлов с близнецами.
Таким образом, максимальная сумма близнецов связанного списка равна 6.
</pre>

<p><strong class="example">Пример 2:</strong></p>
<img alt="" style="width: 250px; height: 70px;" src="https://assets.leetcode.com/uploads/2021/12/03/eg2drawio.png">
<pre><strong>Входные данные:</strong> head = [4,2,2,3]
<strong>Выходные данные:</strong> 7
<strong>Пояснение:</strong>
Узлы с двойниками, присутствующие в этом связанном списке:
- Узел 0 является двойником узла 3, сумма двойников которого равна 4 + 3 = 7.
- Узел 1 является двойником узла 2, сумма двойников которого равна 2 + 2 = 4.
Таким образом, максимальная сумма двойников связанного списка равна max(7, 4) = 7.
</pre>

<p><strong class="example">Пример 3:</strong></p>
<img alt="" style="width: 200px; height: 88px;" src="https://assets.leetcode.com/uploads/2021/12/03/eg3drawio.png">
<pre><strong>Входные данные:</strong> head = [1,100000]
<strong>Выходные данные:</strong> 100001
<strong>Пояснение:</strong>
В связанном списке есть только один узел, имеющий двойника, сумма двойников которого равна 1 + 100000 = 100001.
</pre>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li>Количество узлов в списке является <strong>четным</strong> целым числом в диапазоне <code>[2, 10<sup>5</sup>]</code>.</li>

<li><code>1 <= Node.val <= 10<sup>5</sup></code></li>
</ul>
