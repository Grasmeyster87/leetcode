3418. Maximum Amount of Money Robot Can Earn 
Medium 

<p>You are given an <code>m x n</code> grid. A robot starts at the top-left corner of the grid <code>(0, 0)</code> and wants to reach the bottom-right corner <code>(m - 1, n - 1)</code>. The robot can move either right or down at any point in time.</p>

<p>The grid contains a value <code>coins[i][j]</code> in each cell:</p>

<ul>
	<li>If <code>coins[i][j] &gt;= 0</code>, the robot gains that many coins.</li>
	<li>If <code>coins[i][j] &lt; 0</code>, the robot encounters a robber, and the robber steals the <strong>absolute</strong> value of <code>coins[i][j]</code> coins.</li>
</ul>

<p>The robot has a special ability to <strong>neutralize robbers</strong> in at most <strong>2 cells</strong> on its path, preventing them from stealing coins in those cells.</p>

<p><strong>Note:</strong> The robot's total coins can be negative.</p>

<p>Return the <strong>maximum</strong> profit the robot can gain on the route.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">coins = [[0,1,-1],[1,-2,3],[2,-3,4]]</span></p>

<p><strong>Output:</strong> <span class="example-io">8</span></p>

<p><strong>Explanation:</strong></p>

<p>An optimal path for maximum coins is:</p>

<ol>
	<li>Start at <code>(0, 0)</code> with <code>0</code> coins (total coins = <code>0</code>).</li>
	<li>Move to <code>(0, 1)</code>, gaining <code>1</code> coin (total coins = <code>0 + 1 = 1</code>).</li>
	<li>Move to <code>(1, 1)</code>, where there's a robber stealing <code>2</code> coins. The robot uses one neutralization here, avoiding the robbery (total coins = <code>1</code>).</li>
	<li>Move to <code>(1, 2)</code>, gaining <code>3</code> coins (total coins = <code>1 + 3 = 4</code>).</li>
	<li>Move to <code>(2, 2)</code>, gaining <code>4</code> coins (total coins = <code>4 + 4 = 8</code>).</li>
</ol>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">coins = [[10,10,10],[10,10,10]]</span></p>

<p><strong>Output:</strong> <span class="example-io">40</span></p>

<p><strong>Explanation:</strong></p>

<p>An optimal path for maximum coins is:</p>

<ol>
	<li>Start at <code>(0, 0)</code> with <code>10</code> coins (total coins = <code>10</code>).</li>
	<li>Move to <code>(0, 1)</code>, gaining <code>10</code> coins (total coins = <code>10 + 10 = 20</code>).</li>
	<li>Move to <code>(0, 2)</code>, gaining another <code>10</code> coins (total coins = <code>20 + 10 = 30</code>).</li>
	<li>Move to <code>(1, 2)</code>, gaining the final <code>10</code> coins (total coins = <code>30 + 10 = 40</code>).</li>
</ol>
</div>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>m == coins.length</code></li>
	<li><code>n == coins[i].length</code></li>
	<li><code>1 &lt;= m, n &lt;= 500</code></li>
	<li><code>-1000 &lt;= coins[i][j] &lt;= 1000</code></li>
</ul>
</div>

3418. Максимальная сумма денег, которую может заработать робот
Средний

<p>Вам дана сетка размером <code>m x n</code>. Робот начинает движение из верхнего левого угла сетки <code>(0, 0)</code> и хочет достичь нижнего правого угла <code>(m - 1, n - 1)</code>. Робот может двигаться вправо или вниз в любой момент времени.</p>

<p>В каждой ячейке сетки содержится значение <code>coins[i][j]</code>:</p>

<ul>

<li>Если <code>coins[i][j] <= 0</code>, робот получает столько монет.</li>

<li>Если <code>coins[i][j] < 0</code>, робот встречает грабителя, и грабитель крадет <strong>абсолютное</strong> значение <code>монет[i][j]</code> монет.</li>
</ul>

<p>Робот обладает особой способностью <strong>нейтрализовать грабителей</strong> максимум в <strong>2 клетках</strong> на своем пути, предотвращая кражу монет в этих клетках.</p>

<p><strong>Примечание:</strong> Общее количество монет робота может быть отрицательным.</p>

<p>Вернуть <strong>максимальную</strong> прибыль, которую робот может получить на маршруте.</p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<div class="example-block">
<p><strong>Ввод:</strong> <span class="example-io">coins = [[0,1,-1],[1,-2,3],[2,-3,4]]</span></p>

<p><strong>Вывод:</strong> <span class="example-io">8</span></p>

<p><strong>Пояснение:</strong></p>

<p>Оптимальный путь для получения максимального количества монет:</p>

<ol>

<li>Начните с <code>(0, 0)</code> с <code>0</code> монетами (всего монет = <code>0</code>).</li>

<li>Перейдите к <code>(0, 1)</code>, получив <code>1</code> монету (всего монет = <code>0 + 1 = 1</code>).</li>

<li>Перейдите к <code>(1, 1)</code>, где грабитель крадет <code>2</code> монеты. Робот использует здесь одну нейтрализацию, избегая ограбления (всего монет = <code>1</code>).</li>

<li>Перемещаемся к <code>(1, 2)</code>, получая <code>3</code> монет (всего монет = <code>1 + 3 = 4</code>).</li>

<li>Перемещаемся к <code>(2, 2)</code>, получая <code>4</code> монет (всего монет = <code>4 + 4 = 8</code>).</li>
</ol>
</div>

<div class="example-block">
<p><strong>Входные данные:</strong> <span class="example-io">монеты = [[10,10,10],[10,10,10]]</span></p>

<p><strong>Выходные данные:</strong> <span class="example-io">40</span></p>

<p><strong>Пояснение:</strong></p>

<p>Оптимальный путь для получения максимального количества монет:</p>

<ol>

<li>Начните с <code>(0, 0)</code> с <code>10</code> монетами (всего монет = <code>10</code>).</li>

<li>Перейдите к <code>(0, 1)</code>, получив <code>10</code> монет (всего монет = <code>10 + 10 = 20</code>).</li>

<li>Перейдите к <code>(0, 2)</code>, получив еще <code>10</code> монет (всего монет = <code>20 + 10 = 30</code>).</li>

<li>Перейдите к <code>(1, 2)</code>, получив последние монеты. <code>10</code> монет (всего монет = <code>30 + 10 = 40</code>).</li>
</ol>
</div>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>m == coins.length</code></li>

<li><code>n == coins[i].length</code></li>

Ось ефективне рішення на основі динамічного програмування з оптимізацією по пам'яті. 

Оскільки ми можемо рухатися лише вправо та вниз, стан будь-якої клітинки залежить тільки від клітинки зверху та клітинки зліва. Щоб зробити алгоритм максимально ефективним, ми можемо оптимізувати просторову складність з $O(m \times n)$ до $O(n)$, зберігаючи стани лише для попереднього та поточного рядків.

### Логіка рішення
Для кожної клітинки ми відстежуємо три можливі стани:
1. Максимальний прибуток без використання нейтралізації (`k = 0`).
2. Максимальний прибуток з використанням рівно однієї нейтралізації (`k = 1`).
3. Максимальний прибуток з використанням рівно двох нейтралізацій (`k = 2`).

Коли робот натрапляє на грабителя (від'ємне значення), у нього є вибір: прийняти збиток або (якщо залишилися нейтралізації) витратити одну здібність і прирівняти збиток до нуля.

### Код рішення (JavaScript)

```javascript
/**
 * @param {number[][]} coins
 * @return {number}
 */
var maximumAmount = function (coins) {
  const m = coins.length;
  const n = coins[0].length;

  // dp[j][k] зберігає максимальний прибуток для поточного рядка, стовпця j,
  // при використанні рівно k нейтралізацій.
  let dp = new Array(n).fill(null).map(() => [-Infinity, -Infinity, -Infinity]);

  for (let i = 0; i < m; i++) {
    let nextDp = new Array(n).fill(null).map(() => [-Infinity, -Infinity, -Infinity]);

    for (let j = 0; j < n; j++) {
      // Ініціалізація початкової клітинки
      if (i === 0 && j === 0) {
        nextDp[0][0] = coins[0][0];
        // Якщо на старті відразу грабіжник, можемо його нейтралізувати
        if (coins[0][0] < 0) {
          nextDp[0][1] = 0;
        }
        continue;
      }

      for (let k = 0; k <= 2; k++) {
        let prev = -Infinity;

        // Варіанти кроку з попередніх клітинок (зверху або зліва)
        if (i > 0) prev = Math.max(prev, dp[j][k]);
        if (j > 0) prev = Math.max(prev, nextDp[j - 1][k]);

        // Опція 1: Звичайний крок (без нейтралізації у поточній клітинці)
        if (prev !== -Infinity) {
          nextDp[j][k] = Math.max(nextDp[j][k], prev + coins[i][j]);
        }

        // Опція 2: Застосовуємо нейтралізацію, якщо тут грабіжник і є доступні здібності
        if (k > 0 && coins[i][j] < 0) {
          let prevK1 = -Infinity;
          
          // Шукаємо найкращий попередній стан, де було використано (k - 1) здібностей
          if (i > 0) prevK1 = Math.max(prevK1, dp[j][k - 1]);
          if (j > 0) prevK1 = Math.max(prevK1, nextDp[j - 1][k - 1]);

          // Якщо такий шлях існує, додаємо 0 замість від'ємного значення
          if (prevK1 !== -Infinity) {
            nextDp[j][k] = Math.max(nextDp[j][k], prevK1);
          }
        }
      }
    }
    // Переходимо до наступного рядка
    dp = nextDp;
  }

  // Повертаємо максимум серед усіх можливих кількостей використаних нейтралізацій у фінальній точці
  return Math.max(dp[n - 1][0], dp[n - 1][1], dp[n - 1][2]);
};
```

### Складність
* **Часова складність:** `O(m * n)` — ми проходимо по кожній клітинці сітки рівно один раз і виконуємо константну кількість операцій ($O(1)$) для трьох можливих станів `k`.
* **Просторова складність:** `O(n)` — завдяки тому, що ми зберігаємо лише масив `dp` для попереднього рядка та `nextDp` для поточного, споживання пам'яті лінійно залежить лише від ширини сітки. Матриці на 500 елементів оброблятимуться вкрай швидко.
