2751. Robot Collisions
<br><p>Hard</p>
<p>There are <code>n</code> <strong>1-indexed</strong> robots, each having a position on a line, health, and movement direction.</p>

<p>You are given <strong>0-indexed</strong> integer arrays <code>positions</code>, <code>healths</code>, and a string <code>directions</code> (<code>directions[i]</code> is either <strong>'L'</strong> for <strong>left</strong> or <strong>'R'</strong> for <strong>right</strong>). All integers in <code>positions</code> are <strong>unique</strong>.</p>

<p>All robots start moving on the line<strong> simultaneously</strong> at the <strong>same speed </strong>in their given directions. If two robots ever share the same position while moving, they will <strong>collide</strong>.</p>

<p>If two robots collide, the robot with <strong>lower health</strong> is <strong>removed</strong> from the line, and the health of the other robot <strong>decreases</strong> <strong>by one</strong>. The surviving robot continues in the <strong>same</strong> direction it was going. If both robots have the <strong>same</strong> health, they are both<strong> </strong>removed from the line.</p>

<p>Your task is to determine the <strong>health</strong> of the robots that survive the collisions, in the same <strong>order </strong>that the robots were given,<strong> </strong>i.e. final health of robot 1 (if survived), final health of robot 2 (if survived), and so on. If there are no survivors, return an empty array.</p>

<p>Return <em>an array containing the health of the remaining robots (in the order they were given in the input), after no further collisions can occur.</em></p>

<p><strong>Note:</strong> The positions may be unsorted.</p>

2751. Столкновения роботов

<br>Сложно
<p>Имеется <code>n</code> <strong>1-индексированных</strong> роботов, каждый из которых имеет позицию на линии, здоровье и направление движения.</p>

<p>Вам даны <strong>0-индексированные</strong> целочисленные массивы <code>positions</code>, <code>healths</code> и строка <code>directions</code> (<code>directions[i]</code> может быть либо <strong>'L'</strong> для <strong>left</strong>, либо <strong>'R'</strong> для <strong>right</strong>). Все целые числа в <code>positions</code> являются <strong>уникальными</strong>.</p>

<p>Все роботы начинают движение по линии<strong>одновременно</strong> с <strong>одинаковой скоростью</strong> в заданных направлениях. Если два робота окажутся в одной и той же позиции во время движения, они столкнутся.

Ось ефективне рішення для задачі **2751. Robot Collisions**. 

Ця задача є класичним прикладом використання структури даних **Стек (Stack)**. Оскільки роботи рухаються з однаковою швидкістю, зіткнення можуть відбутися лише тоді, коли робот, що рухається вправо (`R`), знаходиться лівіше від робота, що рухається вліво (`L`).

### Підхід до вирішення:
1. **Збереження початкових індексів:** Оскільки нам потрібно повернути здоров'я роботів у початковому порядку, ми маємо запам'ятати їхні оригінальні індекси перед сортуванням.
2. **Сортування за позицією:** Сортуємо роботів зліва направо за їхніми координатами на прямій.
3. **Використання стека для симуляції:** * Йдемо по відсортованому масиву.
   * Якщо робот рухається вправо (`R`), просто додаємо його в стек (він може зіткнутися з кимось у майбутньому).
   * Якщо робот рухається вліво (`L`), перевіряємо вершину стека. Поки на вершині стека є робот, що рухається вправо (`R`), відбувається зіткнення. Ми порівнюємо їхнє здоров'я і зменшуємо його або видаляємо роботів за правилами задачі.
   * Якщо робот `L` вижив після всіх можливих зіткнень, додаємо його в стек.
4. **Відновлення порядку:** Після завершення симуляції сортуємо роботів, що залишилися в стеку, за їхнім початковим індексом і формуємо фінальний масив здоров'я.

### Код мовою JavaScript:

```javascript
/**
 * @param {number[]} positions
 * @param {number[]} healths
 * @param {string} directions
 * @return {number[]}
 */
var survivedRobotsHealths = function (positions, healths, directions) {
  const n = positions.length;
  const robots = [];

  // 1. Створюємо об'єкти з повною інформацією про кожного робота
  for (let i = 0; i < n; i++) {
    robots.push({
      index: i,
      position: positions[i],
      health: healths[i],
      direction: directions[i],
    });
  }

  // 2. Сортуємо за позицією (зліва направо)
  robots.sort((a, b) => a.position - b.position);

  const stack = [];

  // 3. Симулюємо зіткнення
  for (const robot of robots) {
    if (robot.direction === 'R') {
      stack.push(robot);
    } else {
      let survived = true;

      // Поки в стеку є роботи, що рухаються вправо, і поточний робот 'L' ще живий
      while (stack.length > 0 && stack[stack.length - 1].direction === 'R') {
        const topRobot = stack[stack.length - 1];

        if (topRobot.health > robot.health) {
          topRobot.health -= 1; // Правий робот перемагає
          survived = false;
          break;
        } else if (topRobot.health < robot.health) {
          robot.health -= 1; // Лівий робот перемагає, правий знищується
          stack.pop();
        } else {
          stack.pop(); // Обидва знищуються
          survived = false;
          break;
        }
      }

      // Якщо лівий робот вижив після всіх зіткнень, додаємо його в стек
      if (survived) {
        stack.push(robot);
      }
    }
  }

  // 4. Відновлюємо початковий порядок і повертаємо здоров'я
  stack.sort((a, b) => a.index - b.index);
  return stack.map((robot) => robot.health);
};
```

### Оцінка складності:
* **Часова складність:** $O(N \log N)$. Ми двічі застосовуємо сортування: спочатку за позицією ($O(N \log N)$), а в кінці — за оригінальним індексом ($O(K \log K)$, де $K \le N$). Операції зі стеком в середньому займають $O(N)$, оскільки кожен робот додається і видаляється зі стека не більше одного разу.
* **Просторова складність:** $O(N)$. Потрібна додаткова пам'ять для масиву об'єктів `robots` та для стека, розмір яких у найгіршому випадку дорівнює $N$.
