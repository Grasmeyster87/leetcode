3488. Closest Equal Element Queries
Medium

<p>You are given a <strong>circular</strong> array <code>nums</code> and an array <code>queries</code>.</p>

<p>For each query <code>i</code>, you have to find the following:</p>

<ul>
	<li>The <strong>minimum</strong> distance between the element at index <code>queries[i]</code> and <strong>any</strong> other index <code>j</code> in the <strong>circular</strong> array, where <code>nums[j] == nums[queries[i]]</code>. If no such index exists, the answer for that query should be -1.</li>
</ul>

<p>Return an array <code>answer</code> of the <strong>same</strong> size as <code>queries</code>, where <code>answer[i]</code> represents the result for query <code>i</code>.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums = [1,3,1,4,1,3,2], queries = [0,3,5]</span></p>

<p><strong>Output:</strong> <span class="example-io">[2,-1,3]</span></p>

<p><strong>Explanation:</strong></p>

<ul>
	<li>Query 0: The element at <code>queries[0] = 0</code> is <code>nums[0] = 1</code>. The nearest index with the same value is 2, and the distance between them is 2.</li>
	<li>Query 1: The element at <code>queries[1] = 3</code> is <code>nums[3] = 4</code>. No other index contains 4, so the result is -1.</li>
	<li>Query 2: The element at <code>queries[2] = 5</code> is <code>nums[5] = 3</code>. The nearest index with the same value is 1, and the distance between them is 3 (following the circular path: <code>5 -&gt; 6 -&gt; 0 -&gt; 1</code>).</li>
</ul>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums = [1,2,3,4], queries = [0,1,2,3]</span></p>

<p><strong>Output:</strong> <span class="example-io">[-1,-1,-1,-1]</span></p>

<p><strong>Explanation:</strong></p>

<p>Each value in <code>nums</code> is unique, so no index shares the same value as the queried element. This results in -1 for all queries.</p>
</div>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= queries.length &lt;= nums.length &lt;= 10<sup>5</sup></code></li>
	<li><code>1 &lt;= nums[i] &lt;= 10<sup>6</sup></code></li>
	<li><code>0 &lt;= queries[i] &lt; nums.length</code></li>
</ul>

3488. Запросы на поиск ближайшего равного элемента
Средний уровень сложности

<p>Вам дан <strong>циклический</strong> массив <code>nums</code> и массив <code>queries</code>.</p>

<p>Для каждого запроса <code>i</code> вам необходимо найти следующее:</p>

<ul>

<li>Минимальное</strong> расстояние между элементом с индексом <code>queries[i]</code> и любым другим индексом <code>j</code> в <strong>циклическом</strong> массиве, где <code>nums[j] == nums[queries[i]]</code>. Если такого индекса не существует, ответ на этот запрос должен быть -1.</li>
</ul>

<p>Возвращает массив <code>answer</code> того же размера, что и <code>queries</code>, где <code>answer[i]</code> представляет результат запроса <code>i</code>.</p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<div class="example-block">
<p><strong>Входные данные:</strong> <span class="example-io">nums = [1,3,1,4,1,3,2], queries = [0,3,5]</span></p>

<p><strong>Выходные данные:</strong> <span class="example-io">[2,-1,3]</span></p>

<p><strong>Пояснение:</strong></p>

<ul>

<li>Запрос 0: Элемент по адресу <code>queries[0] = 0</code> равен <code>nums[0] = 1</code>. Ближайший индекс с тем же значением — 2, а расстояние между ними — 2.</li>

<li>Запрос 1: Элемент по адресу <code>queries[1] = 3</code> равен <code>nums[3] = 4</code>. Ни один другой индекс не содержит 4, поэтому результат — -1.</li>

<li>Запрос 2: Элемент по адресу <code>queries[2] = 5</code> равен <code>nums[5] = 3</code>. Ближайший индекс с тем же значением равен 1, а расстояние между ними равно 3 (следуя по круговому пути: <code>5 ->6 ->0 ->1</code>).</li>
</ul>
</div>

<p><strong class="example">Пример 2:</strong></p>

<div class="example-block">
<p><strong>Входные данные:</strong> <span class="example-io">nums = [1,2,3,4], queries = [0,1,2,3]</span></p>

<p><strong>Выходные данные:</strong> <span class="example-io">[-1,-1,-1,-1]</span></p>

<p><strong>Пояснение:</strong></p>

<p>Каждое значение в <code>nums</code> уникально, поэтому ни один индекс не имеет одинакового значения. в качестве запрашиваемого элемента. Это приводит к значению -1 для всех запросов.</p>
</div>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>1 <= queries.length <= nums.length <= 10<sup>5</sup></code></li>
<li><code>1 <= nums[i] <= 10<sup>6</sup></code></li>
<li><code>0 <= queries[i] < nums.length</code></li>
</ul>
