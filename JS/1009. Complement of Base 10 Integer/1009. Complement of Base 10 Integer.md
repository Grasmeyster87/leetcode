1009. Complement of Base 10 Integer


The complement of an integer is the integer you get when you flip all the 0's to 1's and all the 1's to 0's in its binary representation.

    For example, The integer 5 is "101" in binary and its complement is "010" which is the integer 2.

Given an integer n, return its complement.

 

Example 1:

Input: n = 5
Output: 2
Explanation: 5 is "101" in binary, with complement "010" in binary, which is 2 in base-10.

Example 2:

Input: n = 7
Output: 0
Explanation: 7 is "111" in binary, with complement "000" in binary, which is 0 in base-10.

Example 3:

Input: n = 10
Output: 5
Explanation: 10 is "1010" in binary, with complement "0101" in binary, which is 5 in base-10.

 

Constraints:

    0 <= n < 109

1009. Дополнение к десятичному целому числу

Дополнение к целому числу — это число, которое получается, если заменить все нули на единицы и все единицы на нули в его двоичном представлении.

Например, целое число 5 в двоичной системе — это «101», а его дополнение — «010», то есть число 2.

Дано целое число n, верните его дополнение.

Пример 1:

Вход: n = 5
Выход: 2
Пояснение: 5 в двоичной системе — это «101», с дополнением «010», то есть 2 в десятичной системе.

Пример 2:

Вход: n = 7
Выход: 0
Пояснение: 7 в двоичной системе — это «111», с дополнением «000», то есть 0 в десятичной системе.

Пример 3:

Входные данные: n = 10
Выходные данные: 5
Пояснение: 10 в двоичной системе счисления — это "1010", а в двоичной системе счисления — "0101", что равно 5 в десятичной системе.

Ограничения:

0 <= n < 109

Примечание: Этот вопрос аналогичен вопросу 476: https://leetcode.com/problems/number-complement/
