3567. Minimum Absolute Difference in Sliding Submatrix
Medium

You are given an m x n integer matrix grid and an integer k.

For every contiguous k x k submatrix of grid, compute the minimum absolute difference between any two distinct values within that submatrix.

Return a 2D array ans of size (m - k + 1) x (n - k + 1), where ans[i][j] is the minimum absolute difference in the submatrix whose top-left corner is (i, j) in grid.

Note: If all elements in the submatrix have the same value, the answer will be 0.
A submatrix (x1, y1, x2, y2) is a matrix that is formed by choosing all cells matrix[x][y] where x1 <= x <= x2 and y1 <= y <= y2.

 

Example 1:

Input: grid = [[1,8],[3,-2]], k = 2

Output: [[2]]

Explanation:

    There is only one possible k x k submatrix: [[1, 8], [3, -2]].
    Distinct values in the submatrix are [1, 8, 3, -2].
    The minimum absolute difference in the submatrix is |1 - 3| = 2. Thus, the answer is [[2]].

Example 2:

Input: grid = [[3,-1]], k = 1

Output: [[0,0]]

Explanation:

    Both k x k submatrix has only one distinct element.
    Thus, the answer is [[0, 0]].

Example 3:

Input: grid = [[1,-2,3],[2,3,5]], k = 2

Output: [[1,2]]

Explanation:

    There are two possible k × k submatrix:
        Starting at (0, 0): [[1, -2], [2, 3]].
            Distinct values in the submatrix are [1, -2, 2, 3].
            The minimum absolute difference in the submatrix is |1 - 2| = 1.
        Starting at (0, 1): [[-2, 3], [3, 5]].
            Distinct values in the submatrix are [-2, 3, 5].
            The minimum absolute difference in the submatrix is |3 - 5| = 2.
    Thus, the answer is [[1, 2]].

 

Constraints:

    1 <= m == grid.length <= 30
    1 <= n == grid[i].length <= 30
    -105 <= grid[i][j] <= 105
    1 <= k <= min(m, n)

3567. Минимальная абсолютная разница в скользящей подматрице
Средний уровень сложности

Вам дана целочисленная матрица grid размером m x n и целое число k.

Для каждой смежной подматрицы grid размером k x k вычислите минимальную абсолютную разницу между любыми двумя различными значениями внутри этой подматрицы.

Верните двумерный массив ans размером (m - k + 1) x (n - k + 1), где ans[i][j] — минимальная абсолютная разница в подматрице, верхний левый угол которой находится в точке (i, j) в grid.

Примечание: Если все элементы в подматрице имеют одинаковое значение, ответ будет равен 0.
Подматрица (x1, y1, x2, y2) — это матрица, которая формируется путем выбора всех ячеек matrix[x][y], где x1 <= x <= x2 и y1 <= y <= y2.

Пример 1:

Входные данные: grid = [[1,8],[3,-2]], k = 2

Выходные данные: [[2]]

Пояснение:

Существует только одна возможная подматрица k x k: [[1, 8], [3, -2]].
Различные значения в подматрице: [1, 8, 3, -2].
Минимальная абсолютная разница в подматрице равна |1 - 3| = 2. Таким образом, ответ: [[2]].

Пример 2:

Входные данные: grid = [[3,-1]], k = 1

Выходные данные: [[0,0]]

Пояснение:

Обе подматрицы k x k имеют только один уникальный элемент.
Таким образом, ответ: [[0, 0]].

Пример 3:

Входные данные: grid = [[1,-2,3],[2,3,5]], k = 2

Выходные данные: [[1,2]]

Пояснение:

Существует две возможные подматрицы k × k:

Начиная с (0, 0): [[1, -2], [2, 3]].
Различные значения в подматрице: [1, -2, 2, 3].
Минимальная абсолютная разница в подматрице равна |1 - 2| = 1.
Начиная с (0, 1): [[-2, 3], [3, 5]].
Различные значения в подматрице: [-2, 3, 5].
Минимальная абсолютная разница в подматрице равна |3 - 5| = 2.

Таким образом, ответ: [[1, 2]].

Ограничения:

1 <= m == grid.length <= 30

1 <= n == grid[i].length <= 30

-105 <= grid[i][j] <= 105

1 <= k <= min(m, n)

З огляду на невеликі обмеження в умові (матриця максимум $30 \times 30$), ми можемо використати прямий підхід (Brute Force) з сортуванням для кожної підматриці. Це буде працювати ефективно, оскільки загальна кількість операцій не перевищить ліміти для JavaScript.

Ось розв’язок для файлу `3567. Minimum Absolute Difference in Sliding Submatrix.js`:

```javascript
/**
 * @param {number[][]} grid
 * @param {number} k
 * @return {number[][]}
 */
var minAbsDiff = function(grid, k) {
    const m = grid.length;
    const n = grid[0].length;
    
    // Розмір вихідної матриці згідно з умовою
    const resRows = m - k + 1;
    const resCols = n - k + 1;
    const ans = Array.from({ length: resRows }, () => new Array(resCols).fill(0));

    for (let i = 0; i <= m - k; i++) {
        for (let j = 0; j <= n - k; j++) {
            // 1. Збираємо всі унікальні елементи поточної підматриці k x k
            const elements = new Set();
            for (let r = i; r < i + k; r++) {
                for (let c = j; c < j + k; c++) {
                    elements.add(grid[r][c]);
                }
            }

            // 2. Якщо унікальних елементів менше 2, різниця за умовою 0
            if (elements.size < 2) {
                ans[i][j] = 0;
                continue;
            }

            // 3. Перетворюємо Set у відсортований масив
            const sortedUnique = Array.from(elements).sort((a, b) => a - b);

            // 4. Знаходимо мінімальну різницю між сусідніми елементами
            let minDiff = Infinity;
            for (let p = 0; p < sortedUnique.length - 1; p++) {
                const diff = Math.abs(sortedUnique[p + 1] - sortedUnique[p]);
                if (diff < minDiff) {
                    minDiff = diff;
                }
                // Якщо знайшли 1, менше вже не буде (для цілих чисел), можна вийти раніше
                if (minDiff === 1) break;
            }

            ans[i][j] = minDiff;
        }
    }

    return ans;
};
```

### Чому обрано саме такий підхід:
1.  **Складність**: Кількість підматриць — максимум 900. Кожна підматриця містить до 900 елементів. Сортування 900 елементів — це дуже швидка операція для сучасних рушіїв JS.
2.  **Унікальність**: Використання `Set` дозволяє автоматично відсіяти однакові значення, що спрощує пошук різниці між *різними* (distinct) числами.
3.  **Умова для k=1**: Якщо $k=1$ або всі числа в підматриці однакові, `elements.size` буде дорівнювати 1, і код коректно поверне 0, як в прикладі 2.

### 1. Чи зміниться порядок у контейнері при сортуванні?
Ні, структура вашої основної матриці `grid` та результуючого масиву `ans` залишиться незмінною.

* **Тимчасовий масив:** Команда `Array.from(elements)` створює абсолютно **новий, окремий масив** у пам'яті, який містить лише значення поточної підматриці.
* **Ізоляція:** Метод `.sort()` застосовується тільки до цього нового тимчасового масиву (`sortedUnique`).
* **Результат:** Оригінальна матриця `grid` не модифікується. Ми просто використовуємо відсортовані значення, щоб швидко знайти мінімальну різницю між сусідніми числами, а потім записуємо результат у відповідну комірку `ans[i][j]`.

### 2. Куди зникає друга трійка у Прикладі 3?
Це ключовий момент умови завдання. В тексті зазначено: *"compute the minimum absolute difference between any two **distinct** values"* (обчисліть мінімальну абсолютну різницю між будь-якими двома **різними** значеннями).

Розберемо другу підматрицю з Прикладу 3: `[[-2, 3], [3, 5]]`
1.  **Всі елементи:** $-2, 3, 3, 5$.
2.  **Унікальні (distinct) значення:** Нам потрібні саме *різні* числа. Оскільки $3$ і $3$ — це одне й те саме значення, у набір унікальних елементів потрапляє лише одна трійка.
3.  **Набір для розрахунку:** $\{-2, 3, 5\}$.
4.  **Пошук різниці:**
    * $| -2 - 3 | = 5$
    * $| 3 - 5 | = 2$
    * $| -2 - 5 | = 7$
5.  **Мінімальний результат:** $2$.

Якби ми враховували однакові числа (дві трійки), то різниця була б $|3 - 3| = 0$. Проте за умовою ми шукаємо різницю лише між **несхожими** числами. Тільки якщо *всі* елементи в підматриці однакові (наприклад, `[[3, 3], [3, 3]]`), тоді відповідь буде $0$.
