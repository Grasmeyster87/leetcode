3225. Maximum Score From Grid Operations

Hard

<p>You are given a 2D matrix <code>grid</code> of size <code>n x n</code>. Initially, all cells of the grid are colored white. In one operation, you can select any cell of indices <code>(i, j)</code>, and color black all the cells of the <code>j<sup>th</sup></code> column starting from the top row down to the <code>i<sup>th</sup></code> row.</p>

<p>The grid score is the sum of all <code>grid[i][j]</code> such that cell <code>(i, j)</code> is white and it has a horizontally adjacent black cell.</p>

<p>Return the <strong>maximum</strong> score that can be achieved after some number of operations.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">grid = [[0,0,0,0,0],[0,0,3,0,0],[0,1,0,0,0],[5,0,0,3,0],[0,0,0,0,2]]</span></p>

<p><strong>Output:</strong> <span class="example-io">11</span></p>

<p><strong>Explanation:</strong></p>
<img alt="" style="width: 300px; height: 200px;" src="https://assets.leetcode.com/uploads/2024/05/11/one.png">
<p>In the first operation, we color all cells in column 1 down to row 3, and in the second operation, we color all cells in column 4 down to the last row. The score of the resulting grid is <code>grid[3][0] + grid[1][2] + grid[3][3]</code> which is equal to 11.</p>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">grid = [[10,9,0,0,15],[7,1,0,8,0],[5,20,0,11,0],[0,0,0,1,2],[8,12,1,10,3]]</span></p>

<p><strong>Output:</strong> <span class="example-io">94</span></p>

<p><strong>Explanation:</strong></p>
<img alt="" style="width: 300px; height: 200px;" src="https://assets.leetcode.com/uploads/2024/05/11/two-1.png">
<p>We perform operations on 1, 2, and 3 down to rows 1, 4, and 0, respectively. The score of the resulting grid is <code>grid[0][0] + grid[1][0] + grid[2][1] + grid[4][1] + grid[1][3] + grid[2][3] + grid[3][3] + grid[4][3] + grid[0][4]</code> which is equal to 94.</p>
</div>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;=&nbsp;n == grid.length &lt;= 100</code></li>
	<li><code>n == grid[i].length</code></li>
	<li><code>0 &lt;= grid[i][j] &lt;= 10<sup>9</sup></code></li>
</ul>

3225. Максимальный балл за операции с сеткой

Сложно

<p>Вам дана двумерная матрица <code>grid</code> размером <code>n x n</code>. Изначально все ячейки сетки окрашены в белый цвет. За одну операцию можно выбрать любую ячейку с индексами <code>(i, j)</code> и закрасить черным цветом все ячейки <code>j</sup>-го</sup> столбца, начиная с верхней строки и до <code>i</sup>-й строки.</p>

<p>Оценка сетки — это сумма всех <code>grid[i][j]</code> таких, что ячейка <code>(i, j)</code> белая и имеет расположенную рядом по горизонтали черную ячейку.</p>

<p>Возвращает <strong>максимальную</strong> оценку, которая может быть достигнута после некоторого количества операций.</p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<div class="example-block">
<p><strong>Ввод:</strong> <span class="example-io">grid = [[0,0,0,0,0],[0,0,3,0,0],[0,1,0,0,0],[5,0,0,3,0],[0,0,0,0,2]]</span></p>

<p><strong>Вывод:</strong> <span class="example-io">11</span></p>

<p><strong>Пояснение:</strong></p>
<img alt="" style="width: 300px; height: 200px;" src="https://assets.leetcode.com/uploads/2024/05/11/one.png">
<p>В первой операции мы окрашиваем все ячейки в столбце 1 до строки 3, а во второй операции — все ячейки в столбце 4 до последней строки. Результат полученной сетки равен <code>grid[3][0] + grid[1][2] + grid[3][3]</code>, что равно 11.</p>
</div>

<p><strong class="example">Пример 2:</strong></p>

<div class="example-block">
<p><strong>Входные данные:</strong> <span class="example-io">grid = [[10,9,0,0,15],[7,1,0,8,0],[5,20,0,11,0],[0,0,0,1,2],[8,12,1,10,3]]</span></p>

<p><strong>Выходные данные:</strong> <span class="example-io">94</span></p>

<p><strong>Пояснение:</strong></p>
<img alt="" style="width: 300px; height: 200px;" src="https://assets.leetcode.com/uploads/2024/05/11/two-1.png">
<p>Мы выполняем операции над 1, 2 и 3 вплоть до строк 1, 4 и 0 соответственно. Результатом полученной сетки является <code>grid[0][0] + grid[1][0] + grid[2][1] + grid[4][1] + grid[1][3] + grid[2][3] + grid[3][3] + grid[4][3] + grid[0][4]</code>, что равно 94.</p>
</div>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>1 <=&nbsp;n == grid.length <= 100</code></li>

<li><code>n == grid[i].length</code></li>

<li><code>0 <= grid[i][j] <= 10<sup>9</sup></code></li>
</ul>

<h2>Построковий опис коду</h2>

<h3>Складність</h3>
<ul>
<li>Час: <code>O(n³)</code></li>
<li>Пам'ять: <code>O(n²)</code></li>
</ul>

<h3>Ключова ідея</h3>
<p>Кожен стовпець можна "зафарбувати" чорним зверху вниз на деяку висоту <code>h</code> (від 0 до n). Бали отримуємо за <strong>білі</strong> клітини, які <strong>горизонтально суміжні</strong> з чорними. Тобто бали з'являються на межі між стовпцями з різними висотами: білі клітини одного стовпця, що знаходяться навпроти чорних клітин сусіднього стовпця.</p>

<h3>Код з поясненнями</h3>

<pre><code>var maximumScore = function (grid) {</code></pre>
<p><strong>Рядок 17:</strong> Оголошення функції, яка приймає двовимірну матрицю <code>grid</code> розміром <code>n × n</code>.</p>

<pre><code>    const n = grid.length;</code></pre>
<p><strong>Рядок 18:</strong> Зберігаємо розмір сітки. Матриця завжди квадратна (<code>n × n</code>).</p>

<br>
<h4>Блок 1: Побудова префіксних сум по стовпцях</h4>

<pre><code>    const prefix = Array.from({ length: n }, () => new Array(n + 1).fill(0));</code></pre>
<p><strong>Рядок 21:</strong> Створюємо масив <code>prefix[j][i]</code> — сума перших <code>i</code> елементів у стовпці <code>j</code>. Розмір кожного підмасиву <code>n + 1</code>, бо <code>prefix[j][0] = 0</code> (сума нуля елементів).</p>

<pre><code>    for (let j = 0; j < n; j++) {
        for (let i = 0; i < n; i++) {
            prefix[j][i + 1] = prefix[j][i] + grid[i][j];
        }
    }</code></pre>
<p><strong>Рядки 23–27:</strong> Заповнюємо префіксні суми. Для кожного стовпця <code>j</code> накопичуємо суму елементів зверху вниз. Після цього <code>prefix[j][b] - prefix[j][a]</code> дає суму елементів стовпця <code>j</code> з рядка <code>a</code> до рядка <code>b-1</code> (напівінтервал <code>[a, b)</code>).</p>

<br>
<h4>Блок 2: Ініціалізація DP станів</h4>

<pre><code>    let prevPick = new Array(n + 1).fill(0);</code></pre>
<p><strong>Рядок 31:</strong> <code>prevPick[i]</code> — максимальний бал, досягнутий до попереднього стовпця, за умови що попередній стовпець було <strong>зафарбовано</strong> (має чорні клітини) до рядка <code>i - 1</code> (тобто висота = <code>i</code>).</p>

<pre><code>    let prevSkip = new Array(n + 1).fill(0);</code></pre>
<p><strong>Рядок 35:</strong> <code>prevSkip[i]</code> — максимальний бал, де попередній стовпець <strong>НЕ</strong> було зафарбовано (або пропущено), а останній фактично зафарбований стовпець мав висоту <code>i</code>. Цей стан потрібен, щоб правильно обраховувати бали, коли поточний стовпець глибший за "останній обраний".</p>

<br>
<h4>Блок 3: Основний цикл DP — обхід стовпців</h4>

<pre><code>    for (let j = 1; j < n; j++) {</code></pre>
<p><strong>Рядок 37:</strong> Ітеруємо по стовпцях зліва направо, починаючи з <code>j = 1</code> (стовпець 0 — базовий випадок, всі значення 0).</p>

<pre><code>        const currPick = new Array(n + 1).fill(0);
        const currSkip = new Array(n + 1).fill(0);</code></pre>
<p><strong>Рядки 38–39:</strong> Нові масиви для поточного стовпця <code>j</code>: <code>currPick</code> і <code>currSkip</code> — аналоги <code>prevPick</code>/<code>prevSkip</code>, але для стовпця <code>j</code>.</p>

<br>
<h4>Блок 4: Перебір пар (curr, prev) — висот поточного та попереднього стовпців</h4>

<pre><code>        for (let curr = 0; curr <= n; curr++) {
            for (let prev = 0; prev <= n; prev++) {</code></pre>
<p><strong>Рядки 41–42:</strong> <code>curr</code> — кількість чорних клітин у стовпці <code>j</code> (висота від 0 до n). <code>prev</code> — кількість чорних клітин у попередньому стовпці <code>j-1</code>.</p>

<br>
<h4>Випадок 1: curr > prev (поточний стовпець глибший)</h4>

<pre><code>                if (curr > prev) {
                    const score = prefix[j - 1][curr] - prefix[j - 1][prev];</code></pre>
<p><strong>Рядки 43–47:</strong> Якщо в стовпці <code>j</code> чорних клітин більше, ніж у <code>j-1</code>, то рядки від <code>prev</code> до <code>curr-1</code> у стовпці <code>j-1</code> є <strong>білими</strong> і суміжні з <strong>чорними</strong> клітинами стовпця <code>j</code>. Ці білі клітини приносять бали = <code>prefix[j-1][curr] - prefix[j-1][prev]</code>.</p>

<pre><code>                    currPick[curr] = Math.max(
                        currPick[curr],
                        prevSkip[prev] + score
                    );</code></pre>
<p><strong>Рядки 48–51:</strong> Оновлюємо <code>currPick[curr]</code>: бали від попередніх стовпців (<code>prevSkip[prev]</code>) плюс бали за білі клітини стовпця <code>j-1</code>. Використовуємо <code>prevSkip</code>, а не <code>prevPick</code>, тому що коли <code>curr > prev</code>, бали з рядків <code>[prev, curr)</code> стовпця <code>j-1</code> вже <strong>враховані через стовпець j</strong>, і ми не хочемо подвійного рахування з того ж стовпця <code>j-1</code>.</p>

<pre><code>                    currSkip[curr] = Math.max(
                        currSkip[curr],
                        prevSkip[prev] + score
                    );</code></pre>
<p><strong>Рядки 52–55:</strong> Аналогічно оновлюємо <code>currSkip[curr]</code>. Бали ті самі, бо score визначається лише різницею висот.</p>

<br>
<h4>Випадок 2: curr <= prev (попередній стовпець глибший або рівний)</h4>

<pre><code>                } else {
                    const score = prefix[j][prev] - prefix[j][curr];</code></pre>
<p><strong>Рядки 56–60:</strong> Якщо стовпець <code>j-1</code> глибший, то рядки від <code>curr</code> до <code>prev-1</code> у стовпці <code>j</code> — <strong>білі</strong> і суміжні з <strong>чорними</strong> клітинами стовпця <code>j-1</code>. Бали = <code>prefix[j][prev] - prefix[j][curr]</code>.</p>

<pre><code>                    currPick[curr] = Math.max(
                        currPick[curr],
                        prevPick[prev] + score
                    );</code></pre>
<p><strong>Рядки 61–64:</strong> Оновлюємо <code>currPick[curr]</code>: використовуємо <code>prevPick[prev]</code> (попередній стовпець був зафарбований) + бали за білі клітини поточного стовпця <code>j</code>.</p>

<pre><code>                    currSkip[curr] = Math.max(
                        currSkip[curr],
                        prevPick[prev]
                    );</code></pre>
<p><strong>Рядки 65–68:</strong> Оновлюємо <code>currSkip[curr]</code>: тут <strong>без score</strong>! Чому? Бо <code>currSkip</code> означає, що ми "пропускаємо" поточний стовпець. Бали за білі клітини стовпця <code>j</code> (рядки <code>[curr, prev)</code>) ще <strong>можуть бути зібрані</strong> пізніше наступним стовпцем <code>j+1</code>, якщо він буде глибшим. Тому їх не рахуємо зараз.</p>

<br>
<h4>Блок 5: Перехід до наступного стовпця</h4>

<pre><code>        prevPick = currPick;
        prevSkip = currSkip;</code></pre>
<p><strong>Рядки 73–74:</strong> Ковзне оновлення — поточні стани стають попередніми для наступної ітерації. Це дозволяє тримати пам'ять <code>O(n)</code> для DP масивів (загальна <code>O(n²)</code> через prefix).</p>

<br>
<h4>Блок 6: Результат</h4>

<pre><code>    return Math.max(...prevPick);
};</code></pre>
<p><strong>Рядки 77–78:</strong> Повертаємо максимальне значення серед усіх <code>prevPick[i]</code>. Використовуємо саме <code>prevPick</code>, а не <code>prevSkip</code>, бо фінальний результат завжди оптимальний, коли останній "значущий" стовпець обрано (після нього нема стовпця, який міг би зібрати його бали).</p>

<br>
<h3>Чому два стани: Pick і Skip?</h3>
<p>Коли <code>curr > prev</code>, бали збираються зі стовпця <code>j-1</code>. Але ці бали вже могли бути частково зібрані, якщо стовпець <code>j-1</code> сам "бачив" свого лівого сусіда. Щоб уникнути подвійного рахування, ми розділяємо стан на <code>Pick</code> (стовпець зафарбований і може давати бали сусідам) та <code>Skip</code> (стовпець пропущено, бали ще не зібрані).</p>
