3742. Maximum Path Score in a Grid

Medium

<p>You are given an <code>m x n</code> grid where each cell contains one of the values 0, 1, or 2. You are also given an integer <code>k</code>.</p>

<p>You start from the top-left corner <code>(0, 0)</code> and want to reach the bottom-right corner <code>(m - 1, n - 1)</code> by moving only <strong>right</strong> or <strong>down</strong>.</p>

<p>Each cell contributes a specific score and incurs an associated cost, according to their cell values:</p>

<ul>
	<li>0: adds 0 to your score and costs 0.</li>
	<li>1: adds 1 to your score and costs 1.</li>
	<li>2: adds 2 to your score and costs 1. ​​​​​​​</li>
</ul>

<p>Return the <strong>maximum</strong> score achievable without exceeding a total cost of <code>k</code>, or -1 if no valid path exists.</p>

<p><strong>Note:</strong> If you reach the last cell but the total cost exceeds <code>k</code>, the path is invalid.</p>

## Построковий опис рішення

### Підхід: Динамічне програмування (3D DP)

**Ідея:** Використовуємо `dp[i][j][c]` — максимальний score, який можна набрати, дійшовши до клітинки `(i, j)` з сумарною вартістю рівно `c`.

**Правила вартості та балів:**
- Клітинка `0` → score +0, cost +0
- Клітинка `1` → score +1, cost +1
- Клітинка `2` → score +2, cost +1

---

```
Рядок  | Код                                                    | Опис
-------|--------------------------------------------------------|---------------------------------------------
1      | var maxPathScore = function(grid, k) {                 | Оголошуємо функцію з параметрами grid та k
2      |     const m = grid.length;                             | Зберігаємо кількість рядків сітки
3      |     const n = grid[0].length;                          | Зберігаємо кількість стовпців сітки
4-7    |     const dp = Array.from({ length: m }, () =>         | Створюємо 3D масив dp[m][n][k+1],
       |         Array.from({ length: n }, () =>                | ініціалізований значенням -1
       |             new Array(k + 1).fill(-1)                  | (-1 означає недосяжний стан)
       |         )                                              |
       |     );                                                 |
8      |     dp[0][0][0] = 0;                                   | Базовий випадок: старт у (0,0) з score=0, cost=0
9      |     for (let i = 0; i < m; i++) {                      | Зовнішній цикл: перебираємо рядки зверху вниз
10     |         for (let j = 0; j < n; j++) {                  | Середній цикл: перебираємо стовпці зліва направо
11     |             for (let c = 0; c <= k; c++) {              | Внутрішній цикл: перебираємо можливі витрати 0..k
12     |                 if (dp[i][j][c] === -1) continue;       | Пропускаємо стани, до яких не можна дістатися
13     |                 const curScore = dp[i][j][c];            | Зберігаємо поточний score для зручності
14-20  |                 if (i + 1 < m) {                        | ПЕРЕХІД ВНИЗ: якщо є рядок нижче
       |                     const val = grid[i + 1][j];         |   Читаємо значення клітинки під нами
       |                     const addScore = val;                |   Score від клітинки = її значенню
       |                     const addCost = val > 0 ? 1 : 0;    |   Cost = 1 якщо значення > 0, інакше 0
       |                     const nc = c + addCost;              |   Обчислюємо нову сумарну вартість
       |                     if (nc <= k)                         |   Якщо не перевищуємо бюджет k:
       |                         dp[i+1][j][nc] = Math.max(...)   |     Оновлюємо dp максимумом
       |                 }                                        |
21-27  |                 if (j + 1 < n) {                        | ПЕРЕХІД ВПРАВО: якщо є стовпець правіше
       |                     const val = grid[i][j + 1];         |   Читаємо значення клітинки справа
       |                     const addScore = val;                |   Score від клітинки = її значенню
       |                     const addCost = val > 0 ? 1 : 0;    |   Cost = 1 якщо значення > 0, інакше 0
       |                     const nc = c + addCost;              |   Обчислюємо нову сумарну вартість
       |                     if (nc <= k)                         |   Якщо не перевищуємо бюджет k:
       |                         dp[i][j+1][nc] = Math.max(...)   |     Оновлюємо dp максимумом
       |                 }                                        |
28     |     let ans = -1;                                       | Ініціалізуємо відповідь як -1 (шлях не знайдено)
29-31  |     for (let c = 0; c <= k; c++) {                      | Перебираємо всі можливі вартості в кінцевій клітинці
       |         if (dp[m-1][n-1][c] !== -1)                     |   Якщо стан досяжний:
       |             ans = Math.max(ans, dp[m-1][n-1][c]);       |     Оновлюємо відповідь максимумом
       |     }                                                   |
32     |     return ans;                                         | Повертаємо максимальний score або -1
```

### Складність

- **Часова:** O(m × n × k) — три вкладених цикли
- **Просторова:** O(m × n × k) — 3D масив dp
