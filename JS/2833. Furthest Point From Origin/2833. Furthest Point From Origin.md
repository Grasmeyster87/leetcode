2833. Furthest Point From Origin
Easy

<p>You are given a string <code>moves</code> of length <code>n</code> consisting only of characters <code>'L'</code>, <code>'R'</code>, and <code>'_'</code>. The string represents your movement on a number line starting from the origin <code>0</code>.</p>

<p>In the <code>i<sup>th</sup></code> move, you can choose one of the following directions:</p>

<ul>
	<li>move to the left if <code>moves[i] = 'L'</code> or <code>moves[i] = '_'</code></li>
	<li>move to the right if <code>moves[i] = 'R'</code> or <code>moves[i] = '_'</code></li>
</ul>

<p>Return <em>the <strong>distance from the origin</strong> of the <strong>furthest</strong> point you can get to after </em><code>n</code><em> moves</em>.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<pre><strong>Input:</strong> moves = "L_RL__R"
<strong>Output:</strong> 3
<strong>Explanation:</strong> The furthest point we can reach from the origin 0 is point -3 through the following sequence of moves "LLRLLLR".
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre><strong>Input:</strong> moves = "_R__LL_"
<strong>Output:</strong> 5
<strong>Explanation:</strong> The furthest point we can reach from the origin 0 is point -5 through the following sequence of moves "LRLLLLL".
</pre>

<p><strong class="example">Example 3:</strong></p>

<pre><strong>Input:</strong> moves = "_______"
<strong>Output:</strong> 7
<strong>Explanation:</strong> The furthest point we can reach from the origin 0 is point 7 through the following sequence of moves "RRRRRRR".
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= moves.length == n &lt;= 50</code></li>
	<li><code>moves</code> consists only of characters <code>'L'</code>, <code>'R'</code> and <code>'_'</code>.</li>
</ul>

2833. Самая дальняя точка от начала координат
Легко

<p>Вам дана строка <code>moves</code> длиной <code>n</code>, состоящая только из символов <code>'L'</code>, <code>'R'</code> и <code>'_'</code>. Строка представляет ваше движение по числовой прямой, начиная с начала координат <code>0</code>.</p>

<p>На i-м ходу вы можете выбрать одно из следующих направлений:</p>

<ul>

<li>двигаться влево, если <code>moves[i] = 'L'</code> или <code>moves[i] = '_'</code>

<li>двигаться вправо, если <code>moves[i] = 'R'</code> или <code>moves[i] = '_'</code>
</ul>

<p>Возвращает <em>расстояние от начала координат до <strong>самой дальней</strong> точки, до которой вы можете добраться после </em><code>n</code><em> ходов</em>.</p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<pre><strong>Входные данные:</strong> moves = "L_RL__R"
<strong>Выходные данные:</strong> 3
<strong>Пояснение:</strong> Самая дальняя точка, до которой мы можем добраться от начала координат 0, — это точка -3, используя следующую последовательность ходов "LLRLLLR".

</pre>

<p><strong class="example">Пример 2:</strong></p>

<pre><strong>Входные данные:</strong> moves = "_R__LL_"
<strong>Выходные данные:</strong> 5
<strong>Пояснение:</strong> Самая дальняя точка, до которой мы можем добраться от начала координат 0, — это точка -5, используя следующую последовательность ходов "LRLLLLL".

</pre>

<p><strong class="example">Пример 3:</strong></p>

<pre><strong>Входные данные:</strong> moves = "_______"
<strong>Выходные данные:</strong> 7
<strong>Пояснение:</strong> Самая дальняя точка, до которой мы можем добраться от начала координат 0, — это точка 7, полученная с помощью следующей последовательности перемещений "RRRRRRRR".

</pre>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>1 <= moves.length == n <= 50</code></li>

<li><code>moves</code> состоит только из символов <code>'L'</code>, <code>'R'</code> и <code>'_'</code>.</li>
</ul>
