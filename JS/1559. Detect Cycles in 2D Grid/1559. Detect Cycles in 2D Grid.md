1559. Detect Cycles in 2D Grid

Medium

<p>Given a 2D array of characters <code>grid</code> of size <code>m x n</code>, you need to find if there exists any cycle consisting of the <strong>same value</strong> in <code>grid</code>.</p>

<p>A cycle is a path of <strong>length 4 or more</strong> in the grid that starts and ends at the same cell. From a given cell, you can move to one of the cells adjacent to it - in one of the four directions (up, down, left, or right), if it has the <strong>same value</strong> of the current cell.</p>

<p>Also, you cannot move to the cell that you visited in your last move. For example, the cycle <code>(1, 1) -&gt; (1, 2) -&gt; (1, 1)</code> is invalid because from <code>(1, 2)</code> we visited <code>(1, 1)</code> which was the last visited cell.</p>

<p>Return <code>true</code> if any cycle of the same value exists in <code>grid</code>, otherwise, return <code>false</code>.</p>

1559. Обнаружение циклов в двумерной сетке

Средний уровень сложности

<p>Дана двумерная сетка символов <code>grid</code> размером <code>m x n</code>. Необходимо найти, существует ли какой-либо цикл, состоящий из <strong>одинакового значения</strong> в <code>grid</code>.</p>

<p>Цикл — это путь длиной <strong>4 или более</strong> в сетке, который начинается и заканчивается в одной и той же ячейке. Из данной ячейки можно переместиться в одну из смежных с ней ячеек — в одном из четырех направлений (вверх, вниз, влево или вправо), если она имеет <strong>то же значение</strong>, что и текущая ячейка.</p>

<p>Также нельзя переместиться в ячейку, которую вы посетили в своем последнем перемещении. Например, цикл <code>(1, 1) -&gt; (1, 2) -&gt; (1, 1)</code> недействительно, потому что из <code>(1, 2)</code> мы посетили <code>(1, 1)</code>, которая была последней посещенной ячейкой.</p>

<p>Возвращает <code>true</code>, если в <code>grid</code> существует цикл с одинаковым значением, в противном случае возвращает <code>false</code>.</p>
