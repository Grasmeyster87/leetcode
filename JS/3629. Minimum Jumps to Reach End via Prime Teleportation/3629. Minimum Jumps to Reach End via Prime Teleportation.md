3629. Minimum Jumps to Reach End via Prime Teleportation

Medium
<p>You are given an integer array <code>nums</code> of length <code>n</code>.</p>

<p>You start at index 0, and your goal is to reach index <code>n - 1</code>.</p>

<p>From any index <code>i</code>, you may perform one of the following operations:</p>

<ul>
	<li><strong>Adjacent Step</strong>: Jump to index <code>i + 1</code> or <code>i - 1</code>, if the index is within bounds.</li>
	<li><strong>Prime Teleportation</strong>: If <code>nums[i]</code> is a <span data-keyword="prime-number" class=" cursor-pointer relative text-dark-blue-s text-sm"><button type="button" aria-haspopup="dialog" aria-expanded="false" aria-controls="radix-_r_1p_" data-state="closed" class="">prime number</button></span> <code>p</code>, you may instantly jump to any index <code>j != i</code> such that <code>nums[j] % p == 0</code>.</li>
</ul>

<p>Return the <strong>minimum</strong> number of jumps required to reach index <code>n - 1</code>.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums = [1,2,4,6]</span></p>

<p><strong>Output:</strong> <span class="example-io">2</span></p>

<p><strong>Explanation:</strong></p>

<p>One optimal sequence of jumps is:</p>

<ul>
	<li>Start at index <code>i = 0</code>. Take an adjacent step to index 1.</li>
	<li>At index <code>i = 1</code>, <code>nums[1] = 2</code> is a prime number. Therefore, we teleport to index <code>i = 3</code> as <code>nums[3] = 6</code> is divisible by 2.</li>
</ul>

<p>Thus, the answer is 2.</p>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums = [2,3,4,7,9]</span></p>

<p><strong>Output:</strong> <span class="example-io">2</span></p>

<p><strong>Explanation:</strong></p>

<p>One optimal sequence of jumps is:</p>

<ul>
	<li>Start at index <code>i = 0</code>. Take an adjacent step to index <code>i = 1</code>.</li>
	<li>At index <code>i = 1</code>, <code>nums[1] = 3</code> is a prime number. Therefore, we teleport to index <code>i = 4</code> since <code>nums[4] = 9</code> is divisible by 3.</li>
</ul>

<p>Thus, the answer is 2.</p>
</div>

<p><strong class="example">Example 3:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums = [4,6,5,8]</span></p>

<p><strong>Output:</strong> <span class="example-io">3</span></p>

<p><strong>Explanation:</strong></p>

<ul>
	<li>Since no teleportation is possible, we move through <code>0 → 1 → 2 → 3</code>. Thus, the answer is 3.</li>
</ul>
</div>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= n == nums.length &lt;= 10<sup>5</sup></code></li>
	<li><code>1 &lt;= nums[i] &lt;= 10<sup>6</sup></code></li>
</ul>

3629. Минимальное количество прыжков для достижения конца с помощью телепортации по простому числу

Средний уровень сложности
<p>Вам дан целочисленный массив <code>nums</code> длиной <code>n</code>.</p>

<p>Вы начинаете с индекса 0, и ваша цель — достичь индекса <code>n - 1</code>.</p>

<p>Из любого индекса <code>i</code> вы можете выполнить одну из следующих операций:</p>

<ul>

<li><strong>Шаг смежности</strong>: Перейдите к индексу <code>i + 1</code> или <code>i - 1</code>, если индекс находится в пределах допустимых значений.</li>

<li><strong>Телепортация по простому числу</strong>: Если <code>nums[i]</code> является <span data-keyword="prime-number" class=" cursor-pointer relative text-dark-blue-s text-sm"><button type="button" aria-haspopup="dialog" aria-expanded="false" aria-controls="radix-_r_1p_" data-state="closed" class="">простое число</button></span> <code>p</code>, вы можете мгновенно перейти к любому индексу <code>j != i</code> такому, что <code>nums[j] % p == 0</code>.</li>
</ul>

<p>Возвращает <strong>минимальное</strong> количество переходов, необходимых для достижения индекса <code>n - 1</code>.</p>

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<div class="example-block">
<p><strong>Ввод:</strong> <span class="example-io">nums = [1,2,4,6]</span></p>

<p><strong>Вывод:</strong> <span class="example-io">2</span></p>

<p><strong>Пояснение:</strong></p>

<p>Одна из оптимальных последовательностей переходов:</p>

<ul>

<li>Начните с индекса <code>i = 0</code>. Сделайте смежный шаг к индексу 1.</li>

<li>В индексе <code>i = 1</code>, <code>nums[1] = 2</code> является простым числом. Следовательно, мы телепортируемся к индексу <code>i = 3</code>, так как <code>nums[3] = 6</code> делится на 2.</li>
</ul>

<p>Таким образом, ответ — 2.</p>
</div>

<p><strong class="example">Пример 2:</strong></p>

<div class="example-block">
<p><strong>Входные данные:</strong> <span class="example-io">nums = [2,3,4,7,9]</span></p>

<p><strong>Выходные данные:</strong> <span class="example-io">2</span></p>

<p><strong>Пояснение:</strong></p>

<p>Одна из оптимальных последовательностей переходов:</p>

<ul>

<li>Начнем с индекса <code>i = 0</code>. Сделайте шаг в соседнем порядке до индекса <code>i = 1</code>.</li>

<li>На индексе <code>i = 1</code>, <code>nums[1] = 3</code> является простым числом. Следовательно, мы телепортируемся к индексу <code>i = 4</code>, поскольку <code>nums[4] = 9</code> делится на 3.</li>
</ul>

<p>Таким образом, ответ — 2.</p>
</div>

<p><strong class="example">Пример 3:</strong></p>

<div class="example-block">
<p><strong>Входные данные:</strong> <span class="example-io">nums = [4,6,5,8]</span></p>

<p><strong>Выходные данные:</strong> <span class="example-io">3</span></p>

<p><strong>Пояснение:</strong></p>

<ul>
<li>Поскольку телепортация невозможна, мы перемещаемся через <code>0 → 1 → 2 → 3</code>. Таким образом, ответ — 3.</li>
</ul>
</div>

## Построчний опис розв'язку

### Загальна ідея
Задача зводиться до **пошуку найкоротшого шляху (BFS)** у графі, де вершини — індекси масиву, а ребра — сусідні кроки (±1) або телепортація через просте число. Ключова оптимізація: після першого використання групи простого `p` — видаляємо її, щоб не обходити повторно.

### Складність
- **Час:** `O(MAX·log(log(MAX)) + n·log(max_val))` — решето + факторизація + BFS
- **Пам'ять:** `O(MAX + n·ω(max_val))` — решето + групи (ω — кількість різних простих дільників)

---

### Етап 1: Решето найменших простих дільників (рядки 1–10)

```javascript
const MAX = 1000001;
const spf = new Int32Array(MAX);
for (let i = 2; i < MAX; i++) {
    if (spf[i] === 0) {
        for (let j = i; j < MAX; j += i) {
            if (spf[j] === 0) spf[j] = i;
        }
    }
}
```

| Рядок | Опис |
|-------|------|
| `const MAX = 1000001` | Верхня межа значень `nums[i]` + 1 |
| `const spf = new Int32Array(MAX)` | Масив `spf[x]` зберігає найменший простий дільник числа `x`. Ініціалізовано нулями |
| `if (spf[i] === 0)` | Якщо `spf[i]` ще не заповнено, значить `i` — просте число (жоден менший дільник не «позначив» його) |
| `for (let j = i; j < MAX; j += i)` | Перебираємо всі кратні `i` |
| `if (spf[j] === 0) spf[j] = i` | Якщо `j` ще не має записаного дільника — записуємо `i` як його найменший простий дільник |

> **Навіщо:** SPF дозволяє факторизувати будь-яке число до 10⁶ за `O(log x)` та перевіряти чи число просте: `spf[x] === x` означає, що `x` просте.

> **Важливо:** Решето винесено **за межі функції** і обчислюється **один раз** — це критично для LeetCode, де функція викликається повторно на кожен тест.

### Етап 3: Побудова груп за простими дільниками (рядки 20–30)

```javascript
const group = new Map();
for (let j = 0; j < n; j++) {
    let x = nums[j];
    while (x > 1) {
        const p = spf[x];
        if (!group.has(p)) group.set(p, []);
        group.get(p).push(j);
        while (x % p === 0) x = x / p;
    }
}
```

| Рядок | Опис |
|-------|------|
| `const group = new Map()` | `group.get(p)` = масив індексів `j`, де просте `p` ділить `nums[j]` |
| `let x = nums[j]` | Копія значення для факторизації |
| `const p = spf[x]` | Дістаємо найменший простий дільник поточного `x` |
| `group.get(p).push(j)` | Додаємо індекс `j` до групи простого `p` |
| `while (x % p === 0) x = x / p` | Видаляємо всі входження `p` з `x` (наприклад, `12 → 12/2/2 = 3`) |

> **Приклад:** `nums[j] = 30` → дільники {2, 3, 5} → індекс `j` потрапить до `group[2]`, `group[3]`, `group[5]`.

### Етап 4: BFS — ініціалізація (рядки 32–36)

```javascript
const dist = new Int32Array(n).fill(-1);
dist[0] = 0;
const queue = [0];
let head = 0;
```

| Рядок | Опис |
|-------|------|
| `const dist = new Int32Array(n).fill(-1)` | Масив відстаней. `-1` = ще не відвідано |
| `dist[0] = 0` | Стартовий індекс 0 має відстань 0 |
| `const queue = [0]` | Черга BFS, починаємо з індексу 0 |
| `let head = 0` | Вказівник на початок черги (замість `shift()` для O(1)) |

### Етап 5: BFS — основний цикл (рядки 38–66)

```javascript
while (head < queue.length) {
    const i = queue[head++];
    const d = dist[i];
```

| Рядок | Опис |
|-------|------|
| `while (head < queue.length)` | Поки черга не порожня |
| `const i = queue[head++]` | Дістаємо поточний індекс (аналог `dequeue`) |
| `const d = dist[i]` | Поточна відстань від старту |

#### Сусідні кроки (рядки 42–51)

```javascript
if (i + 1 < n && dist[i + 1] === -1) {
    if (i + 1 === n - 1) return d + 1;
    dist[i + 1] = d + 1;
    queue.push(i + 1);
}
if (i - 1 >= 0 && dist[i - 1] === -1) {
    dist[i - 1] = d + 1;
    queue.push(i - 1);
}
```

| Рядок | Опис |
|-------|------|
| `i + 1 < n && dist[i + 1] === -1` | Перевіряємо: чи є правий сусід і чи він ще не відвіданий |
| `if (i + 1 === n - 1) return d + 1` | **Ранній вихід:** якщо правий сусід — це кінець, одразу повертаємо відповідь |
| `dist[i + 1] = d + 1` | Записуємо відстань до правого сусіда |
| Аналогічно для `i - 1` | Крок вліво (без раннього виходу для індексу 0, бо ми звідти стартували) |

#### Телепортація через просте число (рядки 53–65)

```javascript
const val = nums[i];
if (val >= 2 && spf[val] === val) {
    if (group.has(val)) {
        const indices = group.get(val);
        for (const j of indices) {
            if (dist[j] === -1) {
                if (j === n - 1) return d + 1;
                dist[j] = d + 1;
                queue.push(j);
            }
        }
        group.delete(val);
    }
}
```

| Рядок | Опис |
|-------|------|
| `val >= 2 && spf[val] === val` | Перевірка: чи `nums[i]` — просте число (SPF дорівнює самому числу) |
| `group.has(val)` | Чи група для цього простого ще існує (не була видалена раніше) |
| `for (const j of indices)` | Перебираємо всі індекси `j`, де `val` ділить `nums[j]` |
| `if (dist[j] === -1)` | Тільки невідвідані індекси |
| `if (j === n - 1) return d + 1` | **Ранній вихід** при досягненні кінця |
| `group.delete(val)` | **Ключова оптимізація:** видаляємо групу після обробки, щоб уникнути повторного перебору тих самих індексів |

> **Чому `group.delete` працює коректно?** Всі індекси з групи `p` були або додані в чергу (якщо невідвідані), або вже мають коротшу відстань. Повторний обхід тієї ж групи ніколи не дасть кращого результату, адже BFS гарантує пошук по зростанню відстані.
