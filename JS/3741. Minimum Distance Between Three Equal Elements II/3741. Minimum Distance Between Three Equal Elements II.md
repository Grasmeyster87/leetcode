3741. Minimum Distance Between Three Equal Elements II
Medium
<p>You are given an integer array <code>nums</code>.</p>

<p>A tuple <code>(i, j, k)</code> of 3 <strong>distinct</strong> indices is <strong>good</strong> if <code>nums[i] == nums[j] == nums[k]</code>.</p>

<p>The <strong>distance</strong> of a <strong>good</strong> tuple is <code>abs(i - j) + abs(j - k) + abs(k - i)</code>, where <code>abs(x)</code> denotes the <strong>absolute value</strong> of <code>x</code>.</p>

<p>Return an integer denoting the <strong>minimum</strong> possible <strong>distance</strong> of a <strong>good</strong> tuple. If no <strong>good</strong> tuples exist, return <code>-1</code>.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums = [1,2,1,1,3]</span></p>

<p><strong>Output:</strong> <span class="example-io">6</span></p>

<p><strong>Explanation:</strong></p>

<p>The minimum distance is achieved by the good tuple <code>(0, 2, 3)</code>.</p>

<p><code>(0, 2, 3)</code> is a good tuple because <code>nums[0] == nums[2] == nums[3] == 1</code>. Its distance is <code>abs(0 - 2) + abs(2 - 3) + abs(3 - 0) = 2 + 1 + 3 = 6</code>.</p>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums = [1,1,2,3,2,1,2]</span></p>

<p><strong>Output:</strong> <span class="example-io">8</span></p>

<p><strong>Explanation:</strong></p>

<p>The minimum distance is achieved by the good tuple <code>(2, 4, 6)</code>.</p>

<p><code>(2, 4, 6)</code> is a good tuple because <code>nums[2] == nums[4] == nums[6] == 2</code>. Its distance is <code>abs(2 - 4) + abs(4 - 6) + abs(6 - 2) = 2 + 2 + 4 = 8</code>.</p>
</div>

<p><strong class="example">Example 3:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums = [1]</span></p>

<p><strong>Output:</strong> <span class="example-io">-1</span></p>

<p><strong>Explanation:</strong></p>

<p>There are no good tuples. Therefore, the answer is -1.</p>
</div>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= n == nums.length &lt;= 10<sup>5</sup></code></li>
	<li><code>1 &lt;= nums[i] &lt;= n</code></li>
</ul>

3741. Минимальное расстояние между тремя равными элементами II
Средний уровень сложности
<p>Вам дан целочисленный массив <code>nums</code>.</p>

<p>Кортеж <code>(i, j, k)</code> с тремя <strong>различными</strong> индексами является <strong>хорошим</strong>, если <code>nums[i] == nums[j] == nums[k]</code>.</p>

<p>Расстояние</strong> хорошего кортежа равно <code>abs(i - j) + abs(j - k) + abs(k - i)</code>, где <code>abs(x)</code> обозначает <strong>абсолютное значение</strong> <code>x</code>.</p>

<p>Верните целое число, обозначающее <strong>минимальное</strong> возможное <strong>расстояние</strong> кортежа <strong>хороший</strong> кортеж. Если хороших кортежей не существует, верните -1.

<p>&nbsp;</p>
<p><strong class="example">Пример 1:</strong></p>

<div class="example-block">
<p><strong>Входные данные:</strong> <span class="example-io">nums = [1,2,1,1,3]</span></p>

<p><strong>Выходные данные:</strong> <span class="example-io">6</span></p>

<p><strong>Пояснение:</strong></p>

<p>Минимальное расстояние достигается хорошим кортежем <code>(0, 2, 3)</code>.</p>

<p><code>(0, 2, 3)</code> является хорошим кортежем, потому что <code>nums[0] == nums[2] == nums[3] == 1</code>. Расстояние равно <code>abs(0 - 2) + abs(2 - 3) + abs(3 - 0) = 2 + 1 + 3 = 6</code>.</p>
</div>

<p><strong class="example">Пример 2:</strong></p>

<div class="example-block">
<p><strong>Входные данные:</strong> <span class="example-io">nums = [1,1,2,3,2,1,2]</span></p>

<p><strong>Выходные данные:</strong> <span class="example-io">8</span></p>

<p><strong>Пояснение:</strong></p>

<p>Минимальное расстояние достигается с помощью хорошего кортежа <code>(2, 4, 6)</code>.</p>

<p><code>(2, 4, 6)</code> — хороший кортеж, потому что <code>nums[2] == nums[4] == nums[6] == 2</code>. Его расстояние равно <code>abs(2 - 4) + abs(4 - 6) + abs(6 - 2) = 2 + 2 + 4 = 8</code>.</p>
</div>

<p><strong class="example">Пример 3:</strong></p>

<div class="example-block">
<p><strong>Входные данные:</strong> <span class="example-io">nums = [1]</span></p>

<p><strong>Выходные данные:</strong> <span class="example-io">-1</span></p>

<p><strong>Пояснение:</strong></p>

<p>Подходящих кортежей нет. Следовательно, ответ -1.</p>
</div>

<p>&nbsp;</p>
<p><strong>Ограничения:</strong></p>

<ul>

<li><code>1 <= n == nums.length <= 10<sup>5</sup></code></li>
<li><code>1 <= nums[i] <= n</code></li>
</ul>

Для розв'язання цієї задачі з максимальною ефективністю нам потрібно спочатку спростити математичну формулу відстані.

### Аналіз формули
Припустимо, у нас є три індекси $i, j, k$, відсортовані за зростанням: $i < j < k$.
Формула відстані:
$D = |i - j| + |j - k| + |k - i|$
Оскільки $i < j < k$, ми можемо розкрити модулі:
$D = (j - i) + (k - j) + (k - i)$
$D = j - i + k - j + k - i = 2k - 2i = 2(k - i)$

Отже, щоб мінімізувати відстань, нам потрібно знайти три однакові елементи, у яких **різниця між максимальним та мінімальним індексом є найменшою**. Це означає, що ці три елементи мають бути якомога ближче один до одного в масиві. Найкращими кандидатами завжди будуть три **сусідні** входження одного й того самого числа.

### Алгоритм ($O(n)$)
1. Створюємо структуру (об'єкт або `Map`) для збереження списків індексів для кожного унікального числа.
2. Проходимо по масиву `nums` один раз і записуємо індекси кожного числа. Оскільки ми йдемо зліва направо, індекси в списках будуть автоматично відсортовані.
3. Проходимо по отриманих списках індексів. Якщо число зустрічається 3 або більше разів, перевіряємо відстань між кожним $p$-м та $(p-2)$-м індексами.
4. Обчислюємо відстань як $2 \times (indices[p] - indices[p-2])$.
5. Повертаємо мінімальну знайдену відстань або `-1`.

### Реалізація на JavaScript

```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
var minimumDistance = function(nums) {
    const indicesMap = new Map();
    let minDistance = Infinity;

    // Ггрупуємо індекси для кожного числа
    for (let i = 0; i < nums.length; i++) {
        const val = nums[i];
        if (!indicesMap.has(val)) {
            indicesMap.set(val, []);
        }
        indicesMap.get(val).push(i);
    }

    // Шукаємо мінімальну відстань серед трійок сусідніх індексів
    for (const indices of indicesMap.values()) {
        if (indices.length < 3) continue;

        for (let p = 2; p < indices.length; p++) {
            // Формула 2 * (k - i) для відсортованих i < j < k
            const currentDist = 2 * (indices[p] - indices[p - 2]);
            if (currentDist < minDistance) {
                minDistance = currentDist;
            }
        }
    }

    return minDistance === Infinity ? -1 : minDistance;
};
```

### Чому це рішення ефективне?
* **Часова складність:** $O(n)$, де $n$ — довжина масиву. Ми проходимо по масиву один раз для збору даних і ще один раз сумарно по всіх списках індексів.
* **Просторова складність:** $O(n)$ для зберігання індексів у `Map`.
* **Логіка:** Ми ігноруємо комбінації, які завідомо дадуть більшу відстань (наприклад, 1-й, 2-й та 4-й індекси), фокусуючись лише на найближчих трійках.
